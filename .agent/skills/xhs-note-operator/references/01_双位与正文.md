## 一、刚性基准 (Core Benchmarks)

### 1. 【全链路笔记运营：从“双位”跃迁至“五位一体”】

小红书爆款笔记运营，从传统的“双位”（封面认领/标题追问）全面升级加固为**“五位一体”**（认领位/追问位/赦免位/悬念位/暗号位）全链路心理机制体系：

| 阶段位 | 载体位置 | 心理机制与用户动作 | 时长/落点 | 刚性准则与要求 | 失败形态 |
|---|---|---|---|---|---|
| **① 认领位** | **封面图文** | **看**——一眼认领「这说的是我」，直击痛点 | 0.3 秒 | 2~4 行、总字数 ≤ 16、长短错落（长短长/短长短）；**强检包含生活化数据/量纲**（模式一必须含阿拉伯数字或百分比量纲，严禁考试得分词）；**支持【测试数据/量纲 + 人格反差标签】组合** | 空洞口号/字数超标/无数据量纲 |
| **② 追问位** | **笔记标题** | **读**——读完追问「然后呢？原来是这样」，抓搜索流量 | 1~2 秒 | 单行 ≤ 20 字；取材七型（甲1~3、乙1~4），严禁封面文字直球复读 | 与封面一模一样/标题位白送 |
| **③ 赦免位** | **正文首段/前3行** | **释**——情感赦免与松绑，卸下懂事愧疚与道德枷锁 | 前 3 行（折叠线前） | 结合真实测试数据或事件破题；前 3 行必须接住封面/标题钩子；带入生活道具/微动作；赋予“不是你的错/不必战战兢兢迎合”的心理赦免感 | 空泛说教/爹味指责/钩子割裂悬空 |
| **④ 悬念位** | **正文展开中段** | **入**——真实生活切片推展，留白未尽之言 | 正文腰部中段 | 展开五型（一事到底/倒带/对话/清单/判词）；强制实物微动作；引用报告金句转折；**严禁文青式宣誓升华**（如“晴空万里/自己扛”） | AI式顿悟升华/无道具抽象抒情 |
| **⑤ 暗号位** | **正文末行** | **扣**——同频集结暗号，促使读者对暗号接头 | 标签前最后一行 | 支持自然反问、互动暗号、生活定格或对话自然收束；**严禁机械营销套路**（“快去测测看吧”）与机械逼问 | 机械式营销逼问/机械营销套路 |

#### 五位一体各阶段分工与心理机制详解：

1. **① 认领位（封面）**：
   - **核心机制**：0.3 秒视觉拦截，让读者产生强烈的自我映射——「这写的不就是我吗？！」。
   - **刚性规范**：行数 2~4 行，总字数严格 ≤ 16 字；行长必须错落（3 行仅限长短长或短长短）；支持爆款封面“真源雷达量纲/标签 + 人格反差”（如 `共情97 / 内核超稳大女主 / 准点下班`、`边界99 / 清冷结界女王 / 回家泡脚` 等）；模式一建议包含生活化或真实雷达数据/量纲（如 `97`、`99`、`3天`、`5年` 等阿拉伯数字或百分比，严禁出现考试得分词如“低于60分”）。彻底废除“严禁出现测试术语与结果名”的自我阉割条款，用真源数据量纲与鲜明人格标签直击痛点。
   - **四元素共用**：具体名词 + 数字量纲 + 口语虚词 + 强烈反差。

2. **② 追问位（标题）**：
   - **核心机制**：1~2 秒阅读承接，制造蔡加尼克认知缺口——「等等，怎么会这样？然后呢？」。
   - **刚性规范**：单行 ≤ 20 字；取材七型（甲类取材于封面文字，乙类取材于封面之外的答案/他人反应/判词/时间）；严禁与封面简单复读。
   - **搜索权重**：标题承载品类与场景搜索流量，带可检索场景词（如 `原生家庭` / `长姐` / `讨好型人格`），封面则纯情绪。

3. **③ 赦免位（正文前 3 行 / 心理抱持性环境）**：
   - **核心机制**：折叠线前的情绪松绑与心理赦免。读者常年背负懂事、讨好、愧疚、责任等隐形道德枷锁，正文前 3 行必须以绝对包容的姿态接住钩子，卸下其内疚感（如“不是你能力强，是你习惯了逞强”）。
   - **刚性规范**：落地真实的生活实物道具或物理微动作；逻辑因果严丝合缝闭环承接封面/标题，严禁空对空说教，严禁直接跳到童年回忆。

4. **④ 悬念位（正文展开中段）**：
   - **核心机制**：真实生活切片的推进与沉浸。像闺蜜发微信语音吐槽，说到哪算哪，把生活真实痛点和生活状态铺开。
   - **刚性规范**：正文单行放宽至 ≤ 35 字，保护原声对话与引用完整性，绝不机械切碎；口语虚词自然扰动；展开五型轮转搭配；**严禁假大空宣誓升华**（正文结尾绝不许喊口号，杜绝“自己扛”、“成为自己的太阳”等自我感动式鸡汤），以生活微动作或自然测试转折收口。

5. **⑤ 暗号位（正文末行 / 互动接头）**：
   - **核心机制**：同频集结与真实收束。读者读到文末，需要一个能够对暗号、证明“原来我们是一路人”的部落标记或自然生活切片。
   - **规范参考**：支持自然反问（？/吗/怎么推）、对话自然定格、生活动作收束或暗号接头（暗号/集合/认领），多元化收尾；**绝对严禁**“敢不敢在评论区报个”、“快去测测看”、“评论区报一下你是哪一个”等机械营销套路词。

#### 爆款文案心理动线（非机械分段）与正面网感三要素：

为彻底打破脱离测评转化的单机自闭文案，正文必须建立完整的用户心理动线。**特别澄清：四阶段代表心理演进过程，绝非要求机械切分为 4 行独立句子！**
1. **① 认领与破题（痛点接头）**：快速建立第一人称认领映射，点明情境或测评背景（允许生活道具、对话、发疯梗或日常事件破题）；
2. **② 生活场景微动作（细节沉浸）**：严丝合缝接住封面/标题钩子，落地真实生活道具或物理微动作（如电脑防窥膜、工学椅、智能门锁、工牌反扣、AA账单、泡脚桶等），拒绝空洞形而上的抽象抒情；
3. **③ 报告转折赦免（情绪松绑）**：自然融入测评结果名、雷达指标或测试金句（如“坦诚98%”、“边界感99%”、“松弛感是你一生的铠甲与底气”），完成心理学免除内疚与课题分离，给读者卸下道德枷锁与沉重负担；
4. **④ 真实定格与互动收尾**：支持自然对话即收尾、生活动作定格（如回家开火泡脚）、或自然反问与部落接头，拒绝机械套路！

#### 【正面网感三要素：有梗 · 贴近用户 · 追热点】

告别机械死板的负向禁令，全面转向正面网感牵引：
1. **要有梗（Meme-Driven / 互联网嘴替）**：
   - 融入当代年轻人高频使用的网络黑话、幽默自嘲与发疯文学（如“精神离职”、“当代NPC觉醒”、“只要我没有道德，就没人能绑架我”、“脆皮打工人”、“水泥封心”、“放下助人情结，尊重他人命运”）。
   - 把梗作为情绪包袱轻巧抖落，充当读者的嘴替，引发秒懂共鸣与点赞认领。
2. **要贴近用户（Deep User Resonance）**：
   - 极度逼真地还原 20~30 岁女性群体的日常微动作与生活实况：外卖备注、微信置顶清理、合租换智能锁、聚餐秒AA、亲戚群免打扰、工牌反扣、工学椅、泡脚桶。
   - 拒绝宏大叙事与空泛抒情，全以具体物理微动作与心理活动切入。
3. **要追热点（Trend Hunting & 时代呼吸感）**：
   - 捕捉当下社会切片与文化情绪（反向整顿职场、断亲潮、短剧爽文风极速反转、降温寒潮抱团自救）。
   - 文案永远与当下的时代流行语同频呼吸，杜绝出土文物式的陈旧表达。

#### 正文篇幅灵活自如（建议三档）：

- **微短自嘲帖（约 30~50 字）**：绝不折叠，【1句微场景原声/槽点 ➔ 引用真金句 ➔ 1句微动作收束】，如试点卡片 1。
- **场景短帖（约 50~80 字）**：承接 1 个具体生活场域道具或物理微动作，展开真实原声对话与报告深度赦免，如试点卡片 2、3、4。
- **沉浸长帖（约 80~120 字）**：完整切片展开，多出的字数只用来堆叠“高清晰度生活动作”，严禁文艺抒情。

**两位都要给情绪价值，给的却不是同一种**：
- 封面给**被看见**——认同：「这就是我」
- 标题给**被说中**——反转：「原来是这样」

**两位都要有网感**，共用同一套四元素：

| # | 元素 | 换掉什么 |
|---|---|---|
| ① | **具体名词** | `饭` → `面包`；`一些人` → `七个亲戚` |
| ② | **数字** | `很多年` → `三十九年` |
| ③ | **口语虚词** | 融入动态热梗与口语虚词（如`好家伙` / `整乐了` / `服了` / `纯纯` / `直接` / `随手` / `反手` / `干脆`，批次内词汇广泛轮动，避免机械复读同一口癖，“合着”在全批内以不超过 1 篇为建议参考） |
| ④ | **反差** | 落差越大越有劲：`安排全家的我，发烧自己下单退烧药` |

**判据（写完当场检验）**：
- 封面——单独给人看 0.3 秒，他能不能说出一句「这说的是我」？
- 标题——读完，他有没有「等等，还有下文」的冲动？
- **标题读完只剩「哦，跟封面一样」→ 标题位白送，必改。**

**封面行错落**见自检清单 §7.3「封面行」条——`3/3/3`、`8/8/8` 是「一堵墙」。**3 行封面只认两种形状：长短长 / 短长短**（短≤4、长≥6）；分配表「封面节奏」列已轮转排定，落笔照抄，`refine-notes.js` 机检不通过不得落盘。

#### 标题取材七型

落笔前先答一句：**这条标题取材于哪？** 七型互斥且穷尽。

**甲类 · 取材于封面这句话本身**（同源，有字面重叠）

| 型 | 结构 | 例 |
|---|---|---|
| **甲1 截半** | 只取封面一半 + 补新料 | 封面`我妈昨天问我／这周想吃啥／我说都行` → `我妈昨天问我这周想吃啥，其实我想吃火锅` |
| **甲2 全接+补刀** | 封面全文 + 2~6 字反转 | `你对他真的有那么喜欢吗（不是）` |
| **甲3 续写** | 封面全文 + 逗号 + 往下说 | `我说都行，说了三十年` |

**乙类 · 取材于封面之外**（异源，与封面零共字）—— **本 SOP 的首选**

同屏两次出现零共字，标题位一点都不浪费。

| 型 | 取材处 | 例 |
|---|---|---|
| **乙1 问答** | 封面的答案 | 封面`为什么全家的事都找我？` → `因为我从来不关机` |
| **乙2 换人称** | 别人对我的反应 | 封面`去年我拉黑了七个亲戚` → `我妈说你怎么这么狠` |
| **乙3 判词** | 一句狠话 | 封面`站在楼下／把面包吃完／才上楼` → `那晚我二十六岁，没人问过` |
| **乙4 时间** | 一个具体年份或岁数 | 封面`我从来不秒回消息` → `十二岁那年，我就学会了不秒回` |

**配额（防模具化硬约束）**：

| 型 | 全批占比 |
|---|---|
| 甲2 全接+补刀 | **≤ 1/4**（最易套用，必须限量） |
| 甲1 / 甲3 | 各 ≤ 1/6 |
| **乙1~乙4 合计** | **≥ 1/3** |

**三层**：封面**开缺口** → 标题**给反转** → 正文首行**落新画面**（带来一个封面和标题都没有的细节 / 台词 / 动作；自检清单 §7.3「把封面、标题、正文首行三个并排看」条）。三层齐全的完整可复制卡片见 §一.6。

**爆款表达准则**：封面与标题支持【真源量纲/标签 + 人格反差】组合（如“共情97 / 内核超稳大女主 / 准点下班”、“边界99 / 清冷结界女王 / 回家泡脚”），用真实量化数字与高反差人格标签直击读者痛点；标题取材七型承接，制造蔡加尼克缺口。

判据一句话——**这句话，一个真人会在朋友圈或小红书点赞认领吗？**
「领导推来表那一刻，我测出了满级大女主」能让人一秒认领；「我爸说：你能力强，多担待（所以我活该）」能引发强烈共鸣。

优先采用「真源数据/量纲 + 人格反差标签」或「极度具体的狼狈场景与冒犯式荒谬反差」。

### 2. 【正文篇幅：不设字数硬指标，单行放宽至 ≤ 35 字】
**吸引用户是唯一判据**——该短就短，该长就长。不为凑字数补废话，也不为压字数砍掉好句子。
`30~80 字` 是参考区间，**不是硬指标**。**单行放宽至 ≤ 35 字**：保护真实原声对话与真金句引用的完整性，绝不机械强行切碎。

### 3. 【活人发疯网感】：见 §二 去同质化 —— 这是本 SOP 的核心。

### 4. 【蔡加尼克缺口（逼出 9.9 元付费冲动）】
放出前菜痛点，把结论与赞美**留在后面**，不要一次给完——但**这个「后面」是读者心里的后面，不是报告的后面**。
正文**零产品词**（词表见 03_合规审查与自检.md §7.2「产品口吻词」）。缺口的实现方式见 §2.2。

### 5. 【真实字段原生转化与零虚构】
正文所述的心理洞察，必须 100% 取自底层真实字段（**取哪几个字段见该测试的 `测试画像.md`**），转化为口语化大白话。**字段是素材库，不是引用源——写出来要像生活，不像报告。**

### 6. 【零编辑一键复制卡片】

用统一的 ` ```text ` 代码块，按 **`[封面]` + `[标题]` + 空行 + `正文` + 空行 + `标签`** 合并。代码块内**直接放成品文本**：

```text
[封面] 我爸说
       你能力强
       多担待
[标题] 我爸说：你能力强，多担待（所以我活该）

这句话我听了三十年。

所以上周同事说家里有事，
我扛到凌晨三点。

打车回家，
买了个面包。
站在楼下吃完才上楼。

#大女主觉醒 #原生家庭测试 #长姐如母 #懂事女孩 #情绪劳动
```

粘贴时：**`[封面]` 那几行贴进封面图排版，`[标题]` 那一行贴进标题栏，空行以下的正文逐行贴**。`[封面]` 的多行按行首对齐续写。

> **注意正文第三块前的那个 `所以`**：它不是装饰，是**因果桥**——删掉它，正文和标题之间就只剩「然后」。见 §2.7。

### 7. 【标签：金字塔五层】

**写 5 个**（有效区间 4~6）。少于 4：算法拿不到足够打标信息；多于 6：权重被稀释，且堆无关标签有降权风险。

| 位 | 类型 | 作用 | 例 |
|---|---|---|---|
| 1 | 自建品牌词（**全批恒定**） | 沉淀成资产 | 见该测试的 `测试画像.md` |
| 2 | 品类词（**全批恒定**） | 进搜索池 | 见该测试的 `测试画像.md` |
| 3 | 身份词 | 对号入座 | `#长姐如母` `#讨好型人格` |
| 4 | 情境词 | 生活场景 | `#懂事女孩` `#打工人日常` |
| 5 | 情绪词 | 共鸣收口 | `#情绪劳动` `#拒绝内耗` |

**三条纪律**：

1. **前 2 位全批一个字不改**——恒定才沉淀得下来。改一次，前面攒的权重全断；
2. **后 3 位必须从该卡真实内容里长出来**（取自 00_画像与档位.md §零.5 里该测试的关键词字段，或该篇正文实际写到的场景），**不许跨卡乱堆**。同一结果的四篇，后 3 位可以重复，但必须篇篇对得上自己的正文；
3. 标签区是读者**最后一次「被看见」**——正文读完还没走的人，在这里做身份确认的最后一击。

**澄清（否则执行时会误杀）**：**结果名可以出现在标签里**——`#六边形女王` 放在标签位**不算违规**，自检清单 §7.3 只管封面和标题。标签里带结果名，反而让你能被搜到。

### 8. 【纯色大字封面：可执行视觉规范】

**是什么**：一张纯色底 + 大字排版的竖版图（1080×1440），**没有插图、没有图标、没有边框、没有渐变**。它是双位里「封面」这一位的实现，不是设计作品——**唯一任务是让人在 0.3 秒内认领**（§一.1）。

**六条规格**（写封面文案时按这套规格写，不是排版时再补救）：

| 规格 | 口径 | 理由 |
|---|---|---|
| **底色** | 单一纯色；深底浅字或浅底深字；**同一批内不超过 2 种底色** | 纯色让字成为画面里唯一的重量；一卡一色整批就像拼贴 |
| **字号层级** | 判词 / 第一行字号**最大**；其余行同级或降一级，**不做三种以上层级** | 封面是「一眼抓形状」；层级越多，眼睛越不知道先看哪 |
| **行距** | 行距 ≈ **字号的 1.2~1.4 倍**，行与行**紧凑成块**、不散开 | 散开的行读起来是「几句话」，紧凑成块才是一张图 |
| **留白与安全区** | 四周留白 **≥ 画布短边的 8%**；文字块**居中或居中偏上**，不贴边、不压角 | 贴边的字在 feed 缩略图里会被裁掉 |
| **强调色落位** | **最多一行**用强调色（红 / 黄 / 高饱和），且**必须落在判词那一行** | 强调色是重音，只能有一个；多点强调等于没有强调 |
| **行数区间与行首对齐** | **2~4 行**（清单 §7.3「封面行」条）；多行时**行首对齐**（左对齐或居中皆可），不做参差缩进 | 行首错位是「排版」不是「错落」——错落靠**行长**做，不靠缩进做 |

**封面合格的三条**（都要过，口径见自检清单 §7.3）：

- **总字数一眼扫完、不挤满一行**，**硬顶 ≤ 16**——16 字是 feed 缩略图与文字配图生成的可读上限，超了易丢末行；
- **行间错落**：≥2 行时须有**一行 ≤4 字**、**一行 ≥6 字**（`3/3/3`、`8/8/8` 那种「一堵墙」不合格）；
- **3 行形状**：只能是 **长短长**（长/短/长）或 **短长短**（短/长/短）；禁止三行单调递增/递减或全中等；
- **行数 2~4**；另看「全批行数是否恒定、节奏是否只有一种」。

**三种常见失败**：

| 失败 | 长什么样 | 谁抓 |
|---|---|---|
| **一堵墙** | 行长全齐（`3/3/3`、`8/8/8`），眼睛没有落点 | 清单 §7.3「封面行」条 |
| **同款封面** | 全批 24 张卡都是同一个行数、同一种节奏 | 清单 §7.4「把封面放一起」条 |
| **封面塞了标题** | 把悬念整句搬上封面，追问空间被自己堵死 | §一.1 双位判据 + §7.3「三个并排看」条 |

## 二、去同质化 (Anti-Homogenization) —— 核心新增

> 病根：行宽锁死 + 必须引真实字段 + 全批同一情绪档，几条同时成立时解空间会被压成一个形状。
> 五个 Agent 独立作业也会写出同一副骨架。**下面各条是为了把解空间重新撑开。**

### 2.1 起手式八型（正文首句多元化与防同构破题）

**打破“测出...”起手复读机（批次熔断硬约束）**：
标题是悬念，首句就是落点。正文首句必须接住标题并自然推进叙事。
**严禁每篇开头机械复读“测出...”！单批 24 篇中以“测出”作为首行开头的卡片严格不得超过 2 篇**。
测试闭环信号（测出/报告/指数/自测/测评）可自然置于第 2 行或第 3 行转折处。起手式必须充分轮换四大方向、八大型态：

| 起手方向 | 型 | 示例首句 (自然真人切入，拒绝千篇一律) |
|---|---|---|
| **方向 1：真实生活场景/微动作直入 (首选)** | A 场景直入 | 反手把电脑防窥膜贴上了。 |
| | F 道具数字型 | 全勤奖八百全当精神抚恤金了。 |
| | H 动作陈述型 | 下班耳机没歌我也一直戴着。 |
| **方向 2：日常对话/旁人反应直入** | B 对话直入 | 我妈问我这孩子怎么变了， |
| | C 判决直入 | 懂事的人千万别看这条报告。 |
| **方向 3：心理自嘲/发疯嘴替直入** | G 反常识梗 | 只要我没有道德，就没人能绑架我。 |
| | E 疑问自答 | 为什么二十八岁我才学会课题分离？ |
| **方向 4：测出破题直入 (单批 ≤ 2 篇)** | D 结果前置 | 测出六边形女王，翻译过来就是免费保姆。 |

### 2.2 缺口节奏（缺口由内容承担）

**正文零产品口吻词**（严格禁止`第X页`、`前半段`、`后半截`、`翻到最后`、`话术库`等机械产品词；解禁“报告/测出/自测”作为正文转折与赦免引用词）。一旦出现机械产品词，口音当场从「人在说话」变成「产品在说话」——既是口音断裂，也是风控负资产。

缺口改由**内容**承担，三型轮换：

> ⚠️ **铁律一：收尾禁止假大空宣誓，唠家常聊完即停（微动作留白降为可选）**
> 绝对严禁使用「风雪自己扛」、「世界晴空万里」、「空气如此清新」、「我就是自己的庇护所」、「我绝不回头」、「今年我先救自己」等鸡汤升华、假装顿悟的宣誓句收尾。这类句子是典型的 AI 拟人化自我感动，读者一读就出戏。
> **唠家常收尾准则**：
> 1. **聊完就停**：正文像朋友发帖聊天，说到哪算哪，说完就停。可以直接停在测试转折句本身，例如停在“那里才适合我”或“我先给自己买件厚的”，不需要硬加任何多余句子。钩子口号只许在封面 / 标题，正文结尾绝对不许喊口号，这条以 03 和 refine-notes.js 的 SLOGAN_END_PATTERN 为准。
> 2. **微动作留白为可选**：只有当微动作是前面日常情节的自然延续时才可顺手带上一句（如自然停在“站在楼下吃完才上楼”）；**严禁为了凑作文结构硬搞首尾呼应 callback**（例如开头提了暖宝宝，结尾非要硬扯被子）。
>
> ⚠️ **铁律二：严禁机械问卷式促互动，自然转折到测试结果或共鸣叹息**
> 绝对严禁在文末硬甩「那你呢是不是也这样」、「评论区报一下你是哪一个」、「有没有人跟我一样想看看人数」等公屏调查问答。
> 优先采用自然测试结果转折（“难怪我每年冬天都难受，我的精神老家在海南，那里才适合我”）或情绪轻叹（“有些小心翼翼，真的让人心疼”），顺承人设，让共鸣自然发酵。

| 型 | 做法 | 例 |
|---|---|---|
| **测试转折收束（首选）** | 唠家常说到这，自然得出归属感或性格结论，聊完即停 | `难怪我每年冬天都难受` `我的精神老家在海南` `那里才适合我` |
| **短句情绪轻叹** | 三五个字砸下来，不解释，或情绪轻叹收口 | `行吧，我认了。` / `有些小心翼翼，真的让人心疼。` |
| **自然动作留白（可选）** | 前文动作的自然收尾，非硬凑首尾呼应 | `买了个面包。` `站在楼下吃完才上楼。` |
| **人物反应收尾** | 旁人的一句话或一个沉默，把问题弹回读者 | `她沉默了一会儿，` `说她不行。` |

比「报告后半截」强在：**逼读者内省，而不是提示读者「这产品还有内容」**。显式转化 100% 交给 04_分发与排期.md §五 第二道（评论区首条置顶）。

### 2.3 短行与节奏（长短交错与断行破壁）

**短行（≤ 6 字）是节奏的物理来源**——一条正文里要让眼睛撞上几次短行。短行在手机上就是呼吸停顿。

- **断行破壁约束**：严禁全篇行长呈均匀对称的“一堵墙”（例如连续 5 行都是 10~12 字）；
- **短行停顿硬要求（必须带动作）**：正文全文必须包含至少 **2 处 ≤6 字的短行停顿**，且**必须是有主语、有具体动作或动作定格的句子**（如 `合上电脑。`、`直接拉黑。`、`没搭理他。`、`打卡下班。`、`拎包就走。`）。
- **❌ 绝对禁止孤立凑数词独占一行**：严禁把 `真的。`、`算了。`、`索性算了。`、`没回头。`、`醒了。`、`关灯。` 单独占一行凑数！口语词与短句必须嵌在有主语、有动作的句子里。

```
打卡下班。        ← 4字短行（有动作，制造节奏）
没搭理他。        ← 4字短行（有主语/动作，自然停顿）
```

### 2.4 【微信闺蜜吐槽体】真实网感与语气（去作文感、去小说感）

真正的爆款小红书真人文案，本质是**发给闺蜜的微信语音转文字**——大白话、真吐槽、干脆利落。

| 风格形态 | 致命病灶 | 典型反面句式 | 判定 |
|---|---|---|---|
| **中学生作文** | 乖巧听话、好学生思想汇报、总结中心思想、机械套“其实…反倒…”公式 | “我合上电脑。其实别人的焦虑与我无关，我从不替别人背情绪，反倒一身轻松。晚上早点打卡回家。” | ❌ 假大空、像交作业 |
| **文艺小说** | 矫情做作、堆砌文学形容词、刻意特写镜头与伤痕渲染 | “安全出口的幽暗绿光照着键盘，指甲深深抠进塑料缝，胃部一阵阵抽搐抽痛。” | ❌ 油腻、像知青小说 |
| **小红书真人嘴替** | **大白话、日常原声、生活动作真、吐一口浊气收尾** | “新贴了防窥膜。同事探头探脑问我总结写完没。我直接合上笔记本：‘还没动笔呢。’戴上耳机打卡走人。天大的事周一再说。” | ✅ **爆款真人人声** |

#### 真人人声的三大要素（正向牵引）：
1. **事实+动作（无华丽修辞）**：说清几点几分、做了什么具体动作，不写空洞感想；
2. **日常对话原声（带出人间烟火）**：自然嵌入 1~2 句极短对话原话（如“还没动笔呢”、“大伯您退休金涨了吗”、“顺手帮我打印一下呗”）；
3. **聊完即停（吐一口浊气收尾）**：收在自然吐槽或行动转折上（如“天大的事周一再说”、“图啥呢到底”、“谁的事情谁自己做吧”），绝不上价值、绝不总结大道理。

### 2.5 去指纹

**同一测试内，任意两张卡片的任意一行，不得逐字相同。** 这条由「读完全批，找我意识到自己重复了哪句」来兜（自检清单 §7.4）——整句重复是整批最容易犯、自己最看不见的毛病，有意去找，找到就换一种说法。

### 2.6 双位不得互相白送

**病一 · 复读**：封面与标题写成同一句话 → feed 里同屏出现两次，点进去正文首行第三次。用户看到的全是**零新增**，蔡加尼克缺口不推进，手指立刻滑走。

**病二 · 伪补刀（更隐蔽）**：标题看着做了错位，实则补刀里每一个字封面都有——**抹掉括号，标题就剩一句复述**。
封面 `我妈昨天问我／这周想吃啥／我说都行` ＋ 标题 `（我说都行）` → `我`/`说`/`都`/`行` 全在封面 → ❌

**解**：落笔前先答一句「这条标题**取材于哪**」，按 §一.1 的**取材七型**选一个型。**同批不得全部落在同一型**。

### 2.7 正文三动作与展开五型

**依据**：《南方公园》创作者 Trey Parker 与 Matt Stone 的编剧铁律——场景之间若只能填「**然后**」，那场戏就是废戏，必须能填「**但是**」或「**因此**」。Robert McKee《故事》说的是同一件事：一个不转折的场景，根本不算场景。

> 🌟 **【唠家常，不写作文】执行规约 (Lao-Jia-Chang)**
> - **聊完即停**：像微信真实发帖与朋友唠家常，说到哪算哪，聊完就停。杜绝起承转合、首尾呼应与刻意 callback。
> - **转折动作收束**：正文直接收束在测试转折句或具体行动上（如停在“那里才适合我”或“我先给自己买件厚的”）。微动作收尾仅限前面动作的自然延伸，不硬凑呼应。
> - **钩子口号边界**：强情绪破局口号仅在封面与标题使用；正文结尾严禁喊口号。
> - **同频同气**：封面、标题、正文同一个人、同一种情绪脉络吐槽，不中途转为文艺散文，不列虚浮日程清单。
> - **前 3 行接住钩子**：封面/标题承诺什么槽点，正文前 3 行必须立刻用生活实物、动作与体感承接，禁跳回忆。
> - **主语因果动作连贯**：每行具备主语+时间+具体动作因果；拦截无主语孤立天气报单句（如“风也太凶了”）。
>
> 🌟 **双层机审分工保护**：
> - **封面/标题位**：专审钩子强度、0 词表、长短错落与字数（封面 2~4 行 ≤16 字，标题 ≤20 字）；放行高点击口号，不以生活道具规则误伤；
> - **正文位**：专审主语因果、前 3 行生活情节道具、口语扰动、短行节奏与末行收束。

#### 三动作（唠家常推进流程）

| 动作 | 做什么 | 失败形态 |
|---|---|---|
| **① 接住标题与逻辑闭环** | 正文前 3 行必须有对应具体情节展开（带出具体生活实物/情节，如暖宝宝、羽绒服、大骨汤、工牌等），承接封面标题承诺 | 标题写了降温正文全在聊形而上；或无主语无实物纯抽象议论 |
| **② 展开吐槽与转折** | 同一口气唠家常，顺着前因后果往下说，后半段通过自然因果桥（如“难怪我每年冬天都难受”）转到测试结果（“我的精神老家在海南，那里才适合我”） | 变回文青排比句；机械罗列日程生活清单（花衬衫/冲浪板等） |
| **③ 自然收束（聊完即停）** | 说到哪算哪，聊完就停。可直接停在测试转折句本身；微动作收尾仅作为**可选**（严禁硬凑首尾呼应 callback） | 硬加一句动作呼应开头；搞文青鸡汤宣誓（“风雪自己扛/成为自己的太阳”） |

**唯一豁免**：「清单轰炸」型不强制因果桥——并列证据本身就是展开。**代价是清单的第一条必须能对上标题**。

**小红书折叠线**：正文**前 3 行在 feed 里直接可见**。这 3 行不是铺垫，是**第二次拦截**——封面拦一次、标题拦一次、正文前 3 行拦第三次。

#### 展开五型

| 型 | 结构 | 例 |
|---|---|---|
| **1 一事到底** | 一个场景走完，有过程有定格 | `同事说家里有事，／我扛到凌晨三点。／打车回家买个面包。／站在楼下吃完才上楼。` |
| **2 清单轰炸** | 3 条短证据并列，节奏快 | `弟弟工作问我，／爸妈体检问我，／亲戚吵架也问我。` |
| **3 对话实录** | 引一句真对话，然后停顿 | `"你生日是几号？"／这句话我等了三年。` |
| **4 判词连打** | 短句金句，一句一行 | `笑才累。／以前谁惹我我都笑。` |
| **5 倒带** | 先给结果，再回述过程 | `是直接删的。／有一个打来骂我。／我说好的。` |

**分配**：一个模式**主**一个型，**每模式允许 ≤2 张换型**——防止同模式的 6 张卡全成一个模具。各模式的主型见 02_四模式.md §三。

**换型多样性约束（硬规约）**：同一个模式组里的 ≤2 张换型必须互不相同，且全批换型所用型覆盖 ≥3 种。
- **避免单型扎堆**：`判词连打` 虽易写但不得通批顶格滥用，必须与 `一事到底`、`清单轰炸`、`对话实录`、`倒带` 轮转搭配。
- **自动化保证**：`make-plan.js` 自动保证「同组内单型 ≤1 张」与「全批换型种类 ≥3」，人工排表依同等口径执行。
