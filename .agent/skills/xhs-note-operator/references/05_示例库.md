## 🌟 黄金基准标杆 · 【唠家常，不写作文】双正例对照

> **大哥定稿正例（全员基准对照）**：像微信发帖唠家常，说到哪算哪，聊完就停。同频吐槽、前 3 行接住钩子、因果动作连贯推进、转折动作收束、绝不起承转合 callback。

### 标杆一 · 寒潮降温 · 性格城市匹配（三亚 · 精神老家）
```text
[封面] 寒潮降温第一天
       手冻僵
       这也叫暖冬？
[标题] 说好的暖冬呢，我手都冻僵了

说好的暖冬呢
我早上贴的暖宝宝
贴歪了，手到现在还凉
穿了三层羽绒服
出门风一吹就透
这叫暖冬？
其实难怪我每年冬天都难受
我的精神老家真的在海南
那里才适合我

#城市人格 #城市匹配测试 #精神老家 #降温吐槽 #三亚
```

### 标杆二 · 寒潮降温 · 大女主觉醒测试（不被驯化的破茧大女主 · 旧棉袄童年）
```text
[封面] 冻死我了
       说好的暖冬去哪了
       受够了
[标题] 小时候那件旧棉袄，我到现在还记得

我今天出门被冷风吹透
手套戴了两层
手真的到现在还冰凉
我小时候总穿姐姐的旧棉袄
袖口磨得发亮
我放学跑回家手冻得写不了字
家里其实没人问我冷不冷
难怪我现在先顾自己
我先给自己买件厚的

#大女主觉醒 #原生家庭测试 #破茧大女主 #寒潮降温 #童年经历
```

### 拆解为什么这是最高标准的「唠家常」：
1. **同一个人、同一口气的吐槽**：标题吐槽，正文一开口就是同一个人在同一情绪里继续吐槽，不突然变散文排比。
2. **逻辑闭环前 3 行接住钩子**：标题承诺了什么（如暖冬冻僵/手套冰凉），前 3 行立即给出具体生活道具与体感，不空对空，不跳过今天直接跳童年回忆。
3. **因果与主语连贯推进**：每行都有主语+时间+真实生活动作（如“放学跑回家手冻得写不了字”），杜绝“风也太凶了”等孤立天气报碎片。
4. **自然转折到测试结果**：通过因果桥（如“难怪我每年冬天都难受”、“难怪我现在先顾自己”）顺畅连接到测试归属或觉醒意识，不堆砌虚浮日程清单。
5. **聊完即停，停在转折动作句**：停在“那里才适合我”或“我先给自己买件厚的”，交代完毕直接收束。**绝对不喊口号，不硬凑微动作 callback**。

## 卡一 · 模式一【数字标尺与阶梯判词流】（主展开型：**清单轰炸**）

```text
[封面] 情感淡漠87
       反叛93
       我认了
[标题] 血缘这件事，早就不算数

所以过年我不回去。

家族群我退了，
拜年电话我接，
只接三分钟。

我妈说我冷血。

我说是的。

#大女主觉醒 #原生家庭测试 #断亲 #情感隔离 #搞钱
```
`取材型=乙3判词｜起手=H陈述直入｜展开=清单轰炸｜档=冷笑｜缺口=短句收束`

> **清单轰炸**：家族群 / 拜年电话 是**并列短证据**，不是叙述。
> **豁免条款**：清单轰炸不强制因果桥，**代价是第一条必须能对上标题**——这里「家族群」对上了「血缘」。
> **取材型**：乙3 判词，标题与封面**零共字**（`血缘这件事早就不算数` 全部字都不在封面），所以标题位一点没浪费。
> `情感淡漠87 / 反叛93` 取自该结果的真实字段；`我认了` 是口音，不是数据。

## 卡二 · 模式二【现实大反差 + 极短自嘲流】（主展开型：**倒带**）

```text
[封面] 拉黑七个亲戚
       没吵架
       也没解释
[标题] 我妈问我怎么下得去手

所以我给她演示了一遍。

拉黑不用力气，
点两下就完了。

有一个打来骂我，
我说好的。

我妈哭了很久。

她说她这辈子没做过亏心事。

#大女主觉醒 #原生家庭测试 #断亲 #原生家庭 #搞钱
```
`取材型=乙2换人称｜起手=D结果前置｜展开=倒带｜档=解气｜缺口=人物反应`

> **倒带**：先把「结果」摆出来（`所以…演示了一遍`），再回头补过程（点两下 → 有人骂我 → 我妈哭）。
> **反差**：封面是「没吵架 / 也没解释」的体面，正文是「有一个打来骂我 / 我说好的」的冷。
> **缺口**：收在旁人一句话上（`她说她这辈子没做过亏心事。`），不下判词，把问题弹回读者。
> **取材型**：乙2 换人称，标题写的是**我妈的反应**，不是我的动作。

## 卡三 · 模式三【生活痛点 + 真实自白流】（主展开型：**一事到底**）

```text
[封面] 我爸问我
       养你这么大容易吗
       不容易
[标题] 养你这么大，账早算清了

所以那天他问完，我没吭声。

回屋拿了个本子，
把他这些年花在我身上的钱，
一条一条列出来。

列到第三页，
手有点抖。

算完我拍照发给他。

他没回。

第二天他转了两千块过来。
我退回去了。

#大女主觉醒 #原生家庭测试 #情感隔离 #原生家庭 #自我救赎
```
`取材型=甲1截半｜起手=A场景直入｜展开=一事到底｜档=破防｜缺口=短句收束`

> **一事到底**：一个场景走完才有定格（列账 → 手抖 → 发出 → 没回 → 转账 → 退回），不是东一句西一句。
> **取材型**：甲1 截半——取了封面第 2 行「养你这么大」，补的「**账早算清了**」**六个字一个都不在封面里**，所以是真补刀，不是伪补刀。
> 对照：封面写「不容易」是**顺着**读者预期，标题写「账早算清了」是**反着**说——这才是标题该干的反转。

## 卡四 · 模式四【生活怪癖暗号 + 同频集结流】（主展开型：**对话实录**）

```text
[封面] 劝人原谅的
       可以划走
       恨和原谅都不要
[标题] 二十五岁那年，世界终于安静了

安静下来之后，
我才发现是我自己关的。

表姐打来电话，
聊了四十分钟家常。

挂之前她问：
"你妈生日你回不回去？"

我说不回。

她那边停了三秒。

然后说：
"行，我知道了。"

到现在我也没问她，
那三秒在想什么。

#大女主觉醒 #原生家庭测试 #断亲 #边界感 #搞钱
```
`取材型=乙4时间｜起手=G反常识｜展开=对话实录｜档=认命｜缺口=未答疑问`

> **对话实录**：怪癖不在自我介绍里露，在**一句真对话**里露（表姐那句问话 + 那句「行，我知道了」）。
> **停顿**：`她那边停了三秒。` 是对话实录的关键动作——**停顿本身就是内容**。
> **反常识起手**：标题说「世界终于安静了」，正文第一句把它推翻——「是我自己关的」。
> **取材型**：乙4 时间，标题给的是一个**具体岁数**，与封面零共字。
> **注意标签**：结果名 `破茧大女主` **没有**出现在封面或标题（自检清单 §7.3「封面与标题里有没有结果名」条），四张卡都没有。

## 卡五 · 整活与非整活对照（同结果 · 同模式 · 同档）

> **触发时机**：准备给**可整活档**（本测试 = 解气 / 冷笑，归属表见 [`00_画像与档位.md`](00_画像与档位.md) §2.4.1）写卡时读。
> **对照对象**：下面是**同一结果（r6 不被驯化的破茧大女主）、同一模式（模式二 现实大反差）、同一档（解气）**的两版。非整活版就是前面的**卡二**，不重复贴。

**卡五（整活版 · 解气档 · `｜整活=✓`）**

```text
[封面] 亲戚问我恨不恨
       我说
       排期很满
[标题] 我不想恨，我投产比不高

所以她真问了我一次。

我把账本调出来，
一条条念给她听：

二姨借的三万，
三舅那场婚礼，
我爸三十年的账。

她听完说，
一家人算这么细，
多伤感情。

我说对啊。
所以我没算，
直接划掉了。

#大女主觉醒 #原生家庭测试 #断亲 #边界感 #情绪劳动
```
`取材型=乙3判词｜起手=A场景直入｜展开=倒带｜档=解气｜缺口=人物反应｜整活=✓`

**两版差在哪（这张表就是整活的判据）**：

| 维度 | 卡二（非整活） | 卡五（整活） |
|---|---|---|
| 档 | 解气 | 解气（**同档**，整活不换档） |
| 落点 | 动作本身（`点两下就完了`） | 态度的**荒谬量纲**（恨也要讲投产比 / 排期） |
| 笑点位置 | 无，冷叙述走完 | 落在**作者自己**（把自己的情绪当成项目排期） |
| 标注 | 不写 `整活=` | 末尾追加 `｜整活=✓` |

**真实字段来源**（不得照抄字段原文，只取内核再转写）：

- r6 `acquiredTrait`「寡情果决的逆行者」+ `subtitle`「破茧叛逆的防卫剧本」→ 整活版的「果决」被夸张成**算了账再划掉**；
- r6 `quote`「凡是不能打败我的，终将成为我杀出重围的垫脚石」→ 整活版把「杀出重围」这层**战斗叙事**换成「投产比 / 排期」这层**商业叙事**，荒谬感即由此而来；
- 句子与字段**零逐字重合**——整活靠重写，不靠引原句。

**边界（写之前先看这条）**：

- 整活**只落在可整活档**。本测试若给「破防 / 认命」标 `整活=✓`，自检清单 §7.3 的低气压条直接判不合规（不是灰区）；
- 整活**不豁免红线**（[`03_合规审查与自检.md`](03_合规审查与自检.md) §四）：笑点落在作者自己或荒谬的关系模式上，不落在用户的痛处上；
- **不要每张都整活**。齐齐整活只是把「零 emoji」式的整齐腔换了一种排面——整活是那条轴的**少数派**，一档里有一两张就够。
