> 本册为小红书发帖合规、红线词库、网感审查及自检清单的**全系统唯一真源**。
> 整合原 `xhs-note-copywriter` 的红线三分区与交付清单，以及 `xhs-note-analyzer` 的全域敏感词库与去爹味、去AI感审查法则。

## 一、擦边红线三分区 (Controversy Zones)

**医疗为绝对红线，其余可适度试探。**

| 分区 | 内容 | 处理原则 |
|---|---|---|
| ✅ **放行** | 夸张、自嘲、阴阳、网络热梗与发疯文学（如`精神离职` / `NPC觉醒` / `只要我没有道德` / `脆皮打工人` / `水泥封心` / `免费保姆` / `善良没编制`） | 直接写，这是「野」和真人网感的主要来源；笑点落在作者自身或荒谬模式上 |
| ⚠️ **控比例** | 攻击性比喻，把父母 / 领导 / 亲戚设为靶子 | 可写，但同一测试批次内不超过三成 |
| ❌ **不碰** | 脏话、性暗示、身体羞辱、医疗词（`确诊` / `解药` / `抑郁` / `治疗` / `处方` / `症状` / `药物` / `疗效` / `挂号` / `心理疾病`） | 触发平台限流，且与情绪价值目标相悖 |

- 日常叙述词（`生病` / `体检` / `焦虑`）在非医疗主张语境下可用。
- **整活腔不豁免本表**：整活（自嘲玩梗 / 可转发幽默 / 阴阳式身份讽刺）只是表达姿态，**脏话 / 性暗示 / 身体羞辱 / 医疗词仍为 0**，且**笑点只许落在作者自己或荒谬的关系模式上**，不许拿用户或结果本人的痛处当笑点。
- **边界说明**：本表管的是小红书 feed 里的发帖文案与封面。千帆商图不直接受本表约束，但文案与商图必须严防医疗词串味。

## 四、爆款网感审查法则 (Anti-Ad & Anti-AI)

### 1. 逻辑闭环（严打标题党割裂，前 3 行必须接住封面 / 标题钩子）
- **钩子承诺什么，前 3 行必须兑现什么**：标题 / 封面承诺了什么具体事件、槽点或情绪冲突（如“终于离职了”、“拉黑了所有人”、“说好的暖冬去哪了”、“冻死我了 / 受够了”），正文**前 3 行必须立刻用具体生活动作、物理体感交代承接**（如提到了暖冬/冻死，前 3 行必须先写今天出门怎么冷、被风吹透、戴两层手套手依然冰凉等），不许空对空抒情。
- **严禁跳过钩子直接转进**：严禁封面/标题还在吐槽今天的寒潮，正文首行就直接跳到童年或回忆，造成钩子悬空割裂；先在今天接住钩子，再自然因果转折引出下文。
- 严禁标题制造巨大悬念，正文却全篇空洞议论或生硬推销测试。

### 2. 去爹味审查（第二人称转第一人称）
- **❌ 爹味说教体（严禁）**：“你是不是经常觉得下班很累？这叫情绪内耗，快来做个测试诊断一下！”（防御心理极高，像发传单）
- **✅ 第一人称日记体（推荐）**：“上个月我差点崩溃，下班连回微信的力气都没有，后来发现这叫低电量内耗...顺手把自测题放最后了，同款姐妹抱团取暖。”（真人叙事，分享姿态）

### 3. 【微信闺蜜吐槽体】人味硬门禁 (WeChat-Voice & Anti-AI)
- **微信发帖，聊完就停**：正文是正常发帖唠家常，像给闺蜜发微信语音转文字，大白话，说到哪算哪，聊完即停。**不许起承转合，不许首尾呼应，不许 callback**。
- **两拒（硬边界）**：
  - **❌ 拒【中学生作文】**：严禁好学生思想汇报、总结中心思想、机械套“其实…反倒…”公式（如“其实我不占别人便宜，反倒一身轻松”）；
  - **❌ 拒【文艺小说】**：严禁矫情做作、堆砌文学形容词、刻意特写镜头与伤痕渲染（如“幽暗的绿光照在键盘上”、“指甲掐进肉里”、“胃部一阵阵抽搐”）。
- **三要素（正向牵引）**：
  - **① 事实+动作**：说清具体事情和动作，不写空洞感想；
  - **② 日常原声对话**：自然嵌入 1~2 句极短对话原话（如“还没动笔呢”、“大伯您退休金涨了吗”、“顺手帮我打印一下呗”）；
  - **③ 吐一口浊气收尾**：收在自然吐槽或行动转折上（如“天大的事周一再说”、“图啥呢到底”、“谁的事情谁自己做吧”），不升华、不喊口号。
- **严禁为了凑结构硬加收尾（微动作收尾为可选）**：反面例子——开头提了暖宝宝，结尾非要加一句“我把被子又往上拉了拉”来呼应——彻底删掉这种写法！微动作收尾仅在它是前面动作的自然延伸时才可用。
- **允许直接停在测试转折句本身**：例如停在“那里才适合我”，就完了，不用再收尾。**钩子口号只许在封面 / 标题，正文结尾绝对不许喊口号**。正文不许出现“自己扛”、“破茧了往前走不回头”、“过好自己的日子比啥都强”等口号句。
- **同一个人、同一口气的吐槽**：封面、标题、正文必须是同一个人、同一口气的真实吐槽。
- **每行要有主语 / 时间 / 因果动作连贯（严禁碎片行）**：
  - 每行都要有主语 + 时间 + 动作或因果连贯，不许堆砌没有主语的形容词碎片；
  - **严禁天气报式单句与孤立碎片**：像“风也太凶了”、“我冻透了”、“冷死了”这种无动作、无因果的孤立天气感叹句一律禁止；
  - **严禁孤立凑数短行**：严禁“真的。”、“算了。”、“索性算了。”、“醒了。”等无主语、无动作的孤立凑数词单独占一行。
- **前 3 行生活情节与道具**：正文前 3 行必须包含日常生活实物或物理情节（暖宝宝、羽绒服、大骨汤、自提柜、工牌、工作机等），严禁通篇形而上的空洞议论。
- **短行断行破壁**：正文全文必须包含至少 2 处 ≤6 字的短行停顿（短行必须嵌在有主语、有具体动作的句子里），严禁全篇行长均匀对称（一堵墙）。

### 4. 道具前后交代闭环（严禁正文后半段突然天降新道具）
- **实物道具必须提前交代**：正文里不许出现前面没交代过的道具。凡是正文里第一次出现的实物（伞、雨、车等），**前面 3 行或标题 / 封面里必须出现过**，否则判不合格重写。
- **反面典型**：寒衣节内耗那篇，正文前 8 行通篇没雨没伞，最后一句突然写“我都忘了能跟谁借伞”——属于典型的后半段突兀天降道具，强行文艺出戏。

### 5. 双层机审分工架构
- **封面 / 标题层**：只查钩子强度、0 词表、字数规范（行数 2~4 行、短≤4、长≥6、总字数≤16；标题≤20字）。**强情绪破局口号仅限在封面与标题使用**（如“谁让我不痛快我就当场掀桌子……过好自己的日子，比啥都强”、“二十岁我悟出了一个硬道理。职场勾心斗角全当耳风”、“不回应就是不失联。是把命还给自己”等高 CTR 钩子），**绝对严禁以“无生活场景道具”为由误判封面标题**！正文结尾严禁喊口号。
- **正文层**：查主语、时间、因果、前 3 行具体情节、口语虚词扰动、短行节奏与逻辑闭环。正文末行严禁口号升华，只能停在测试转折句本身。
- **元数据与标签真源核查**：机检强制核对 `result_name`（结果名）与品牌词、品类词，必须 100% 对齐 `测试画像.md` 与 `lib/*-data.ts`，绝不允许只数标签够 5 个就放过，绝不允许编造结果名。
- **历史回溯准则**：对历史笔记扫描时，分开上报【封面/标题不合格数】与【正文不合格数】。正文不合格系按最新人味新规回溯，只作记录，严禁批量改写或删除历史文件！

## 五、五条硬规格与排版标准 (Physical Specs)

> **规格 ≠ 配额**：规格是物理红线，不可妥协。自动化修整统一使用 `node "scripts/refine-notes.js" --file <path> --fix`。

1. **正文单行 ≤ 15 字**（硬规格，手机阅读不折行）：按意群智能回车断行；包含至少 2 处 ≤6 字短行停顿；
2. **封面 2~4 行，字数合计 ≤ 16**：多行时**须有一行 ≤ 4 字、一行 ≥ 6 字**；**3 行必须落成「长短长」或「短长短」**（`refine-notes.js` 机检），通过行长错落打破“一堵墙”视觉疲劳；
3. **标题一行、≤ 20 字**：一眼扫完，不挤满两行；
4. **标签恰好 5 个且真源对齐**：前 2 位（品牌词 / 品类词）全批字字相同且严格对照测试画像 `测试画像.md`（如城市测试品牌词为 `#城市人格`、品类词为 `#城市匹配测试`；大女主为 `#大女主觉醒`、`#原生家庭测试`），机检不许只数 5 个就放过；
5. **钩子原句 vs 末行字数**：末行若为分配表指定的互动钩子，**以钩子原句为准**（整句照抄，不许改写、不许砍成共用前缀）；无钩子时遵从目标末行字数。
6. **口语扰动度**：每篇正文命中 ≥2 种官方口语虚词（`ORAL_PERTURBATION_WORDS`）。

### 5.1 五位一体全链路标准 (The Five-in-One Model)

| 阶段位 | 载体位置 | 心理机制与用户动作 | 刚性准则与要求 | 失败形态 |
|---|---|---|---|---|
| **① 认领位** | 封面图文 (0.3秒) | 一眼认领「这说的是我」，直击痛点 | 2~4行、总字数≤16、长短错落（长短长/短长短）；解禁为爆款封面【测试数据/量纲 + 人格反差标签】（如 `测出大女主92% / 水泥封心`）；**强检包含生活化/测试数据量纲**（模式一必须含阿拉伯数字或百分比，严禁考试得分词） | 空洞口号/字数超标/无数据量纲 |
| **② 追问位** | 笔记标题 (1~2秒) | 读完追问「然后呢？原来是这样」，抓搜索流量 | 单行≤20字；取材七型（甲1~3、乙1~4），严禁封面文字直球复读 | 与封面一模一样/标题位白送 |
| **③ 赦免位** | 正文首段/前3行 | 情感赦免与松绑，卸下懂事愧疚与道德枷锁 | 前3行必须接住封面/标题钩子并融入测试闭环（允许生活道具、对话、发疯梗或测出破题，严禁全量机械复读“测出”起手）；落地生活实物微动作；赋予“不是你的错/善良没编制”的心理赦免感 | 空泛说教/爹味指责/钩子割裂悬空/全员同构破题 |
| **④ 悬念位** | 正文展开中段 | 真实生活切片推展，留白未尽之言 | 展开五型轮转；强制实物微动作；**引用测试报告金句转折与心理学赦免**；**严禁文青式宣誓升华**（如“晴空万里/自己扛”） | AI式顿悟升华/无道具抽象抒情/无报告转折 |
| **⑤ 暗号位** | 正文末行 (标签前) | 同频集结暗号，促使读者对暗号接头 | 字数符合分配表目标末行；**强制包含互动疑问（？/吗）或对暗号指令（几级/对暗号/暗号/留个/扣）**，点燃评论区；**严禁机械营销套路与单机自闭收尾**（“下班了/真清爽/屋里安静”） | 机械式营销逼问/无暗号留白/单机自闭 |

### 5.2 批次反同构熔断与正面网感自检清单

机检与自审必须从微观单词拓展至整批（如 24 篇）宏观健康度把控：
1. **反同构词频硬顶**：单批 24 篇中文案口语虚词 `合着` 全篇累计不得超过 **1 篇**；
2. **首行起手多样性**：单批 24 篇中文案正文首行以 `测出...` 机械破题的卡片累计不得超过 **2 篇**，严禁连续两张卡片采用同构句式开头；
3. **末行暗号多样性**：互动疑问句式充分轮转，严禁全量复读相同暗号句，穿插“暗号对一下”、“留个同款”、“扣1接头”、“你呢？”等；
4. **热梗覆盖丰富度**：单批文案中使用的口语虚词与网络热梗种类不得少于 **6 种**（从发疯文学、职场整顿、短剧反转、生活实录四大频道中调配）；
5. **A档结构解脱**：A 档微短帖（15~35 字）执行【1句微场景自嘲/嘴替 ➔ 甩锅测试 ➔ 1句顺嘴反问】极简流，2~3 行连贯写完，绝不强塞四段。

## 六、交付前自检清单 (Pre-Delivery Checklist)

### 6.1 两个固定项
- [ ] **红线词表写前过一遍**：动笔前扫视本册 §二 三个 0 词表与 §三 平替表。
- [ ] **换一双眼睛**：交付前由独立执行体或换位视角读一遍，只问一句：“哪一篇最假？”

### 6.2 逐卡看（五位一体与物理规格逐项过）
- [ ] **① 认领位（封面）**：2~4 行，合计 ≤ 16 字；有一行 ≤4 字、一行 ≥6 字；**3 行须为长短长或短长短**（对照分配表「封面节奏」列）；**模式一封面强检数值或百分比量纲**（如 `90%`、`3天`），严禁考试得分词（如 `低于60分`）；全面支持【测试数据/量纲 + 人格反差标签】；遮住正文读封面一眼能认领（“这说的是我”）。

## 七、自动化审查与自检脚本

在文档初稿生成完毕后，一键执行双层自动化核验与修复：

```bash
node ".agent/skills/xhs-note-operator/scripts/refine-notes.js" --file "design/product-docs/<测试名>/docs/YYYY-MM-DD_发帖文案.md" [--fix]
```

- **五位一体自动化机审**：
  - **① 认领位（封面）**：行数 2~4 行、长短节奏（长短长/短长短）、总字数 ≤16 字、0 词表；**模式一强检阿拉伯数字或百分比生活量纲**（缺失直接报错）；放行测试数据/量纲与反差标签组合；
  - **② 追问位（标题）**：单行 ≤20 字、0 词表、防空洞与复读；
  - **③ 赦免位（前 3 行）**：前 3 行生活场域道具或具体物理情节、逻辑闭环承接钩子；
  - **④ 悬念位（正文展开）**：正文智能断行 ≤15 字、口语虚词扰动 ≥2 种、短行停顿 ≥2 处、拦截第二人称说教与全篇宣誓口号、道具前后闭环；**强制正文包含测试闭环词（测出/报告/指数/测试等）**；
  - **⑤ 暗号位（正文末行）**：标签前最后一行**强制必须包含互动疑问（？/吗）或暗号指令词（几级/暗号/对暗号/留个/扣）**，严禁机械营销套路与单机自闭收束，校验末行有效性；
- **自检报告分离**：终端看板清晰呈现封面/标题与正文的分项合格情况及「五位一体门禁」整体达标判定；
- **历史回溯特别说明**：历史旧文回溯不合格仅反映新门禁标准的历史体检，绝不代表全盘报废，严禁依据扫描结果批量改写或删除历史文件；
- **--fix 定向自愈规范**：只执行确定性机械修复（断行、修标题、剥离末行宣誓口号、第二人称转第一人称、补齐固定品牌/品类标签）；通篇空洞无实物卡片打上 `[REWRITE_REQUIRED]`，严禁胡编乱填。
