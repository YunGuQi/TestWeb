> 本册为小红书发帖合规、红线词库、网感审查及自检清单的**全系统唯一真源**。
> 整合原 `xhs-note-copywriter` 的红线三分区与交付清单，以及 `xhs-note-analyzer` 的全域敏感词库与去爹味、去AI感审查法则。

## 一、擦边红线三分区 (Controversy Zones)

**医疗为绝对红线，其余可适度试探。**

| 分区 | 内容 | 处理原则 |
|---|---|---|
| ✅ **放行** | 夸张、自嘲、阴阳、网络热梗与发疯文学（如`精神离职` / `NPC觉醒` / `只要我没有道德` / `脆皮打工人` / `水泥封心` / `工位结界` / `反向整顿职场`） | 直接写，这是「野」和真人网感的主要来源；笑点落在作者自身或荒谬模式上 |
| ⚠️ **控比例** | 攻击性比喻，把父母 / 领导 / 亲戚设为靶子 | 可写，但同一测试批次内不超过三成 |
| ❌ **不碰** | 脏话、性暗示、身体羞辱、医疗词（`确诊` / `解药` / `抑郁` / `治疗` / `处方` / `症状` / `药物` / `疗效` / `挂号` / `心理疾病`） | 触发平台限流，且与情绪价值目标相悖 |

- 日常叙述词（`生病` / `体检` / `焦虑`）在非医疗主张语境下可用。
- **整活腔不豁免本表**：整活（自嘲玩梗 / 可转发幽默 / 阴阳式身份讽刺）只是表达姿态，**脏话 / 性暗示 / 身体羞辱 / 医疗词仍为 0**，且**笑点只许落在作者自己或荒谬的关系模式上**，不许拿用户或结果本人的痛处当笑点。
- **边界说明**：本表管的是小红书 feed 里的发帖文案与封面。千帆商图不直接受本表约束，但文案与商图必须严防医疗词串味。

## 四、爆款网感审查法则 (Anti-Ad & Anti-AI)

### 1. 逻辑闭环（严打标题党割裂，前 3 行必须接住封面 / 标题钩子）
- **钩子承诺什么，前 3 行必须兑现什么**：标题 / 封面承诺了什么具体事件、槽点或情绪冲突（如“终于离职了”、“拉黑了所有人”、“说好的暖冬去哪了”、“冻死我了 / 受够了”），正文**前 3 行必须立刻用具体生活动作、物理体感交代承接**（如提到了暖冬/冻死，前 3 行必须先写今天出门怎么冷、被风吹透、戴两层手套手依然冰凉等），不许空对空抒情。
- **严禁跳过钩子直接转进**：严禁封面/标题还在吐槽今天的寒潮，正文首行就直接跳到童年或回忆，造成钩子悬空割裂；先在今天接住钩子，再自然因果转折引出下文。
- 严禁标题制造巨大悬念，正文却全篇空洞议论或生硬推销测试。

### 2. 去爹味审查（第二人称转第一人称）
- **❌ 爹味说教体（严禁）**：“你是不是经常觉得下班很累？这叫情绪内耗，快来做个测试诊断一下！”（防御心理极高，像发传单）
- **✅ 第一人称日记体（推荐）**：“上个月我差点崩溃，下班连回微信的力气都没有，后来发现这叫低电量内耗...顺手把自测题放最后了，同款姐妹抱团取暖。”（真人叙事，分享姿态）

### 3. 【微信闺蜜吐槽体】人味硬门禁 (WeChat-Voice & Anti-AI)
- **微信发帖，聊完就停**：正文是正常发帖唠家常，像给闺蜜发微信语音转文字，大白话，说到哪算哪，聊完即停。**不许起承转合，不许首尾呼应，不许 callback**。
- **两拒（硬边界）**：
  - **❌ 拒【中学生作文】**：严禁好学生思想汇报、总结中心思想、机械套“其实…反倒…”公式（如“其实我不占别人便宜，反倒一身轻松”）；
  - **❌ 拒【文艺小说】**：严禁矫情做作、堆砌文学形容词、刻意特写镜头与伤痕渲染（如“幽暗的绿光照在键盘上”、“指甲掐进肉里”、“胃部一阵阵抽搐”）。
- **三要素（正向牵引）**：
  - **① 事实+动作**：说清具体事情和动作，不写空洞感想；
  - **② 日常原声对话**：自然嵌入 1~2 句极短对话原话（如“还没动笔呢”、“大伯您退休金涨了吗”、“顺手帮我打印一下呗”）；
  - **③ 吐一口浊气收尾**：收在自然吐槽或行动转折上（如“天大的事周一再说”、“图啥呢到底”、“谁的事情谁自己做吧”），不升华、不喊口号。
- **严禁为了凑结构硬加收尾（微动作收尾为可选）**：反面例子——开头提了暖宝宝，结尾非要加一句“我把被子又往上拉了拉”来呼应——彻底删掉这种写法！微动作收尾仅在它是前面动作的自然延伸时才可用。
- **允许直接停在测试转折句本身**：例如停在“那里才适合我”，就完了，不用再收尾。**钩子口号只许在封面 / 标题，正文结尾绝对不许喊口号**。正文不许出现“自己扛”、“破茧了往前走不回头”、“过好自己的日子比啥都强”等口号句。
- **同一个人、同一口气的吐槽**：封面、标题、正文必须是同一个人、同一口气的真实吐槽。
- **每行要有主语 / 时间 / 因果动作连贯（严禁碎片行）**：
  - 每行都要有主语 + 时间 + 动作或因果连贯，不许堆砌没有主语的形容词碎片；
  - **严禁天气报式单句与孤立碎片**：像“风也太凶了”、“我冻透了”、“冷死了”这种无动作、无因果的孤立天气感叹句一律禁止；
  - **严禁孤立凑数短行**：严禁“真的。”、“算了。”、“索性算了。”、“醒了。”等无主语、无动作的孤立凑数词单独占一行。
- **前 3 行生活情节与道具**：正文前 3 行必须包含日常生活实物或物理情节（暖宝宝、羽绒服、大骨汤、自提柜、工牌、工作机等），严禁通篇形而上的空洞议论。
- **短行断行破壁**：短行只作参考看板，不阻塞，与 refine-notes.js 的 shortLines 口径一致（≤10 字统计、不阻塞），严禁全篇行长均匀对称（一堵墙）。

### 4. 道具前后交代闭环（严禁正文后半段突然天降新道具）
- **实物道具必须提前交代**：正文里不许出现前面没交代过的道具。凡是正文里第一次出现的实物（伞、雨、车等），**前面 3 行或标题 / 封面里必须出现过**，否则判不合格重写。
- **反面典型**：寒衣节内耗那篇，正文前 8 行通篇没雨没伞，最后一句突然写“我都忘了能跟谁借伞”——属于典型的后半段突兀天降道具，强行文艺出戏。

### 5. 双层机审分工架构
- **封面 / 标题层**：只查钩子强度、0 词表、字数规范（行数 2~4 行、短≤4、长≥6、总字数≤16；标题≤20字）。**强情绪破局口号仅限在封面与标题使用**（如“谁让我不痛快我就当场掀桌子……过好自己的日子，比啥都强”、“二十岁我悟出了一个硬道理。职场勾心斗角全当耳风”、“不回应就是不失联。是把命还给自己”等高 CTR 钩子），**绝对严禁以“无生活场景道具”为由误判封面标题**！正文结尾严禁喊口号。
- **正文层**：查主语、时间、因果、前 3 行具体情节、口语虚词扰动、短行节奏与逻辑闭环。末行可停在原声对话、物理动作、生活场景或自然反问，不强制停在测试转折句本身，不升华、不喊口号。
- **元数据与标签真源核查**：机检强制核对 `result_name`（结果名）与品牌词、品类词，必须 100% 对齐 `测试画像.md` 与 `lib/*-data.ts`，绝不允许只数标签够 5 个就放过，绝不允许编造结果名。
- **历史回溯准则**：对历史笔记扫描时，分开上报【封面/标题不合格数】与【正文不合格数】。正文不合格系按最新人味新规回溯，只作记录，严禁批量改写或删除历史文件！

## 五、四项硬规格与版式标准 (Physical Specs)

> **硬规格（阻塞性门禁）**：机审脚本 `refine-notes.js` 阻断级红线，必须 100% 达标。自动化核验使用 `node "scripts/refine-notes.js" --file <path> [--fix]`。

1. **正文单行放宽至 ≤ 35 字**（物理硬约束）：按意群自然断行，保护日常对话原声与真源引用的完整性，绝不机械强行切碎；
2. **封面 2~4 行，字数合计 ≤ 16**（物理硬约束）：行长错落打破视觉疲劳，3 行建议落成「长短长」或「短长短」；
3. **标题一行、≤ 20 字**（物理硬约束）：一眼扫完，不挤满两行；超长时由作者人工精简，--fix 输出 [WARN] 绝不粗暴截字；
4. **标签恰好 5 个且真源对齐**（物理硬约束）：前 2 位（品牌词 / 品类词）全批字字相同严格对照 `测试画像.md`，第 3 位为真源结果名，全量 5 个标签。

> **网感与写作建议（非阻塞性参考）**：
> - **钩子与收尾**：末行遵从自然收尾、生活动作定格或互动暗号，严禁“快去测测看吧”等机械营销套路；
> - **口语虚词与热梗**：建议正文自然融入流行语与口语虚词，为写手提供网感建议看板，不作机械阻塞。

### 5.1 五位一体全链路标准 (The Five-in-One Model)

| 阶段位 | 载体位置 | 心理机制与用户动作 | 刚性准则与要求 | 失败形态 |
|---|---|---|---|---|
| **① 认领位** | 封面图文 (0.3秒) | 一眼认领「这说的是我」，直击痛点 | 2~4行、总字数≤16、长短错落（长短长/短长短）；支持爆款封面【真源雷达量纲/标签 + 人格反差标签】（如 `共情97 / 内核超稳大女主 / 不兜底`）；**建议包含生活化或真实雷达数据量纲**，严禁考试得分词 | 空洞口号/字数超标/无数据量纲 |
| **② 追问位** | 笔记标题 (1~2秒) | 读完追问「然后呢？原来是这样」，抓搜索流量 | 单行≤20字；取材七型（甲1~3、乙1~4），严禁封面文字直球复读 | 与封面一模一样/标题位白送 |
| **③ 赦免位** | 正文首段/前3行 | 情感赦免与松绑，卸下懂事愧疚与道德枷锁 | 前3行必须接住封面/标题钩子并融入测试闭环（允许生活道具、对话、发疯梗或日常事件破题）；落地生活实物微动作；赋予“不是你的错/不必战战兢兢迎合”的心理赦免感 | 空泛说教/爹味指责/钩子割裂悬空 |
| **④ 悬念位** | 正文展开中段 | 真实生活切片推展，留白未尽之言 | 展开五型轮转；落地实物微动作；**悬念位可选自然融入结果名、雷达指标或测试金句，三者任选其一即可，也可只用对话或动作推进，不强制插金句**；**严禁文青式宣誓升华**（如“晴空万里/自己扛”） | AI式顿悟升华/无道具抽象抒情/无报告转折 |
| **⑤ 暗号位** | 正文末行 (标签前) | 同频集结暗号，促使读者对暗号接头 | **暗号位可选自然反问、互动暗号、生活定格或对话自然收束，四者任选其一，不强制含疑问句或暗号词**；**严禁机械营销套路**（“快去测测看吧”）与单机自闭收尾 | 机械式营销逼问/无暗号留白/单机自闭 |

### 5.2 批次去同构与防模板硬门禁 (Batch Diversity Gates)

1. **批次去同构与防模板硬门禁（阻塞项，超阈值 exit 1）**：
   - **① 标题公式**：禁止全批套用“[场景]，测出[结果]我[动作]”单一公式。同一批 24 篇里该结构不得超过 8 篇（≤1/3），且标题结构至少 3 种以上（对话直入、无“测出”、动作先行、疑问、场景白描等）；
   - **② 结果报幕**：禁止每篇都在正文中段写“测出X，雷达Y%，我……”完整报幕句。报幕位置必须轮换（开头/中段/末行/只在封面、标题、首评出现），同一位置不得连续 3 篇，全批完整报幕句不得超过 12 篇（≤50%）。测试闭环只需正文命中一次“测出/自测/卡片”等词即可，不必每篇都写完整报幕句；
   - **③ 今昔对比**：禁止把“要是以前……这回……/换以前……/以前真的不敢……”当默认转折。同一批里今昔对比不得超过 6 篇（≤25%），其余必须用直接动作、对话打断、场景切换、物件定格等转折；
