## 三、四大心理学爆款模式 (The 4 Viral Patterns)

每个**主推结果**配备四种模式（主推结果的定义与挑选见 SKILL.md §六）。**四篇的骨架必须真的不同**（起手型 / 档 / 缺口型 三项至少两项不同），不是换名词。

**展开型分配**（定义见 01_双位与正文.md §2.7）：模式一 → **清单轰炸**，模式二 → **倒带**，模式三 → **一事到底**，模式四 → **对话实录**。**判词连打**作换型备选。**每模式允许 ≤2 张换型**。

**示例骨架**：四个模式的完整结构示范在 [`05_示例库.md`](05_示例库.md)。那是**骨架，不是可以套的模板**——示例全部取自大女主测试，**词句必须按本测试真实字段重写**。

> **整活注入点**（定义与档位归属见 [`00_画像与档位.md`](00_画像与档位.md) §2.4.1；**只有可整活档才注入**）：成熟度 **模式二 > 模式一 ≈ 模式四 > 模式三（不注入）**。各模式的落点见下。

### 模式一：【数字标尺与阶梯判词流（锚定与红线断言）】
**篇幅搭配**：**A档·为为极致微短帖（15~35字）为主**。核心数据在封面冲击，正文 1 句吐槽 + 1 句反问直接收束。
**心理机制**：锚定效应与损失厌恶。给出极端量化阶梯或危险红线，利用阿拉伯数字穿透信息流，逼用户瞬间自我对号入座。
**封面硬规格**：2~4 行阶梯判词或粗暴断言，**必须包含阿拉伯数字或百分比量纲**（如 `90%`、`3天`、`20年`、`1%`、`7个`），**行间错落**（自检清单 §7.3）。
- ✅ **正向模具（自嘲量纲）**：`懂事指数超过85% / 说明你天天都在 / 替所有人擦屁股`、`社交电量仅剩1% / 聚会超三人就想逃跑`、`退让指标拉满到99 / 换来的是全家习惯性忽视`。
- ❌ **反向红线**：严禁出现考试/测评打分词（`低于60分`、`得分98`、`测出`），量纲必须落在**生活场景与真实自嘲**上。
**整活注入点**：把**量化阶梯的量纲**写成荒谬的自嘲指标——整活版的量纲本身就是笑点，不是把数字改小。可注入。

### 模式二：【现实大反差 + 极短自嘲流】
**篇幅搭配**：**A档·为为极致微短帖（15~35字，纯正为为灵魂）**。绝不展开，笑点与反差全在自己身上，买家秀神评。
**心理机制**：认知失调与反差幽默。崇高人设与狼狈细节对撞，零认知阻力，引爆评论。
**封面**：2~4 行参差节奏，直接展现人设与现实的极端反差，**行间错落**（封面行错落，自检清单 §7.3「封面行」条）。
**整活注入点**：**天然整活场**——笑点落在**作者自己**身上（崇高人设 × 狼狈细节），整活腔在本模式最容易落地。可注入。

### 模式三：【生活痛点 + 真实自白流】
**篇幅搭配**：**B档·标准场景短帖（40~80字）** 与 **C档·沉浸体验长帖（100~150字）**。脆弱与情绪赦免需要呼吸空间，带入具体生活实物道具。
**心理机制**：真实脆弱感与情绪授权。撕开坚强伪装，撕开职场 / 家庭中的具体委屈。
**封面**：具体生活破防场景，**行间错落**（封面行错落，自检清单 §7.3「封面行」条），如 `从小太懂事 / 天天替所有人撑伞 / 我也想要个肩膀`。
**整活注入点**：**不注入**——本模式是低气压档的载体，玩梗会把脆弱感当场打碎。

### 模式四：【生活怪癖暗号 + 同频集结流】
**篇幅搭配**：**B档·标准场景短帖（40~60字）** 与 **A档·为为微短帖（25~35字）**。枚举隐秘怪癖，抛出接头暗号。
**心理机制**：社会认同与部落接头。枚举隐秘而精准的生活怪癖，把缺陷变成部落徽章。
**封面**：提炼 2~3 个隐秘习惯暗号，**行间错落**（封面行错落，自检清单 §7.3「封面行」条），如 `微信常年免打扰 / 聚会超三人 / 我就想跑`。
**整活注入点**：把**怪癖本身当部落黑话玩**（阴阳式身份讽刺）——暗号越自嘲，接头感越强。可注入。
