# 分册 02 · 题库模型与微情境 (Question Bank & Micro-Scenarios)

> **知识来源**：老罗头部爆款（ABO/甄嬛/变态测试）底层逆向规范  
> **核心职责**：指导微情境题干起草、四向生物本能选项映射及 85%+ 完答率把控。

---

## 一、 完答率黄金法则 (Completion Rate)

* **痛点**：传统 20~50 题学术量表流失率高达 80% 以上，用户答题超过 3 分钟会产生强烈的认知疲劳与弃答心理；
* **刚性指标**：
  * **题量锁定 12~15 题**（绝不超过 15 题）；
  * **单题作答时间 8~10 秒**，全卷完答严格控制在 **2.5 分钟以内**；
  * **300ms 平滑自动切题**：选项点击后延迟 300ms 自动平滑滚动切到下一题，降低 50% 的手指点击决策成本。

---

## 二、 题干设计：从“抽象自评”走向“戏剧微情境”

### 2.1 彻底剔除三类低效题干
* ❌ **道德说教题**：“你平时对待朋友真诚友善吗？”（引发伪善选择，结果失真）；
* ❌ **主观内省题**：“当你感受到内耗时，你的焦虑程度是？”（无情境画面，调动不起潜意识）；
* ❌ **医学诊断题**：“过去两周你是否有失眠或持续情绪低落？”（触碰平台医疗红线，体验沉重）。

### 2.2 爆款“戏剧微情境”三大构建公式
将题目扔进一个带有**轻微道德压迫、人际冲突、利益取舍或生活尴尬**的具体微镜头中：

| 情境类型 | 爆款示范题干（老罗/甄嬛/ABO） | 现有产品迁移范例（大女主/内耗测试） |
| :--- | :--- | :--- |
| **突发人际冤枉** | *“邻居家丢了东西，大家都怀疑有过前科的你，但你什么都没做。你会？”* | *“部门方案被同事原封不动抄袭并在例会上抢先汇报，所有人都在夸她。你会？”* |
| **高压利益取舍** | *“你是一位武林高手，在街上遇见差点杀死你的仇敌，周围全是平民。你会？”* | *“家里急需用钱催你掏空积蓄给弟弟买房，否则就说你白眼狼。你会？”* |
| **尴尬社交冷落** | *“在陌生人聚会中，你独自站在角落，旁边的圈子聊得正火热。你会？”* | *“合租室友每次带朋友聚会都默认让你洗碗收拾，今天你累瘫了。你会？”* |

## 三、 选项设计：四向人格对齐与无痛选择

### 3.1 四向生物本能模型 (Fight / Flight / Freeze / Fawn)
每个题目的 4 个选项，应严格分别映射 4 种无意识本能，不设道德高下，让用户秒选：

```text
[选项 A · Fight (硬刚反击)]  -> 对应 Alpha / 掌控型 / 杀伐果断
例：“直接在会议上调出修改记录，当众戳穿并要求其公开解释”

[选项 B · Flight (决绝抽离)] -> 对应 独立孤狼 / 课题分离 / 止损型
例：“一句话不说立刻离职/搬走，所有联系方式拉黑，再也不见这群人”

[选项 C · Freeze (防御冷漠)] -> 对应 Beta / 理智观察 / 幕后防御
例：“不解释不争辩，冷眼看戏，暗中收集证据等最关键时刻反戈一击”

[选项 D · Fawn (委屈求全)]   -> 对应 Omega / 敏感迎合 / 内省内耗
例：“躲到洗手间自己哭一场，擦干眼泪回去装作什么都没发生”
```

### 3.2 选项排版视觉控制
* **字数齐整**：每个选项字数控制在 **12~16 字以内**，严禁出现一个选项 5 个字、另一个选项 35 字的长短失衡；
* **消灭否定词**：多用主动行为动词（“暗中搜集”、“立刻反击”、“转身离开”），减少认知解析负荷。
