女娲造人的核心哲学是：**造的不是人，是提炼可运行的认知操作系统（思维框架）**。
当大哥在即刻、X、小红书或线下圈子发现新的优秀操盘手（如：爆款文案专家、千帆带货黑马、投流大拿、私域裂变高手）时，我们不堆砌其冗长的对话录或零散文章，而是通过女娲方法论，将其蒸馏为标准化的**智囊审查官卡片**，无缝接入本项目。

```markdown
  - [他看什么最不顺眼？会立刻叫停什么行为？]

```

## 三、 四步归仓流程序列

```
[原始语料] (推文/长访谈/复盘文章)
    │
    ▼ 步骤 1：原稿落盘至 `教程/分享/[博主名]/`
    │
    ▼ 步骤 2：调用 `huashu-nuwa` 执行三重验证（跨域复现/生成力/排他性）
    │
    ▼ 步骤 3：提炼核心心智模型、四大死因与经典判词，写入 `references/01_masters_dossier.md`
    │
    ▼ 步骤 4：更新 `SKILL.md` 的智囊矩阵全景图与调用分工
```

### 审查验证要点：
1. **排他性验证**：该大师的视角是否具备鲜明独特性？（如果只是泛泛说“要做好内容”，直接降级为普通建议，不给大师席位）；
2. **场景可执行性**：该大师的判词能否在发帖文案或代码落地前作为**机器可自检的硬性门禁**；
3. **保持单一真源（SSOT）**：新大师入库后，如果其打法与现有大师有冲突（如重交付 vs 轻自动化），在分册中注明“流派张力与适用边界”，确保矩阵协同不乱套。
