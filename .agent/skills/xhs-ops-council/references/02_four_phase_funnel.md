# 分册 02 · 投后四阶漏斗诊断树与尾流归因指南

> **知识来源**：小晚不在（四阶排查漏斗） + Fufu日常局（6-15天尾流法则） + 老罗（44帖出8单死因归因）

---

## 一、 小红书分发周期与尾流机制（拒绝单次焦虑）

很多新手容易陷入“发帖 24 小时没爆就删帖重发”的焦虑误区。
必须深刻理解小红书与短视频平台（抖音/快手）的底层机制差异：

| 平台属性 | 抖音 / 快手 | 小红书 |
| :--- | :--- | :--- |
| **分发机制** | **赛马机制**（当天跑不出赛马池即被淘汰） | **双列瀑布流 + 搜索长尾双轮驱动** |
| **生命周期** | 90% 内容活不过 24 小时 | **拥有 6~15 天的长效尾流**，长尾持续分发 |
| **新号底量** | 波动极大，若无表现力常卡 0 播放 | 普通新号普遍有 **2000 左右的基础曝光打底** |
| **操作铁律** | 追热点、短平快、不行即弃 | **发帖后 7 天内严禁轻举妄动**，非违规不改标题不删帖 |

## 二、 四阶漏斗排查模型（科学归因，不甩锅平台）

当笔记数据表现不理想时，坚决不泛化为“平台不给流量”，严格按以下四阶漏斗自上而下逐级排查：

```
                    ┌─── 1. 曝光漏斗：曝光量 < 500
                    │    ➔ 排查类目合规、敏感词、纯净网络IP
                    │
                    ├─── 2. 点击漏斗：曝光正常但点击率低 (CTR < 8%)
                    │    ➔ 排查封面大字反直觉度、排版拥挤度、标题搜索价值
                    │
                    ├─── 3. 互动漏斗：有阅读但点赞收藏评论低
                    │    ➔ 排查24张卡片滑屏节奏、正文是否鸡汤、结尾暗号是否点燃
                    │
                    └─── 4. 变现漏斗：有互动甚至涨粉，但不进店/不出单
                         ➔ 排查主页承接力、1.98元支付阻力、订单防白嫖流程
```

### 第一阶：曝光少（曝光 < 500）
- **现象**：小眼睛几乎不动，跑不满基础曝光池。
- **排查清单**：
  1. **账号合规状态**：是否收到官方系统违规提醒？
  2. **网络与设备**：是否在同一局域网 Wi-Fi 下多账号密集操作？（必须切换为手机蜂窝移动网络）；
  3. **题材与违禁词**：是否误触医疗/迷信高压线（如出现“抑郁、诊断、前世、算命”）；
  4. **同质化重合**：图片素材是否与全网库完全雷同被系统查重。

### 第二阶：有人看到却不点开（点击率低，CTR < 8%）
- **现象**：曝光量上千，但点击阅读极低。
- **排查清单**：
  1. **封面缩略图测试**：把封面缩小到手机瀑布流大小，0.5秒内能否看清大字？
  2. **双位信息同质化**：封面大字和标题是不是说了同一句话？（必须封面抓痛点眼球，标题给确定性价值）；
  3. **艺术字与贴纸污染**：是否踩了老罗四大死因（艺术花字认不出、贴纸低质营销感）；
  4. **痛点与用户相关性**：大字是否居高临下、自嗨？有没有刺中 20~30 岁女性的隐性内耗？

### 第三阶：有人看完但不收藏/不互动
- **现象**：阅读量不错，但赞藏低、评论区空空如也。
- **排查清单**：
  1. **正文踩了科普鸡汤坑**：越写专业科普越没人互动！必须直截了当抛三大心理钩子；
  2. **排版视觉拥挤**：是否单行超过 15 字造成“文字墙”窒息感？
  3. **缺少接头暗号**：文末和首评有没有给明确行动指令？（如“留个【觉醒】测测你的精神内耗指数”）。

### 第四阶：有粉丝/有互动，但不转化出单
- **现象**：评论区很热闹，但千帆店铺 1.98 元出单量惨淡。
- **排查清单**：
  1. **变现承接断层**：读者看完了以为只是娱乐段子，不知道存在一个能测的深度测评产品；
  2. **支付链路阻力**：1.98 元下单后卡密推送是否顺畅？H5 页面做题是否卡顿？
  3. **主页承接力不够**：主页简介是否清晰说明了“你是谁、提供什么测试、怎么获取”；
  4. **防白嫖机制失效**：是否被盗刷链接，或者未设置真实毛玻璃遮罩导致直接被白嫖看完了结果。
