# 00_Account Setup (账号基建篇)

在接手全新的小红书账号时，第一步必须完成“基建包装”（名字、头像、简介）。

> [!IMPORTANT]
> **双轨发布矩阵策略（对齐项目核心规范 `CLAUDE.md`）**：
> - **老号（安安，前缀 `安安_`）**：已有粉丝基础与沉淀权重，优先用于发布新测试“测水温”、收集初盘反馈；
> - **新号（纯白号，前缀 `新号_`）**：享受新号扶持自然推流，主攻千帆挂车与公域转化。
> 所有产出文案、封面及账号命名规划时，须首先明确是安安老号还是纯白新号。

## 1. Account Archetypes (三大流派)

When generating new account proposals, you MUST present these 3 archetypes or directly generate complete setups for them:

### 1. 拟人陪伴流（参考：猫咪情绪馆）
- **适用场景**：主打深度情绪内耗、疗愈、深夜emo话题。
- **名字公式**：`[动物/软萌物体]` + `[情绪/解忧]` + `馆/铺/便利店`。例如：*树懒解忧铺*、*小熊情绪便利店*。
- **头像建议**：手绘风格的动物（带有某种情绪，如发呆的猫、撑伞的熊），色调偏向温暖的治愈色（如鹅黄、莫兰迪蓝）。
- **简介公式**：`[人设说明]` + `[提供价值]` + `[导流钩子]`。
  > 示例：“一个懂你的深夜小熊🐻 | 帮你认清自己的情绪盲区 | 深度情绪体检请戳下方小店👇”

### 2. 品牌工作室流（参考：Blueberry Studio、温心点灯）
- **适用场景**：做极简拔草流，无情感废话，纯靠量化测试和二元对立吸引流量，适合流水线矩阵号。
- **名字公式**：`[英文/极简意象]` + `Studio/实验室/点灯/指北`。例如：*Pineapple Studio*、*微光实验室*。
- **头像建议**：极简的图形 Logo，或是简单的几何线条、品牌字母缩写。背景多为纯色（如牛皮纸色、纯黑、纯白），具有“高冷、严谨”的学术感或机构感。
- **简介公式**：高度精简，直接表明这是一个测试分发机器。
  > 示例：“专注直击灵魂的趣味测试 💡 | 遇见更真实的自己 | 专属潜意识档案获取通道👇”

### 3. 趣味测试垂直流（融合二次元/玄学风格）
- **适用场景**：专门发布各类趣味心理测试，受众年轻化，有强烈的转发和验证自我的需求。
- **名字公式**：`[圈层核心词汇/二次元称呼]` + `观察室/研究所/鉴定中心`。例如：*高敏感人群研究所*、*少女心事鉴定中心*。
- **头像与背景建议**：头像使用**二次元卡通少女头像**或具有特定圈层符号的标志；背景强烈建议使用**好运玄学插画壁纸**（增加神秘感与锦鲤属性）。
- **简介公式**：直接建立测试的独特性，必须包含关键词：“心理学”、“仅供娱乐”、“原创测试”。
  > 示例：“专注原创心理学测试 🔮 | 仅供娱乐，但也许能看穿你 | 获取最新性格深度报告👇”

## 2. Execution Requirements (执行要求)

1. **Auto-generate 3 proposals**: 直接输出上述三大流派的具体【名字、简介、头像风格】推荐组合。
2. **MANDATORY CTA Hook**: AI 在设计简介（Bio）时，必须在结尾强制加上引导变现或引流的钩子（如“测算请戳小店”、“进群获取完整版”），确保流量不被浪费。
3. **Lock & Consistency (Tone matching)**: 用户选中某一方案后，后续的测试设计（阶段2）和物料生成（阶段3）的文案语调必须与该人设保持绝对一致（例如：选了“小熊”，文案偶尔可以带点动物拟人语气；选了“工作室”，文案必须绝对冷酷极简）。

## 3. Basic Profile Settings (其他基础资料设置)

在完成核心的【名字、头像、简介】后，还需完善以下账号基础资料。向用户提供建议时，请遵循以下原则：

1. **性别**：强烈建议设置为 **女**（小红书平台女性用户为主，女性身份或中性身份的防备心更低，私聊转化效果更好），或者选择**不展示/隐藏**（更适合“品牌工作室流”的冷酷非人格化调性）。
2. **生日/星座**：必须是 **成年日期**（如2005年之前，以符合开店与实名要求）。为配合特定人设，可精心挑选日期（如：10.05 天秤座代表平衡美感；11.11 天蝎座代表神秘心理学；1.20 水瓶座代表脑洞前卫）。
3. **地区 / IP 属地**：
   - **国内高级感**：建议设置为 **上海** 或 **北京**，天然带有前卫、中产、专业机构的滤镜。
   - **海外神秘感**：可以设置为冷门高纬度国家，如 **冰岛、挪威、芬兰**，极度契合“微光”、“疗愈”、“暗黑”等概念。
4. **职业**：
   - 如果是“陪伴流/垂直流”，建议填写：**心理咨询师、独立撰稿人、插画师**。
   - 如果是“工作室流”，建议填写：**自由职业、艺术总监、视觉设计师**。
   - 核心原则：职业需带有“创意”、“洞察”或“自由”属性，避免填写过于沉闷的传统行业。
5. **学校**：
   - 建议 **留白（不填）**，保持神秘感，避免暴露真实隐私。
   - 若必须要利用学历背书（尤其是专业垂直流），可填写国内外知名高校的艺术/心理学相关方向，如：**伦敦艺术大学、华东师范大学** 等。

## 4. Real-name Auth & Store Binding (后台硬装)

账号“软装”资料填写完毕后，必须由用户在手机端手动完成以下“硬装”动作，否则账号无法获得正常流量或开展变现：

### 1. 实名认证（强制动作）
- **重要性**：未实名账号发帖一段时间后会被系统判定为营销号，遭受**隐藏限流**（帖子与商品全部不显示）。
- **操作路径**：手机小红书 App -> 我 -> 设置 -> 账号与安全 -> 实名认证。
- **技巧**：如果实名被旧号占用，在新号认证时选择“注销旧账号”，原因选“实名被占用”，实名额度会立刻释放。

### 2. 开通店铺（仅主账号操作）
- **操作路径**：创作者中心 -> 全部服务 -> 开通店铺 -> 立即开店。
- **设置**：类型选【个人店铺】；资质上传身份证正反面；规模选【小额零售】。
- **资金**：开店时**可先不交保证金**，等后续有订单需要提现时再补交。

### 3. 新号连接主号店铺（矩阵绑定打法）
如果当前起的是“矩阵小号”，不需要每个号都开店，只需将其挂靠在主号开的店铺下即可：
- **前提条件**：主账号必须已经完成开店（并且下载了“千帆 App”）。
- **操作路径（在主账号操作）**：打开手机【千帆 App】 -> 全部工具 -> 账号关联 -> 创建关联邀请。
- **绑定方式**：输入新号（小号）的小红书号（名称下方那一串数字ID）发送邀请，小号确认即可。
- **效果**：关联成功后，小号可以直接在发帖时挂载主账号店铺里的测试商品，实现“一店多号”的流量矩阵。
- **注意**：关联后如果想要解绑，必须等待 **30天**。
