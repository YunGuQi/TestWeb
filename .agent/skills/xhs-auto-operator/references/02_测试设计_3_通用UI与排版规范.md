# 02_测试设计_3 - 通用 UI 与排版规范 (General UI & Typography SOP)

为了保证项目的交互体验、产品高级感与变现拦截能力，前端研发**必须严格遵循**以下视觉与交互规范。

> **⚠️ MANDATORY: Scope of Application & Impeccable Design Standards (视觉降维打击要求)**：
> 无论是使用优先推荐的“全栈大盘架构”，还是用于快速验证的“单 HTML”开发，本规范中的交互排版（如单页瀑布流、订单拦截、自动跳转）均**必须无条件遵守**。
> **在编写前端代码时，强制要求调用并遵循 `impeccable` 技能群（`craft`, `colorize`, `bolder`）**，抛弃基础的原生组件堆砌，打造极具力量感的排版、高级情绪色彩映射和丝滑的物理级微动效。

## 1. Core UI Architecture Standards (核心页面 UI 架构规范)

虚拟测试项目的前端页面必须包含且仅包含以下 5 大核心架构模块：

### 1. 封面页 (Start Page)
- **功能**：承载标题、引入测试动机的引导文案、[开始测试] 主按钮。
- **互动增强（虚假繁荣）**：必须在 [开始测试] 按钮正下方加入“目前有 XX 人参与测试”的提示（可使用随机数或定时器动态跳动，随机范围建议 0-100 之间，追求真实感），以增加测试热度和从众心理。
- **次要入口**：底部常驻 Flex 并排布局的两个次级按钮：[查看历史档案]（如有历史记录时显示，或直接入口）和 [探索更多测评/店铺入口]（如安安店铺链接：`https://xhslink.com/m/Atwtf3Cy6FR`）。

### 2. 前置分流页 (Status Page - 视需可选)
- **功能**：用于进入问答前收集强依赖条件（如性别、情感状态等）。此类条件通常不计入分数，但会改变最终结果的细节。
- **组件**：独立大区块选择器与 [返回封面] 防误触按钮。

### 3. 核心问答页 (Question Page)
- **交互核心 (自动跳转)**：必须实现“答题自动跳转”逻辑。用户点击选项后，必须展示选中动效/盖章，并在 300ms 延迟后自动切换到下一题，降低用户操作成本。
  - **选项常驻**：选项被点击后的动效必须**常驻保留**，不能在跳转前清除。
  - **🚨 关键特例**：最后一题答完后绝对不能自动跳转，必须展示一个明确的【生成报告 / 打印账单】主按钮，点击后才进行结算跳转，以此增加仪式感。
- **组件**：左上角永远固定为返回首页的入口。除了第一题，选项下方必须固定提供基于历史数据栈的 [← 撤回上一题] 按钮。

### 4. 结果与操作页 (Result Page) - 🚨核心变现区
- **核心交互**：强制采用**单页瀑布流向下排版**，所有内容一拉到底，绝不使用左右滑动卡片形式。
- **🚨 订单验证防白嫖系统（30% 诱饵 vs 70% 锁定的黄金分割线）**：
  - **免费展示区（前 30% · 极度精准的诱饵）**：页面顶部展示身份定调层（称号/Tags/金句）、核心量化图谱（雷达/象限/指标卡）以及深度诊断引言。
  - **高斯模糊遮罩锁定区（后 70% · 高价值硬核解药）**：将破防场景 TOP 3、绝配与克星物种、避难所处方等深层内容置于 **高斯模糊遮罩（CSS `backdrop-filter: blur(8px)`）** 之下，页面一拉到底但关键解药不可读。
  - **动态高危预警逼单钩子 (Loss Aversion)**：遮罩上方浮层必须结合用户作答，动态渲染红线报警文案：
    > ⚠️ **【高危预警】** 检测到您的核心指标突破安全阈值，针对性的破防名场面、克星避坑指南与专属处方已加密封存。
  - **解锁交互**：用户点击浮层或悬浮按钮，弹出【解锁完整报告】弹窗，输入私域或小红书店铺获取的**激活码（订单号）**，验证通过后无缝移除遮罩、展开完整长文并允许截图保存。
- **顶部：主海报区 (社交炫耀展现)**
  - 最上方必须固定显示类似“你是第 XXX 个完成测试/被领养的人”的提示，以增加专属感与稀缺性。
  - 包含动态视觉印章、3-4 个特质标签（Tags）与极具视觉冲击力的核心称号。
  - **🚨 响应式卡片头图引擎 (Image & DOM 混排规范)**：
    - **痛点**：直接生成带有排版文字或全屏复杂背景的海报图，在移动端或不同设备宽度下容易被裁切，甚至导致文字遮挡人物面部。
    - **生图标准**：前端背景图**绝对不能包含任何文字**。生图时必须强制使用类似 Prompt：“`Landscape layout. Character strictly placed on the RIGHT half. The LEFT half MUST BE COMPLETELY EMPTY and fade into a dark, solid background. NO TEXT.`”。
    - **代码实现**：前端将该纯净图设置为自适应比例的容器背景（如 `w-full h-full object-cover object-right`），并**强制叠加一层左到右的 CSS 纯色渐变遮罩**（例如：`bg-gradient-to-r from-[#121212] via-[#121212]/80 to-transparent`）。然后将所有结果页文案、印章（如 DOSSIER）、雷达数据用绝对定位或 Flex 布局写在左侧的纯黑/暗色安全区。
    - **效果**：无论屏幕如何缩放，左侧 HTML 文字永远清晰可读，右侧人物立绘自然融合背景，彻底解决移动端适配与挡脸问题，实现顶级时尚杂志质感。
    - **👉 参考案例图集**：详见本技能仓库中的 `assets/responsive-card-covers/` 目录，这里存放了经过验证的纯净无字版、左黑右人构图的参考图片。
  - **防同质化数据与动态图谱（小数点后一位与上下微波动规范）**：量化图谱（6维雷达/4维象限/3维斜纹卡）必须严格基于作答计算与常模百分位动态生成，**数值强制精确到小数点后一位（如 82.4%、18.7%），杜绝死板整数；同时必须附加 ±0.3%~0.8% 的轻微去重波动**，有效防御小红书截屏查重，并彻底杜绝多个维度撞在同一整数死角上。
- **底部：深度解析长卷 (情绪价值与变现承接)**
  - **结构标准**：长卷必须完整兑现 [02_测试设计_2_题库模型与结果分析精算规范.md](02_测试设计_2_题库模型与结果分析精算规范.md) 确立的**【黄金六联排 (Golden 6-Pack)】**（1.身份定调 → 2.动态图谱 → 3.深度机理 → 4.破防名场面TOP3 → 5.社交绝配克星 → 6.避难所指南），前 30% 为诱饵，后 70% 必须置于高斯模糊遮罩之下。
  - **杂志级排版**：长文本必须 `text-align: justify`，行高 `1.6-1.8`。剔除原生 Emoji 作为标题，改用 CSS 强调线。
- **操作与截图区**
  - 最底部固定放置 [重新测试] 和 [探索更多测评/引导测试大厅] 的按钮。
  - [保存专属专属证书] 按钮：截图对象必须是**整个瀑布流容器**，一次性保存带有数据与长文的所有内容。

### 5. 全局模态框 (Modals & Hooks)
- **历史记录存档**：测试完成后必须有结果存档功能（如 `localStorage` 兜底），防止数据库异常时无记录。
- **防堆叠规范**：任何页面的底部如果存在两个次级功能按钮，**必须并排 (Flex)**，严禁上下堆叠影响重心。
