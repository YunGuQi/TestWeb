# 01_Data Discovery (爆款对标篇)

根据选择的平台严格按以下流程执行：

## Phase A: Bilibili Dimension Reduction Extraction (B站降维挖掘法 - 强烈推荐用于心理测试)

“爆过的内容会重复爆”，将B站高播放量的精品心理测试视频搬运改造，是极高效率的起盘方式。

1. **获取链接**：由 `browser_subagent` 自动去 B 站搜索互动视频（如：“趣味心理测试”、“超准性格测试”），或向用户索要特定的互动视频链接（提供 BVID 即可）。
2. **提取原型（API 降维打击法）**：
   - **绝对禁止**使用 `browser_subagent` 模拟手动点击视频选项（效率极低且容易超时）。
   - **必须直接调用内置的扒谱爬虫**：AI 必须直接执行预置的 Python 脚本，拉取视频的全套节点结构 JSON（亦可联动 `bilibili-stein-extractor` 技能解析复杂跳转逻辑）。
   - **执行指令**：`uv run python .agent/skills/xhs-auto-operator/scripts/bilibili_ripper.py <BVID> -o "design/product-docs/<测试名称>/docs/benchmark_bilibili/"`
   - 等待脚本执行完毕，脚本会自动遍历整个互动视频的树状结构，扒出里面所有潜藏的**题目、选项、隐形计分 Variables（算分条件）、以及所有分支对应的测试结局**。
   - 脚本会自动过滤出真正的问卷题目并生成 `*_quiz.json` 结构，大大降低清洗数据的工作量。
3. **输出报告与自动拉流**：脚本执行完毕后，不仅会生成完整的 `<测试主题>_report.md` 骨架，还会全自动遍历所有结局分支的 CID，使用底层接口和 `ffmpeg` 将每个结局的原片无损下载至 `design/product-docs/<测试名称>/docs/benchmark_bilibili/` 目录（例如 `真实结局_306398259.mp4`）。
4. **AI 视觉补全（核心黑科技）**：因为 B 站的底层 API 是不包含 UP 主加在视频画面里的“性格剖析小作文”的，所以你（作为多模态大模型 AI Agent）**必须执行此步骤**：
   - 使用 `view_file` 工具直接去“看”下载好的 4-6 个 `真实结局_<CID>.mp4` 视频或截图（此工具支持识别视频画面的 OCR 文字）。
   - 提取出画面中滚动的：1. 性格关键词；2. 后天人格属性；3. 依恋类型；4. 大段的深层心理剖析文本（说明分析）。
   - 最后，使用 `multi_replace_file_content` 工具，将提取出的这些长篇说明文字完整无缺地填补进 `<测试主题>_report.md` 文档里，放在每个结局节点下方。**至此，无死角的终极百万爆款图鉴才算闭环收集完成！**
5. **资产归档规范（强制自动落盘 SSOT）**：
   - 提取与补全完毕后，必须自动将【定位、底层算法、题库、选项、权重、结果判定矩阵、深度心理分析】按照标准格式整理并落盘至：
     `design/product-docs/<测试名称>/docs/product_plan.md`
   - 作为后续 Phase 2 测试研发与 Phase 3 笔记文案制作的唯一可信源（SSOT）。

## Phase B: Xiaohongshu Native Extraction (小红书站内挖掘法 - 灰豚 + 小红书)

### Step B1: Huitun Data Discovery (灰豚数据安全寻宝)

**⚠️ CRITICAL SECURITY RED LINE**: 严禁直接使用 Python 爬虫请求灰豚数据接口！必须调度内置浏览器智能体（`browser_subagent`）执行以下人工模拟操作：

1. 操作浏览器访问 `https://xhs.huitun.com/#/goods/goods_list`。
2. 按照 `文教服务 -> 笔记商品榜 -> 周榜（优先）或月榜` 进行筛选。
3. 从网页截取榜单前三到前五的爆款商品，提取以下信息：
   - 商品/测试名称
   - 互动总量
   - 关联笔记数
   - 关联达人数

### Step B1.5: Golden Benchmark Screening Criteria (黄金对标账号过滤红线)

在灰豚上顺藤摸瓜找到关联达人后，在决定是否对其进行深度溯源前，必须用以下标准进行**严格过滤**：

✅ **MANDATORY: Perfect Benchmark Targets (必须模仿的“完美对标”)**：
1. **粉丝数极低（必须 < 5000，越低越好）**：证明其纯靠内容自然流爆火，没有私域或老粉加持，极易复制。
2. **封面极简统一**：纯文字或实拍截图，没有花里胡哨的艺术字和表情包。
3. **内容有悬疑/极端钩子**：标题和内容充满极端反差或提问，而非干瘪的科普鸡汤。
4. **选品丰富且每日更新**：店铺持续上架多品类测试，且最近两天内有发帖。

❌ **CRITICAL: Toxic Accounts to AVOID (绝对不能抄的“毒药账号”)**：
1. **大V账号（粉丝 > 5000）**：已形成IP壁垒或靠其他手段起号，普通新号抄了必死。
2. **单品吃到底**：整个主页只卖一道测试题，大概率是靠花钱投流或站外引流，不要模仿。
3. **视觉杂乱**：满屏表情包+花字，用户抓不住重点。

### Step B2: Xiaohongshu Content Deep Dive (红书前台溯源追踪)

拿到宏观爆款线索后，立刻调度内置浏览器智能体（`browser_subagent`）潜入小红书前台进行拆解：

1. 访问小红书主页，搜索目标博主名称，点击进入其主页。
2. 提取该博主的核心信息：
   - 博主名称
   - 博主简介
3. 在博主主页中，提取前五篇爆款笔记内容。由于小红书详情页存在强防爬模态框拦截，必须采取以下**双重策略**：
   - **自动提取层**：指挥 `browser_subagent` 依次点击前五篇笔记，尽可能获取笔记的【标题】、【正文】、【底部标签(#)】、【图片/封面描述】。
   - **人机协同层 (Fallback)**：若智能体点开详情页时被拦截或卡死，立即终止自动抓取，向用户请求支援：“请在浏览器中将这前五篇笔记点开截图，并保存至 `对标账号/<博主名>/` 目录下”。AI 读取截图后即可利用视觉能力提取原文和标签。
4. **分析该达人的商业闭环模式**，判定依据如下：
   - 是否在主页简介中包含“测试链接”、“主页链接”、“店铺”等引导语。
   - 笔记或评论区中是否出现明确的引流或变现话术。
   - 笔记风格是否统一、封面模板化（说明有批量产出能力和商业规划）。

### Step B3: Output Standard Analysis Report (输出标准拆解报告)

将上述抓取的信息，整理并输出为 Markdown 报告：
1. **保存路径与命名**：强制保存在 `design/product-docs/<测试名称>/docs/benchmark_<平台名>.md`（请自动创建该目录，实现测试项目文档的高内聚）。
2. **文档结构必须包含**：
   - 博主名及变现方式
   - 帖子链接与截图
   - 视觉与文案拆解
   - 评论区生态揭秘
   - 爆火底层逻辑
   - 如何模仿与导流（落地指南）
