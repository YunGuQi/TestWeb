## 1. Pre-flight Check (需求对齐与信息确认)
- **MANDATORY**: 在正式策划前，必须先启动 `grill-me` 技能或通过一问一答的形式，与用户明确以下核心要素：
  1. **测试主题**（核心定位）
  2. **目标受众**（针对哪类人群）
  3. **分享海报的隐喻实体**（发挥想象，除非特殊需要，否则不用车票、说明书、录取通知书、诊断书这几个）
  4. **题目总数**（确切的题量）

## 2. Input Sources (输入来源)
读取上一阶段在 `对标账号/B站原型/<测试主题>.md` 中提取的原始题目素材。

## 3. Execution Commands for Planning (策划扩写执行指令)
请要求 AI（或开启一个新的智能体）扮演顶级心理学家与爆款产品经理，**强制调用 `marketing-psychology` 技能（运用得寸进尺、损失厌恶、目标梯度等模型）**，按以下结构输出《完整测试方案》：

### 1. 引言与包装（动态情境隐喻化）
- 设计一个非常有噱头的测试大标题。
- 设计一段用于降低防备心、引发好奇的引导文案。
- **统一包装隐喻**：要求 AI 强制根据当前测试的主题，**动态设定一个相匹配的实体隐喻（如：处方单、机票、说明书、魔法卷轴、结账小票等）**。在策划文案用词上，必须全方位贴合该隐喻（例如若隐喻为机票，则使用“办理登机”、“航线”、“专属航班”等词汇），确保整个测试从头到尾概念统一。

### 2. 题库设计（白话化改造与去AI感）
- 将题目扩充至前期明确的题目总数。
- **前端交互要求**：页面必须设计“上一题”按钮，允许用户返回修改。
- **强制设计规范 (MANDATORY)**：题干与选项的文案生成**必须严格遵循 [02_测试设计_2_题库模型与结果分析精算规范.md](02_测试设计_2_题库模型与结果分析精算规范.md)**：
  1. **平行处事哲学**：选项必须是 4 种平行的成熟生活态度，绝不把人当病人审判（杜绝重度/中度/轻度内耗的阶梯选择）；
  2. **普适大情境**：题干锚定 100% 成年人公约数场景，杜绝狭窄具象细节；
  3. **禁词硬审查**：严禁出现`复盘`、`反思`、`揣摩`、`内耗`等概念标签同义词；
  4. **双短语律**：所有选项采用“动作 + 心理落脚点”对称结构，字数在 12~22 字区间；
  5. **真随机混维**：彻底打散 A/B/C/D 顺位，杜绝答题预判。

### 3. 测试结果池构建（强制遵循【黄金六联排】结构）
- 构建至少 **8 种**差异化且能引发自嘲与同温层共鸣的测试结果画像。
- **强制结构规范 (MANDATORY)**：每个结果画像的内容设计必须严格执行 [02_测试设计_2_题库模型与结果分析精算规范.md](02_测试设计_2_题库模型与结果分析精算规范.md) 的**【黄金六联排 (Golden 6-Pack)】**标准：
  1. **身份定调层 (Identity)**：极具网感爆梗的核心称号 + 3~4 个反差 Tags + 一句话出圈梗系评语；
  2. **核心量化层 (Spectrum)**：严格匹配维度的动态量化指标（6 维雷达 / 4 维十字象限 / 3 维斜纹指标卡，严禁千人一面）；
  3. **深度机理层 (Pathology)**：底层心理机制、原生印记或心智原型剖析；
  4. **具象名场面 (Scenarios)**：戳心破防生活真实场景 TOP 3 或电影级微镜头（具象不抽象）；
  5. **社交互动层 (Network)**：天生绝配 vs 宿命克星 / 能量吸血鬼（激发评论区撕逼与找同类）；
  6. **避难所指南 (Rx Cure)**：专属处方 / 避雷手册 / 锦囊（提供高浓度实用情绪价值）。

### 4. 严密的算法评分标准（常模精算与五级判定漏斗）
算法设计必须严格遵循 [02_测试设计_2_题库模型与结果分析精算规范.md](02_测试设计_2_题库模型与结果分析精算规范.md)：
1. **等权混维出题**：单选每题固定 **+1 分**，无多余不对称加权，彻底打乱顺位，消除各维度先天题量偏态；
2. **常模击败百分位映射**：前台严禁直接展示原始得分率，统一走 $Raw \rightarrow Z\text{-Score} \rightarrow \text{Percentile Rank}$，呈现为“超越 XX% 脆皮人类/同龄人”；
3. **五级判定流水线**：严格按照 `彩蛋特殊 > 极端双极拦截 > 同分仲裁锁链 > 单维度最高分常规判定 > 全局均衡兜底` 闭环执行；
4. **概率健康度仿真**：必须保证 5000 次蒙特卡洛模拟下，单画像占比 $\le 20\%$，且所有画像均可触发（$\ge 4\%$）。

### 5. 产品页面规划（交给研发的设计蓝图）

在策划阶段确定以下页面的**功能定位**（研发篇只负责具体实现细节）：

- **`/` 首页**：大标题 + 引导文案 + [开始测试] 主按钮。必须在介绍中明确写明测试能带来什么、测哪些维度。必须把“真实的当前参与测试人数（设定较少）”紧贴放置在 [开始测试] 主按钮的正下方；底部常驻 [查看历史档案] + [探索更多测评]（引导小红书账号https://xhslink.com/m/Atwtf3Cy6FR）入口。
- **`/test` 答题页**：左上角永远固定为 [← 返回首页]；除第一题外，选项下方固定提供 [撤回上一题] 按钮。选完自动进入下一题；最后一题**必须在用户点击（选中）某个选项后，才在底部显现明确的提交按钮**（如 [生成报告]、[打印账单]），手动点击该按钮后才进行跳转。
- **`/explore` 矩阵导流页**：展示系列全部测评产品（已上线可跳转，开发中灰显），是跨测评导流的核心枢纽。
- **`/result/[id]` 结果页**：最上方展示“你是第几个完成测试的人”；核心功能为呈现深度解析长文及展示最终结果。具体的排版结构与组件必须遵守 [02_测试设计_3_通用UI与排版规范.md](02_测试设计_3_通用UI与排版规范.md) 中的单页排版与 30%vs70% 遮罩规范。最底部固定为 [重新测试] 和 [引导测试大厅] 两个按钮。
