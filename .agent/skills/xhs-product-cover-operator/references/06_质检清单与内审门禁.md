# 06_质检清单与内审门禁

在交付商图提示词或最终图片前，必须对照本清单完成逐条内审。出现任何一项不符合，立即进行针对性修改或重新生成。

---

## 1. 结构与排版内审 (Layout Integrity & 5 Elements)

- [ ] **画布比例**：严格保证 1:1 正方形（800×800 或以上），适应小红书商品卡缩略图。
- [ ] **64-Split 上下层级**：上部 60~70% 为情绪认同区（标题+角色+心声），下部 30~40% 为干货公信与行动区（徽章条+CTA）。
- [ ] **具象人设 (Role-play Mirror)**：画面 C 位或强右侧必须有符合测试主题的核心人物/代言角色，绝无纯景物空镜头。
- [ ] **左上主标题**：字号醒目，占据 30%~40%，移动端缩略图一眼看清，附带核心痛点副标。
- [ ] **3 组维度胶囊**：左中垂直紧凑排列 3 组真实维度条目，有图标、有标签、有深度解析。
- [ ] **4 条独立心声气泡**：围绕人物环绕严格 4 条扎心内心独白，每条情绪与文案互不相同。
- [ ] **底部结果徽章条**：横向贯穿排列 6~8 个圆形头像或人设结果名称。
- [ ] **单居中 CTA 按钮**：画面最底端正中放置 **仅此 1 个** 宽圆角按钮，带点击箭头与规格参数。

---

## 2. 工业级防克隆与防重复审查 (Deduplication Check)

- [ ] **严禁双按钮**：画面底端绝对不得出现并排双按钮、上下双按钮或重复 CTA。
- [ ] **严禁气泡克隆**：4 条心声气泡绝无相同句式、重复文案或复制粘贴现象。
- [ ] **负向词完备**：Prompt 中必须包含 `duplicate buttons, twin buttons, repeated text bubbles, cloned elements, double CTA`。
- [ ] **文字逐字双引号**：所有需呈现的中文短句均在 `Text (verbatim):` 中被独立双引号包裹。

---

## 3. 真实性与事实锚定审查 (Fact-Anchored Consistency)

- [ ] **数据真实**：题目数、耗时、维度名称必须与测试项目源文件一致，严禁捏造。
- [ ] **严禁假条形码**：画面任何位置不得出现纯装饰性假条形码（Barcode）。
- [ ] **严禁假英文乱码**：严禁无意义的纯假英文装饰字母堆砌。
- [ ] **严禁虚假刷量**：严禁出现“全网已测999万+”等虚假造势文案。

---

## 4. 色彩与细节融合审查 (Aesthetic & Blending)

- [ ] **色温强绑定 (Scene-Palette Binding)**：大景、卡片、文字、按钮渐变色温统一，无突兀配色。
- [ ] **免抠无白边 (Zero-Border IP Blending)**：角色与大景无缝交融，无突兀的白框或硬生生截断。
- [ ] **主标去实框 (Transparent Title Container)**：主标题容器为全透明画框，无死白卡纸遮挡大景。
