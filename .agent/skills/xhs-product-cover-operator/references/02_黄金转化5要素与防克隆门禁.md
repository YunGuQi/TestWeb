# 02_黄金转化5要素与防克隆门禁

本规约定义小红书千帆 1:1 测试商品主图的黄金转化 5 要素布局标准，以及防止 AI 生图模型克隆翻车的工业级防重复门禁。

---

## 1. 黄金转化 5 元素布局 (The 5-Element Golden Conversion Layout)

一张高点击率与高付费转化率的 1:1 小红书测试商品主图，必须严密组织以下 5 大核心功能区域，严禁空洞留白：

```text
┌────────────────────────────────────────────────────────┐
│ [TOP-LEFT]                                [RIGHT]      │
│ ① 主标题 (Title 30~40%)                 ③ 角色与心声  │
│   高极性悬念大字 + 核心痛点 Hook                         │
│                                           C位/右侧 IP  │
│ ② 分析维度胶囊 (3组垂直堆叠)                 +          │
│   [🔍 边界防御] [❤️ 敏感内耗] [⚡ 反刍倾向]   4条独立心声  │
│   (严密提取自真实题库算法)                   独白气泡   │
├────────────────────────────────────────────────────────┤
│ ④ 底部结果人设徽章条 (横向贯穿)                           │
│   [头像1·人间铁壁] [头像2·4K回放] [头像3·钝感防御] ... (6~8个) │
├────────────────────────────────────────────────────────┤
│ ⑤ 底部唯一居中行动按钮 (Single Centered CTA Button)      │
│              [ ✦ 立即开启测试 · 查看深度报告 ✦ ]          │
│              (N道题目 | M分钟测完 | 专属处方)             │
└────────────────────────────────────────────────────────┘
```

### 区域详解与规格：

1. **左上主标题与痛点钩子 (Top-left Title & Subtitle Hook)**
   - 占据画面左上方约 30%~40% 面积，保证在手机端瀑布流缩略图下一眼秒懂。
   - 附带高反差底衬或荧光标注的一句话痛点钩子（15 字以内，直击用户软肋）。

2. **左中分析维度胶囊 (Mid-left Dimension Capsules)**
   - 垂直紧凑排列 **3 组** 圆角胶囊条目：`[图标] 维度名称 | 深度解析说明`。
   - 必须提取自真实测试配置与算法模型（如：恋爱防御力、敏感反刍度、社交耗竭值），严禁虚构。

3. **右侧主人物与 4 条独立心声气泡 (Right Character & 4 Unique Bubbles)**
   - 右侧占据约 40%~50%，呈现符合主题的二次元代言人/情绪主体。
   - 周围环绕 **严格 4 条互不相同、高度扎心** 的内心独白弹幕气泡（如：“发完微信反复琢磨标点”、“是不是我又冷场了”），精准激发对号入座心理。

4. **底部结果人设徽章条 (Bottom Result Badge Strip)**
   - 位于主插画与底部按钮之间的横向状态栏。
   - 密集排列 **6~8 个圆形头像/徽章**，标明具体测出的人格/角色名称（如：`[人间铁壁]`、`[深夜复盘]`、`[高敏雷达]` 等），强化“盲盒抽卡”的期待感。

5. **底端唯一居中行动按钮 (Single Centered CTA Button)**
   - 画布最底部居中放置 **仅此 1 个** 宽圆角主按钮（如：“✦ 开始平账 ✦”或“✦ 开启深度测试 ✦”）。
   - 按钮下方附带真实测试规格注释：`[N道题 | M分钟测完 | 专属解析报告]`。

## 2. 工业级防翻车与防重复门禁 (Deduplication Rules)

AI 绘画大模型（如 Midjourney、DALL-E 3、SDXL、千帆生图等）在解析复杂 UI 版面时极易产生“克隆复制”或“按钮成对”的缺陷。必须在提示词与指令中建立三道刚性门禁：

### 门禁 1：按钮唯一性硬约束 (Single Centered Button Invariant)
- **风险**：模型极易在底部画出“两个并排按钮”或“上下叠放的重复按钮”。
- **Prompt 强制声明**：
  ```text
  EXACTLY ONE SINGLE centered wide pill button at the very bottom (strictly no side-by-side buttons, no duplicate buttons).
  ```

### 门禁 2：心声气泡去重约束 (Strictly 4 Unique Floating Monologues)
- **风险**：模型为了填补空间，会克隆复制完全相同的气泡文案。
- **Prompt 强制声明**：
  ```text
  Surrounded by exactly 4 distinct floating speech monologue bubbles, each containing completely different text (strictly no repeated phrases).
  ```
- **编号分行约束**：在提示词中必须使用 1、2、3、4 分行独立标注文案，杜绝模型偷懒。

### 门禁 3：负向提示词硬封锁 (Negative Control Guardrails)
- 在任何生图调用或提示词模板的 `Avoid:` / Negative Prompt 区域，必须强制包含以下词条：
  ```text
  duplicate buttons, twin buttons, repeated text bubbles, cloned elements, double CTA, side-by-side buttons, repeated phrases, fake barcodes, distorted text.
  ```

### 门禁 4：原文字符双引号强制声明 (Verbatim Quoting)
- 在 `Text (verbatim):` 区域列出所有需要出现的中文文字，每条独立用双引号包裹，保证文字内容精准可控。
