# 04_测试维度提取与文案规则

本规约定义生成小红书千帆商图前，如何从实际产品工程中提取真实测试维度，并将其转化为高转化文案的完整工作流。

---

## 1. 真实维度与底层指标提取 (Fact-Anchored Extraction)

在生成任何商图提示词或图像前，**必须优先读取** 目标测试的真实源文件（如：`design/product-docs/<测试名>/` 下的 `product_plan.md`、`questions.json`、`page.tsx` 或 `01_策划与方案篇.md`）。

必须提取出以下四项硬核事实，严禁凭空捏造：
1. **测试全称与核心痛点**：用户购买此测试是为了解决什么情绪内耗或认知盲区（如：讨好型人格确诊、情侣极限契合度）。
2. **测试底层分析维度**：题库实际测量的 3~5 个核心指标（如：情绪反刍度、边界感知力、依恋风格等），作为左中“3 组维度胶囊”的来源。
3. **测出结果总数与具体角色名**：实际计算出的 6~8 种人格结果（如：“人间铁壁”、“4K深夜回放”、“治愈向日葵”），作为“底部结果人设徽章条”的来源。
4. **测试规格参数**：实际题目总数（N 道）、平均耗时（M 分钟）、报告页数或模块数。

---

## 2. 实体禀赋隐喻 (Physical Metaphor & Endowment Effect)

通过具象的物理载体提升心理价值感（Endowment Effect，禀赋效应），让用户感觉测试是一份真实的实体交付物：

| 测试题材 | 推荐实体隐喻 | 画面视觉细节 |
| :--- | :--- | :--- |
| **情绪内耗 / 逃离内卷** | 心灵逃跑车票 / 登机牌 | 齿孔边缘、检票印章、出发地与目的地条目 |
| **恋爱命定 / 关系契合** | 命定档案袋 / 羊皮纸火漆信 | 火漆印、红线系绳、邮戳、撕边质感 |
| **性格排查 / 深度鉴定** | 心理体检单 / 诊断报告书 | 药丸胶囊、处方笺盖章、医学勾选框 |
| **暗黑人格 / 欲望探寻** | 禁忌塔罗牌 / 机密档案夹 | 金属包角、神秘纹章、机密 STAMP 印章 |

---

## 3. 文案提炼与防虚假铁律 (Copy Refinement Rules)

1. **绝对禁止虚假工业装饰**：
   - 严禁加入无意义的假条形码（Barcode）。
   - 严禁加入无意义的乱码纯英文单词。
   - 严禁虚构伪造数据（如：“已验证 NO.159”、“99.9%的人都测错”、“全网1000万人已测”）。

2. **用真实干货替换假数据**：
   - 将底部或卡片装饰区全部替换为从题库提炼出的高价值事实标签（如：“34种城市人格”、“5大核心维度深度剖析”、“专属成长处方”）。

3. **四条心声气泡文案提炼准则**：
   - 必须采用第一人称视角（“我……”）。
   - 必须反映具体日常场景中的痛点行为（如：“发微信反复斟酌标点符号”、“别人一生气我就开始自我反思”）。
   - 4 条文案情绪必须互不相同（1 条场景痛点 + 1 条内心挣扎 + 1 条自我怀疑 + 1 条渴望释怀），严禁同义反复。

4. **主 CTA 按钮文案标准**：
   - 动词 + 结果收益（8~12 字）：
     - `✦ 开启深度测试 · 查看专属解析 ✦`
     - `✦ 立即开始平账 · 领取情绪处方 ✦`
     - `✦ 测测我的真实人格底牌 ✦`
