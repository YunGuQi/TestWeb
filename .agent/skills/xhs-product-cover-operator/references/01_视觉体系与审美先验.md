# 01_视觉体系与审美先验

本规约定义小红书千帆 1:1 测试商品图与主图海报的核心视觉体系、审美支柱与风格分支。

---

## 1. 核心审美六大先验支柱 (Core Aesthetic Pillars)

1. **`Role-play Mirror`（具象人设镜像）**
   - **卡尼曼系统 1 准则**：大众抗拒晦涩的心理学概念，但对“投射自身状态的拟人人设”极度敏感。
   - **红线规则**：绝对禁止纯背景/纯景物空镜头。画面 C 位或强右侧必须带有明确的核心主理人/代表角色（如：甜润多巴胺二次元少女、清冷黑白猫系御姐、呆萌治愈小怪兽），赋予用户“自我人设盲盒抽卡”的获得感。
   - **女性倾向默认**：女性向测试默认使用原创高辨识度二次元 Q 版或轻日漫少女；中性/职场/泛大众测试可依据主题调整为中性少年、治愈动物或情绪剪影。

2. **`Full-bleed`（全画幅巨匠大景铺底）**
   - 画布 1:1 满版铺底（吉卜力治愈森林、深海孤鲸光束、赛博霓虹都市、暖金日落云海），绝对禁止生硬的“白底+色块”左右割裂排版。
   - 叠加 **`Glassmorphism Overlay`（毛玻璃浮层）**：信息卡片采用微透明底色与毛玻璃质感，让背景大景意境自然透出。

3. **`Scene-Palette Binding`（色温强制绑定）**
   - 每个风格变体的「大景色调 + 毛玻璃底色 + 文字色 + 胶囊边框色 + CTA 渐变色」五项必须严格统一在同一色温区间，严禁背景与组件色温冲突：
     | 主题风格 | 大景意境关键词 | 卡片底色 | CTA 渐变主色 |
     | :--- | :--- | :--- | :--- |
     | **粉紫多巴胺** | 樱花雨、粉白云海、极光晨曦 | `rgba(255,240,248,0.85)` | `#FF4D8D` 玫红渐变 |
     | **自然森系疗愈** | 吉卜力翠林、晨雾松原、苔藓光斑 | `rgba(10,26,18,0.75)` | `#34D399` 薄荷青绿 |
     | **潮酷暗黑夜影** | 霓虹都市夜、赛博机甲、星系云雾 | `rgba(18,8,38,0.80)` | `#A855F7` 荧光紫 |
     | **暖阳复古日落** | 莫奈晚霞、印象派落日、暖金麦田 | `rgba(255,248,235,0.88)` | `#F59E0B` 琥珀金 |
     | **深海幽蓝沉思** | 深海光束、深渊孤鲸、水波倒影 | `rgba(10,20,48,0.78)` | `#22D3EE` 冰川青蓝 |

4. **`Zero-Border IP Blending`（IP 立绘无界融入）**
   - 角色立绘必须全透明免抠或自然光影融入，绝对禁止带有任何正方形白边、浅色剪影框或突兀描边。

5. **`Transparent Title Container`（主标去遮挡全透明）**
   - 标题区域采用去遮挡全透明容器，依靠文字本身的字重、阴影、微药丸底衬在背景上浮现，绝不阻挡后方大景与角色纵深。

6. **`Fact-Anchored Inference`（事实锚定推演）**
   - 画面上的所有维度、测评结果、参数标签，必须严格提取自测试题库与真实设定，绝对拒绝无意义的条形码、乱码假英文或虚假刷量数据。

## 2. 四大视觉分支路由 (Theme Branch Routing)

根据测试的主题与情绪基调，路由至以下四大视觉分支之一：

### 分支 1：潮酷冲突型 (Cool / Conflict)
- **适用场景**：危险人格、暗黑人格、反派性格、潜在欲望、黑化倾向、社交面具、控制欲等冲突题材。
- **参考垫图**：`assets/reference-danger.jpg`
- **配色基调**：纯黑、暗夜紫、品红、荧光霓虹绿、米白。
- **角色形象**：自信神秘、眼神微扬、锋芒感强的潮酷少女/御姐或暗影剪影，拒绝纯恐怖惊悚。
- **版式与图形**：重字重粗衬线/笔刷标题、荧光关键词高亮、利落对话气泡、闪电/王冠/荆棘微符号。

### 分支 2：清新测试型 (Fresh / Personality)
- **适用场景**：MBTI 深度解析、潜意识伪装、日常人格、性格体检、泛大众趣味趣味测试。
- **参考垫图**：`assets/reference-mbti.jpg`
- **配色基调**：薄荷绿、珊瑚粉、浅丁香紫、奶酪黄、暖白。
- **角色形象**：青春活力、亲和力强、时髦可爱的二次元 Q 版少女。
- **版式与图形**：清晰圆角模块、整齐维度胶囊、虚线与手绘星星装饰、清新对号入座勾选单。

### 分支 3：情绪叙事型 (Emotional / Resonance)
- **适用场景**：原生家庭、精神内耗、孤独感、社交疲惫、敏感度排查、童年创伤。
- **参考垫图**：`assets/reference-family.jpg`
- **配色基调**：黄昏琥珀、深海蓝、灰粉、暖灰、深烟草棕。
- **角色形象**：沉思静止、抱膝凝望或带有情绪道具（如旧玩偶、泛黄信件、雨伞）的细腻少女。
- **版式与图形**：日杂手账质感、扎心内心独白对话气泡、细腻小票或打卡单边缘。

### 分支 4：治愈浪漫型 (Healing / Romance)
- **适用场景**：命定恋人、正缘画像、恋爱脑确诊、灵魂伴侣、亲密关系修复。
- **参考垫图**：`assets/reference-romance.jpg`
- **配色基调**：蜜桃粉、薰衣草紫、香槟金、柔白、奶油杏。
- **角色形象**：温柔梦幻、手持花束/红线/星光的浪漫二次元少女。
- **版式与图形**：心形/光芒微装饰、手写风重点词圈注、对号入座特征卡。

## 3. 视觉绝对禁令 (Visual Prohibitions)

1. **严禁纯景物空镜头**：严禁没有任何角色或人设主体的死板海报。
2. **严禁死白死黑平铺底**：背景必须有渐变、纹理或全画幅意境大景。
3. **严禁割裂左右栏排版**：必须采用 64-Split 上下层次 + 毛玻璃纵深结合。
4. **严禁虚假工业装饰**：严禁无意义的假条形码（Barcode）、乱码假英文、纯数字占位符。
5. **严禁恐怖或低俗视觉**：暗黑主题亦须保持潮酷美学与社交传播礼貌，严禁血腥、惊悚或猎奇元素。
