# 心理测试题目与选项优化设计规范（去AI感与通用化实操指南）

> **参考基准**：操盘手为为（小满）《心理测试的第二版方案》与《xhs-ops-playbook》爆款研发心法  
> **适用对象**：小红书趣味心理测试产品线（以“深度情绪内耗测试 / 安安心灵便利店”为核心样板）  
> **文档定位**：彻底根除“题目一眼看穿答案”、“AI机械感塑料味”、“选项语义同质化”的题目与选项重构SOP。

---

## 一、 核心问题诊断：为什么目前的题目“太假、太明显”？

### 1. 概念直给与词面泄密（致命伤）
- **现象**：测试结果叫“深夜复盘家”，题目选项里就大量出现`回忆`、`复盘`、`反复揣摩`、`记好几天`、`分析`等同义词。
- **后果**：做题者只要扫一眼动词，不用思考就能猜出这道题背后加哪项分。测试沦为“字面填空”，丧失了潜意识测验的神秘感与探索欲。

### 2. 问卷变成了“病症轻重测试”，而非“性格态度选择”
- **现象**：同一道题的四个选项，本质是“重度内耗、中度内耗、轻度内耗、不内耗”。
- **后果**：做题者会产生强烈的心理戒备与防御机制，甚至故意选体面的选项伪装自己，测完后觉得沉重沮丧，丧失自传播分享欲。

### 3. AI 机械书面语泛滥（缺乏人类生活感）
- **现象**：充斥着`灾难化想象`、`精神内耗`、`社交耗尽所有能量`、`产生自我怀疑`等教科书式学术词汇。
- **后果**：充满冰冷无机质的“AI味”，用户代入感极差。

### 4. 走向另一个极端：过度具象化导致普适性断裂
- **误区**：为了生动，把选项写成非常细碎且特定的微小动作（如：“*吹头发时愣神*”、“*把被子猛拉过头顶*”）。
- **弊端**：每个人的生活习惯截然不同，一旦细节与用户不符，用户会本能产生“这写的不是我”的抽离感。**题目需要的是具有共鸣的“通用处事态度”，而非特定微动作。**

## 二、 为为（小满）标杆方案的核心设计哲学

对照《心理测试的第二版方案》，操盘手跑出 2.9 万单的题目底层逻辑有四大基石：

### 1. 题干：每个人都必定经历的“通用大情境”
情境必须覆盖 **100% 成年人都有的生活公约数**，不做小众偏门假设：
- 面对人际分歧时的自然反应；
- 独处/压力大时的第一解压选择；
- 收到模棱两可信息时的本能举措；
- 聚会结束回归个人空间后的常态；
- 面对意外变故/挫折时的第一下意识。

### 2. 选项：四种平行的“处事哲学”，绝无高下优劣
- **为为原则**：四个选项必须分别代表四种**平行的、体面的、合情合理的生活态度**。
- 每一个选项在常人看来都是“正常且体面”的应对方式，做题者在毫无道德包袱、毫无病理审判感的前提下凭借直觉二选一，算法在后台进行隐蔽变量加权。

### 3. 句式结构：工整自然的“核心动向 + 心理落脚点”
为为的选项绝不写单调字词，而是采用均衡的短语节奏（类似 4~6 字动作 + 4~8 字心态）：
- `独处放空、逃离人群，彻底屏蔽外界纷扰`
- `找亲友吐槽倾诉，需要陪伴和情绪安慰`
- `懒得争辩，保持距离，不被人际捆绑消耗`
- `心软帮忙，顾及彼此情分`
- `权衡利弊，选择对自己最有利的处理方式`

### 4. 彻底打散维度排布（真正的随机混维）
- **铁律**：严禁出现“A永远是第一维度、B永远是第二维度”的刻板规律。
- 20 道题目的选项维度彻底打乱乱序，规避做题者的答题预判，保障测试严谨度。

## 三、 去 AI 感词汇过滤规范（黑白名单）

在编写所有题目与选项时，必须严格执行词汇审查机制：

| 禁用词（AI 高频生造/概念书面词）❌ | 推荐替代方式（通用生活化口语/人类心理落脚点）✅ |
| :--- | :--- |
| **复盘 / 回放** | 把今天发生的事在脑子里过一遍 / 顺一顺细节 |
| **反复揣摩 / 过度分析** | 习惯性想得比较深 / 试图理清来龙去脉 |
| **自我反思 / 自我怀疑** | 反复确认是不是自己没处理好 / 习惯向内找原因 |
| **灾难化想象** | 本能把最坏的结果先预演一遍 |
| **记好几天** | 表面翻篇了，但这事总在脑海里挂着 |
| **精神内耗** | 脑子停不下来 / 心里一直放不下 |
| **社交能量耗尽** | 感到电量见底 / 觉得疲惫只想安静呆着 |
| **建立边界感** | 保持礼貌距离 / 多一事不如少一事 / 就事论事 |

## 四、 深度情绪内耗测试：四大核心维度通用重构范式

针对当前测试中出现“复盘、敏感、讨好、边界”同质化的问题，按为为标准梳理出通用的态度映射：

### 1. 【反刍/复盘维度】（深夜复盘家等画像）
- **核心内核**：不是“病态自责”，而是**“习惯向内归因、习惯把事情在逻辑上彻底理顺”**。
- **通用选项句式**：
  - *“自己呆着，把今天聊到的事和细节在心里过一遍”*
  - *“表面翻篇，但接下来几天总会忍不住反复琢磨这件事”*
  - *“习惯性想得比较深，反复确认是不是自己哪里没处理好”*
  - *“事情过去了，脑子里还一直在预演‘如果当时换个做法会怎样’”*

### 2. 【敏感/预警维度】（薛定谔的敏感等画像）
- **核心内核**：不是“神经过敏”，而是**“感知雷达灵敏、对周围微妙气氛能快速察觉”**。
- **通用选项句式**：
  - *“敏锐察觉到气氛有微妙变化，会下意识保持警惕”*
  - *“对语气和态度的细微转变很敏感，心里立刻有了数”*
  - *“在心里打了个问号，虽然不挑明，但会开始留意细节”*

### 3. 【心软/妥协维度】（心软神明降临等画像）
- **核心内核**：不是“软弱窝囊”，而是**“重情重义、顾全大局、希望每个人都舒服”**。
- **通用选项句式**：
  - *“心软妥协，顾及大家面子，优先维护和睦气氛”*
  - *“宁愿自己多担待一点，也不希望场面尴尬冷落了谁”*
  - *“虽然自己有些为难，但只要对方开口，还是会尽量成全”*

### 4. 【边界/钝感维度】（人间铁壁 / 精神守财奴画像）
- **核心内核**：不是“冷酷无情”，而是**“清醒止损、守住精力底线、就事论事”**。
- **通用选项句式**：
  - *“就事论事公事公办，不把多余情绪带入其中”*
  - *“听完就过，分清各自职责，不背负别人的情绪”*
  - *“适度拒绝，守住自己的生活节奏不被他人打乱”*

## 六、 题库落地验收清单（Checklist）

在将新题库提交或更新入代码前，必须逐项自查：

- [ ] **1. 无概念直给**：全篇题干与选项中，彻底杜绝出现`复盘`、`反思`、`揣摩`、`内耗`等概念标签词。
- [ ] **2. 选项平行对等**：每道题目的 4 个选项，都是一种说得通的生活选择，绝无“谁有病谁正常”的评判倾向。
- [ ] **3. 场景普适宏观**：情景均取材于日常普遍生活场景，无过度怪癖或狭窄具象假设。
- [ ] **4. 选项句式匀称**：每个选项长度大致相当（12~20 字之间），采用“动作 + 心理落脚点”的双短语节奏。
- [ ] **5. 维度随机乱序**：A/B/C/D 选项对应的维度彻底打散，无固定顺位规律。
- [ ] **6. 算法引擎兼容**：文案重构后，每个选项底层的分值字段（senScore, rumScore, plsScore, bndScore）与判定引擎保持无缝契合，保证 10 大画像均匀分布。
