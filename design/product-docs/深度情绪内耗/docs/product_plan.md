# 深度情绪内耗测算 - 全栈产品方案

## 一、 核心定位与产品包装
- **测试主题**：深度情绪内耗测算 —— 测测你的每一次内耗，到底花了多少“钱”。
- **目标受众**：高敏感体质、讨好型人格、深夜复盘专家、职场打工人。
- **视觉隐喻**：便利店收银小票（情绪消费账单 / Receipt）。
- **分享噱头标题**：【系统警告】你的情绪信用卡已刷爆！看看是谁在偷偷扣你的费。
- **引导文案**：一次不太正经的内心欲望小测试。别装了，你的每一次纠结，都在暗中标好了价格。即刻打印你的情绪消费账单。

## 二、 算法架构（维度积分制）
本次升级采用4维度雷达算法。每道题的不同选项将分别增加特定维度的分数（0-5分）。
- **Sen (Sensitivity / 敏感度)**：对他人眼光、外界评价的捕捉雷达。
- **Rum (Rumination / 反刍度)**：事后反复复盘、纠结、懊恼的严重程度。
- **Pls (Pleasing / 讨好度)**：为了迎合他人、维持关系而委屈自己的倾向。
- **Bnd (Boundary / 边界感)**：【反向指标】拒绝他人、保护自我能量的能力。

**算法判定优先级与兜底规则**：
1. 优先提取单一维度得分最高的属性，匹配对应结果。
2. 若某两项负面维度（如 Sen 和 Pls）均大于等于特定阈值，触发对应的双高复合结果（如【情绪海绵】）。
3. 若四个维度极度均衡（甚至全0或全低），触发兜底结果【精神守财奴】。

## 五、 产品页面规划（全栈架构）

- **`/` 首页**：便利店收银台风格背景，大标题“情绪内耗消费账单” + [拉出结账单开始测算] 主按钮。必须在介绍中明确写明该测试能帮你分析情绪内耗成分、测算社交压力与边界感。底部附加真实的参与人数提示（如：“当前排队结账人数：128 人”）；最底部常驻 [查看历史消费单] + [探索其他专柜] 入口。
- **`/test` 答题页**：沉浸式终端机UI。每次显示一题，带扫描线进度条。左上角永远固定为 [← 返回首页]；除第一题外，选项下方固定提供 [撤回上一条计费] 按钮。选项点击后有类似扫码枪的屏幕闪烁反馈，随后自动进入下一题；最后一题须有明确的提交按钮 [打印账单]，手动点击后才跳转。
- **`/explore` 矩阵导流页**：陈列其他心理测试专柜。
- **`/result/[id]` 结果页**：
  - 最上方展示“你是第 XXX 个结账完成的顾客”。
  - **直接采用单页完整排列，不再分双卡片左右滑动**。截图功能截取完整的单页内容。
  - 页面结构由上至下依次为：超长便利店小票（消费明细） -> 深度解析报告（包含四维度数据条、核心成因与破局建议） -> **测试结果池展示**（列出所有可能的小票类型）。
  - **沉浸式弹幕层（新增互动）**：结果页加载时，自动触发全屏横向飘过该结果专属的【预置强共鸣弹幕】。弹幕需设置为半透明（如透明度 60%），不阻挡下方小票文字的阅读，营造“无数人与我产生共鸣”的热烈氛围。
  - **截图分享防遮挡处理**：使用 html2canvas 等截图功能生成分享图片时，系统必须在截图前的瞬间临时隐藏弹幕层，确保生成的分享图中只包含干净、高颜值的小票报告，截取完毕后再自动恢复弹幕飘动。
  - 最底部固定为 [重新打印(重新测试)] 和 [查看更多专柜(更多测试)] 两个按钮。
