## 三、口音表（常量 · 每测试写一次）

> 口径见 SOP §零.5.1。**全量 10 个结果，一条不落**——无论本次走 A 发放率 / B 人工定 / C 全量哪条路线，选中的结果都在这张表里。**直接查表，不许现写。**
>
> 全部从 `lib/data.ts` 的结果定义（`danmaku` 优先，辅以 `quote` / `description` / `scenarios`）萃取，**未读任何历史发帖文案**。`danmaku` 是本测试最独特的素材字段，**它天然就是口音来源**。

| 结果名 | 这是个什么脾气的人 | 允许整活 |
|---|---|---|
| 人间铁壁 | 别人阴阳怪气，她一边吃薯片一边礼貌附和「确实确实」，转头就开了免打扰的人 | ✓ |
| 精神守财奴 | 刚想为一句无心的话纠结，一算「这事一小时亏 200 块」，立刻倒头就睡的人 | ✓ |
| 薛定谔的敏感 | 平时大大咧咧，对方少打一个「哈」就能自己演完八十集的人 | ✓ |
| 心软神明降临 | 拒绝的话在脑子里彩排了千百遍，对方眼神一失落，脱口而出的还是「好的」的人 | ✗ |
| 深夜复盘家 | 白天体面理性，一关灯就开始高清回放自己的黑历史、还顺手想出三句绝妙回怼的人 | ✓ |
| 情绪海绵 | 方圆五米的脸色她第一个察觉，听完别人的苦水自己堵三天、还嫌自己不够体贴的人 | ✗ |
| 灵魂透支大户 | 什么都没干也觉得累，连下楼拿快递、回一条消息都要攒半天勇气的人 | ✗ |
| 自我PUA带师 | 事办成 99% 也只盯着那 1%，外面没人骂她，她自己已经在心里批判过一万遍的人 | ✓ |
| 工伤级脆皮打工人 | 听到工作软件的提示音心里就一紧，周一早晨盯着天花板想「今天要是发烧就好了」的人 | ✓ |
| 情绪断电绝缘体 | 已读不回是家常便饭，远远看见熟人就提前五十米拐进便利店的人 | ✓ |

> **允许整活列（本测试口径）**：可整活档是**自嘲 / 解气**（见 SOP §2.4.1）。上表 7 条 ✓、3 条 ✗——判 ✗ 的是**真被耗空的三条**（`心软神明降临` / `情绪海绵` / `灵魂透支大户`），它们的痛是「没力气了」，玩梗会显得凉薄；✓ 的 7 条里，`人间铁壁` 的自嘲要换成**理直气壮**（画像 §三 明令不许给它写自嘲、也不许写委屈——它的整活落在「只要我没有道德，你就绑架不了我」这层阴阳上），`深夜复盘家` / `自我PUA带师` / `工伤级脆皮打工人` 则是自嘲档的正样本。

**与「口音基调」的关系**：基调是「自嘲宣告：先把自己钉上耻辱柱，再下台」，**十条口音里有八条在这个底色里**——它们都肯把自己摆上那张小票，当账单念给读者听（`本海绵精快被吸干了` / `对自己最狠的人原来是我自己` / `救救孩子吧`）。

**显式例外（写的时候必须换气口）**：

1. **`人间铁壁` 是唯一的硬例外**——它**不在**自嘲基调里。它的 `danmaku` 整段都是**别人**在围观（`羡慕这种顶级钝感力` / `求人间铁壁保佑我` / `请收下我的膝盖！`），它是**被羡慕的那一个**，不是上耻辱柱的那一个。**不许给它写自嘲，也不许给它写委屈**——它的底气是「关我屁事」和「只要我没有道德，你就绑架不了我」。
2. **两个半例外：`精神守财奴` / `情绪断电绝缘体`**——它们不钉自己，而是把「无所谓」当奖杯领（`这小票打印得没毛病` / `被说冷血但真的很舒服`）。它们是**理直气壮**，不是**自贬**：自嘲要收着用，靠「算得清」和「走得开」发力，别硬按它们低头。

## 五、红线清单（常量 · 每测试写一次）

> 口径见 SOP §零.5.3。通用表见 SOP §四，本表是**本测试摘录 + 专属弃用词**。落笔时对着本表看，不必回翻 SOP。
> ⚠️ **本测试是五个测试里术语密度最高的一个**（源数据含激素名、疾病名、诊断名、临床术语、量化生理指标），**本清单不许抽样，只能穷尽**。

### 5.1 三分区摘录

| 分区 | 本测试适用 | 处理 |
|---|---|---|
| ✅ **放行** | 夸张、自嘲、阴阳、身份讽刺 | 直接写，这是「野」的主要来源。本测试可用例：`年化错失职场无效八卦约 120 小时`（账单腔夸张）/ `只要我没素质，素质就绑架不了我`（阴阳）/ `精神离职祖师爷`（身份讽刺）/ `睡前批斗会VIP`（自嘲） |
| ⚠️ **控比例**（同一批 ≤ 三成） | 把领导 / 同事 / 伴侣 / 搭子 / 熟人设为靶子 | 可写，但**靶子必须对准「具体行为」，不许对准「某一类人」**——本测试的靶子素材是「下班前甩活」「群里只回一个微笑表情」「说话留半句让人猜」「拉你入圈质问你为什么不说话」。**不许升级为对整类人的判决**（`领导没一个好东西` / `同事全员恶人` / `亲戚都…`），也不许点名现实中的具体对象。另注：10 个结果**全部带 `vampires`（吸血对象）字段**，密度为本批最高——它写得再狠也只是**结果页文案**，抄进正文即变报告腔，**优先改写成对方的一个动作** |
| ❌ **不碰** | 脏话、性暗示、身体羞辱、医疗词 | 医疗词逐条列明：`确诊` / `解药` / `抑郁` / `治疗` / `处方` / `症状` / `药物` / `疗效` / `挂号` / `心理疾病`。**本测试另加五条同档禁词**：`PTSD` / `诊断` / `患者` / `自残` / `躯体化`（明细见 5.2） |

**三条口径澄清**（第一条是本测试最容易误杀、也最容易误用的地方）：

- **`焦虑` 与 `抑郁` 必须分开处理，两个词不是一档**：
  - **`焦虑` ＝日常叙述词，在非医疗主张语境下可用**。本测试源数据里真实出现三处（`全民焦虑内耗的时代` / `焦虑贩卖机` / `年化焦虑充值超 1,500 元`），写「这个全民焦虑的时代」没问题。**唯一条件是别写成主张句**——不写「焦虑症」「你会焦虑到××」，也不把焦虑当成某种后果来断言。
  - **`抑郁` ＝绝对红线，一个都不许出现**，`微笑抑郁` / `有点抑郁` / `抑郁情绪` 全部同档，与 `确诊` / `治疗` 并列。**本测试源数据里一次都没出现过 `抑郁`（已逐字比对）**——它一旦出现在文案里，就是执行时自己写进去的，不是素材带的。这正说明：`焦虑` 能用是因为素材里有，`抑郁` 不能用是因为**它连素材都没有，属于凭空收紧或凭空放毒的典型**。
- 日常叙述词（`生病` / `体检` / `感冒` / `头疼`）在非医疗主张语境下可用。`体检` 在本测试源数据里真实出现过（`借口"明天早起体检"丝滑买单离场`），照用无妨。
- **已日常化的 pop-psych 词可用，但只做主语句、不做判断句**：`内耗` / `讨好型人格` / `共情` / `巨婴` / `完美主义` / `打压` / `情绪劳动` 这些词已被日常口语吞掉——`讨好型人格破大防了` 就是本测试 `danmaku` 的**用户原话**，禁掉它等于把用户的话禁掉。**可用**，条件是别写成「你是××型人格」「你属于××倾向」这种**下诊断的句式**：那是报告腔，也是医疗腔的入口。

### 5.2 本测试专属弃用词

> 来源：扫 `lib/data.ts` 的 `results` 数组**原始字段值**（`description` / `quote` / `scenarios` / `hiddenCosts` / `danmaku` / `vampires` / `bestMatch` / `adviceList` / `tags`）逐条比对，**10 个结果全部过完**。
> 下表已按严重度排序：医疗/疾病词 → 临床/心理学术语 → 生理指标腔 → 报告腔书面词。**替代表述优先取同结果自身的真实字段词。**
> 凡「我记得这个不能用」的都已落到下表——**不要再靠记忆**。特别注意 `vampires` / `hiddenCosts` 这两个字段名：**名字是隐喻（吸血 / 账单），值里却真藏着疾病名**，必须看值。
