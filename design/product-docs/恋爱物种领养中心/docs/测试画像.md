**与「口音基调」的关系**：基调描述的是**说话方式**（粘与冷之间来回摆、一条消息就能翻面）。16 条里 **7 条天然在这个底色里**——噬元橘猫 / 护食幼狼 / 剧毒水母 / 脆皮洋桔梗 / 刺客猞猁 / 傲娇曼岛猫 / 沙漠耳狐，它们的「粘」与「冷」都是真的，**同一张卡内可以翻面**。

其余 **9 条是例外，显式标出，不要为了统一而扭曲结果本身的气质**：

- **只热不冷**（恒定输出型，没有翻面那一半）：`满电海獭` / `筑巢小燕子`——它们的温度是常亮的，硬加一句「忽冷忽热」等于改了它的病根；
- **只冷不粘**（恒定低温型，粘人那一面几乎不存在）：`幻影变色龙`（慢热 + 隐身，不是冷暴力）/ `装甲刺猬` / `极地白狼` / `暗夜猫头鹰` / `冰川雪豹`——它们是**从头到尾一个温度**，别给它们补一句撒娇；
- **恒温不翻转**（既不粘也不冷，是平的）：`慢热冬眠熊` / `待机水豚`——它们的「野」在**钝**，不在翻面。

## 五、红线清单（常量 · 每测试写一次）

> 口径见 SOP §零.5.3。通用表见 SOP §四，本表是**本测试摘录 + 专属弃用词**。落笔时对着本表看，不必回翻 SOP。

### 5.1 三分区摘录

| 分区 | 本测试适用 | 处理 |
|---|---|---|
| ✅ **放行** | 夸张、自嘲、阴阳、物种比喻、身份讽刺 | 直接写，这是「野」的主要来源。本测试可用例：`免费光源` / `情绪吸尘器` / `吸血鬼` / `消耗狂魔` / `老妈子` / `饲养员` / `露肚皮的专属特权` / `恋爱脑`（词本身可用） |
| ⚠️ **控比例**（同一批 ≤ 三成） | 把**具体的人**设成靶子 | 可写，但**靶子只能对准「关系没定义时的消耗行为」，不许升级成人格或群体**——本测试唯一合法的靶子是**暧昧对象 / 关系未定义期的对方**（对应题目 q1 深夜问候、q6 隐秘过往连结、q8 模糊公开），因为它指向「还没说清楚就先要人猜」，不指向任何群体；见下「三条靶子边界」 |
| ❌ **不碰** | 脏话、性暗示、身体羞辱、医疗词 | 医疗词逐条列明：`确诊` / `解药` / `抑郁` / `治疗` / `处方` / `症状` / `药物` / `疗效` / `挂号` / `心理疾病` |

**三条靶子边界**（本测试专属，⚠️ 档只在这里开口）：

- **父母 / 原生家庭：本测试没有这个靶子。** 16 个结果的成因**没有任何一条**归到父母身上——唯二沾到「童年」的是 `脆皮洋桔梗` 的 `description`（「童年或过往经历让你深信唯有看得见的物质才能抵御背叛」），而它讲的是**物质安全感**，并且原句已经把「过往经历」并列写出；`大女主觉醒测试` 的父母叙事**不许套到本测试**，套了就是跨测试换皮；
- **前任：只能当场景背景，不能当审判对象。** 数据源里前任只出现在 q2（「已结束的关系 / 陌生过客」），是给关系史做铺垫的。可以写「上一段留下的毛病」，**不许写成「前任毁了我」**；
- **性别群体：一律不许当靶子。** `redFlag` 字段里原样写着 `渣男`（橘猫 / 幼狼 / 桔梗）、`直男`（水母）、`心机男`（桔梗）、`暖男`（刺猬）——那是**结果页里对用户的单人提醒**，语气是「远离这一类」，主词是**行为**（冷暴力 / 画大饼 / 抠搜算计），不是性别。文案侧把「渣男」扩写成「男人都……」会让本测试 16 个结果里一半的冷感慕强型用户（`装甲刺猬` / `极地白狼` / `暗夜猫头鹰` / `冰川雪豹`）当场划走。要写就写行为：「半天不回消息的人」「光说不做的人」。

**三条口径澄清**：

- 日常叙述词（`生病` / `体检` / `感冒` / `发烧`）在**非医疗主张语境**下可用；
- 本测试 `radar` 的 `distance` / `expression` / `core` / `focus` 是**结果页图表维度名**，`hiddenCost` 的 `S级` / `年化消耗 82% 情绪电量` / `恋爱脑中毒指数：92%` 是**结果页刻度**——两者写进正文都会变成报告腔，**文案侧一律不取**（见 5.2）；
- 结果名 `剧毒水母` 里的「毒」是**物种比喻**，不是医疗词，标签位与正文可用（门禁 #14 只管封面与标题）。

## 六、本测试专属注意

> **字段结构提醒**：本测试 `tags` 是**数组**（3 个，自带 `#`）；`radar` 是 **object**（不是数组），取值方式与 `name`/`value` 型数组不同，须按真实结构读。
> `emoji` / `redFlag` / `careGuide` / `hiddenCost` 可作补充素材。

- **本测试底层是「领养」隐喻**：结果 = 物种 = 待领养的生命，**文案要有「被领养」的可爱感**，不要写成冷冰冰的依恋类型诊断；
- **`breakdownScenes` 是模式三的主素材**（崩场面的真实场景），`behavior` 是模式四的主素材（怪癖暗号）；
- 口音基调是**猫系**——粘与冷只隔一条消息，**同一张卡内可以允许情绪翻转**，这是本测试独有的「野」；
- 结果数 16，主推 6（其余 10 走 SOP §六 长尾降级）。

### 6.1 数据源两处结构异常（落笔前先知道）

- **`emoji` 有重复**：`护食幼狼`(r2) 与 `极地白狼`(r12) 同为 `🐺`；`满电海獭`(r3) 与 `待机水豚`(r15) 同为 `🦦`。**封面/配图侧不要靠 emoji 区分这四个结果**，要靠结果名与物种形象（海獭 vs 水豚、幼狼 vs 白狼）；
- **`脆皮洋桔梗`(r6) 不是动物**：其余 15 个结果都是动物，只有它是植物（洋桔梗），`emoji` 为 `🥀`。写「领养」隐喻时**不要硬给它安动物身份**，按数据源原样写「一株花」即可。
