# 《命定恋人》测试产品方案（全栈大盘融入版）

## 一、 产品定位与包装

- **测试主题**：测算你命中注定的理想另一半类型。
- **目标受众**：单身渴望恋爱的人群；恋爱中想要验证对方是否是“对的人”的人群。
- **核心隐喻**：**【红娘档案卡 / 月老办事处】**（视觉采用**玉牌签文式**极简现代新中式风格）
  - **大标题**：《月老办事处：解密你的命定恋人档案》
  - **引导文案**：“你是否曾在夜里幻想过那个‘对的人’究竟是什么模样？TA 是像你一样喜欢安静，还是能带你探索世界？是你的避风港，还是并肩作战的战友？不管你现在是单身还是恋爱中，月老办事处的姻缘簿上早已记录了那份命中注定的羁绊。花 3 分钟完成这份灵魂问卷，解锁专属于你的【红娘档案卡】。”
  - **UI 包装语境**：将“开始测试”包装为“翻开姻缘簿”，将“生成报告”包装为“抽取档案卡”。
  - **前置交互**：测试开始前增加【身份录入】环节，要求用户输入**称呼**并选择**当前状态（单身/恋爱中）**，该信息将贯穿测试并在结果页生成专属文案（如“王小明的姻缘签”）。

---

## 二、 算法与维度设计（维度积分制）

测试不再沿用 B站 原本的单纯树状图（因为缺失结果端数据，且分支不易于扩展到20题），而是采用**维度积分制**。
评估“理想伴侣”的 4 个核心维度：

1. **引领 (L) vs 守护 (G)** - 倾向找带领自己的人，还是默默陪伴自己的人？
2. **直球 (D) vs 细节 (S)** - 喜欢热烈直接的表达，还是细水长流的细节关怀？
3. **冒险 (A) vs 居家 (C)** - 想要一起探索世界的新鲜感，还是宅家追剧的安全感？
4. **浪漫 (R) vs 务实 (P)** - 追求灵魂共振与仪式感，还是柴米油盐的烟火气？

- 共 20 题，每个维度 5 题。
- 每题 2 个选项，分别对应维度两端的 +1 分。
- 最终根据四个维度的倾向，组合出 8 种最具代表性的“命定恋人”类型。

## 三、 题库设计（20 题）

> 交互要求：选项无明显规律，每题下方提供 [撤回上一题] 按钮。

**【维度 1：引领 vs 守护 (L/G)】**
1. 遇到突发的棘手问题，你更希望你的另一半：
   - A. 冲在前面，直接帮你把事情解决好。（L+1）
   - B. 陪在你身边，安抚你的情绪并给你支持。（G+1）
2. 周末出去约会，你通常更喜欢：
   - A. 对方已经做好了完美的攻略，我只要跟着走就行。（L+1）
   - B. 两个人一起商量，或者随性一点走到哪算哪。（G+1）
3. 在感情中，你觉得哪种感觉更吸引你？
   - A. 崇拜感：TA 在某个领域闪闪发光，让我仰望。（L+1）
   - B. 归属感：在 TA 面前我可以卸下所有伪装，做个小孩。（G+1）
4. 当你们对某件事产生分歧时，你倾向的解决方式是：
   - A. 听有理的一方，只要 TA 能说服我，我就听 TA 的。（L+1）
   - B. 先照顾彼此的感受，互相妥协找个折中方案。（G+1）
5. 你理想中的副驾体验是：
   - A. TA 稳稳地开车，我只管放心睡觉或切歌。（L+1）
   - B. 两人一路上有说有笑，偶尔我还会帮 TA 看看导航。（G+1）

**【维度 2：直球 vs 细节 (D/S)】**
6. 对方做什么会让你瞬间心动？
   - A. 大方地当众表达对我的偏爱，从不掩饰。（D+1）
   - B. 悄悄记住了我随口提过的小喜好，并给了我惊喜。（S+1）
7. 吵架冷战后，你更吃哪一套求和方式？
   - A. 直接一个拥抱，或者发一大段真诚的道歉小作文。（D+1）
   - B. 默默给你点了一杯你爱喝的奶茶，或者帮你把乱糟糟的房间收拾好。（S+1）
8. 对于“我爱你”这句话，你的态度是：
   - A. 爱就要大声说出来，每天听都不会腻。（D+1）
   - B. 说不说无所谓，只要行动上能让我感觉到就行。（S+1）
9. 两人一起散步时，你更喜欢的小互动是：
   - A. 突然把你拉进怀里或者十指紧扣。（D+1）
   - B. 默默让你走在马路内侧，或者帮你理好被风吹乱的头发。（S+1）
10. 如果对方想送你礼物，你更希望：
    - A. 直接问我最近想要什么，然后给我买。（D+1）
    - B. 通过平时的观察，偷偷准备一个我觉得很实用的东西。（S+1）

**【维度 3：冒险 vs 居家 (A/C)】**
11. 难得的小长假，你们更可能怎么度过？
    - A. 去一个没去过的城市旅行，体验当地的风土人情。（A+1）
    - B. 窝在家里看电影、做饭，享受只有两个人的慢时光。（C+1）
12. 到了晚上 10 点，突然觉得肚子饿，你希望对方：
    - A. 走！我们穿上外套去吃那家很火的夜市烧烤！（A+1）
    - B. 别折腾了，我去厨房给你煮碗热腾腾的面吧。（C+1）
13. 你向往的约会场景更偏向：
    - A. 去游乐园玩过山车、去听livehouse、或者去滑雪。（A+1）
    - B. 去安静的咖啡馆待一下午，或者一起逛逛宜家。（C+1）
14. 在布置你们共同的家时，你觉得哪个区域最重要？
    - A. 一个巨大的展示柜或者充满科技感的电竞/娱乐房。（A+1）
    - B. 一张极其舒服的大沙发或者温馨的开放式厨房。（C+1）
15. 面对生活中突然出现的变化（比如突然下大雨），你希望对方：
    - A. 觉得很刺激，拉着你在雨中狂奔或者立刻找个有趣的地方避雨。（A+1）
    - B. 马上拿出备用伞，或者带你去买热饮驱寒。（C+1）

**【维度 4：浪漫 vs 务实 (R/P)】**
16. 恋爱一周年纪念日，你更期待：
    - A. 一场精心布置的烛光晚餐和一束巨大的玫瑰。（R+1）
    - B. 对方给你清空了购物车里纠结很久没舍得买的实用物品。（P+1）
17. 你觉得维系一段长久关系，最重要的是：
    - A. 始终保持心动的感觉和精神上的共鸣。（R+1）
    - B. 生活步调一致，能把日子过得安稳妥帖。（P+1）
18. 当你在工作中受了委屈抱怨时，你希望伴侣：
    - A. 跟你同仇敌忾，坚定地站在你这边为你提供情绪价值。（R+1）
    - B. 在安慰你之后，帮你理性分析问题并给出解决方案。（P+1）
19. 对方的什么特质最让你觉得有魅力？
    - A. 有有趣的灵魂，脑子里总有奇奇怪怪的好点子。（R+1）
    - B. 情绪稳定，办事靠谱，凡事都有交代。（P+1）
20. 想象一下未来，最让你觉得幸福的画面是：
    - A. 两个人老了以后，还能像小年轻一样牵手去环游世界。（R+1）
    - B. 下班回家，推开门看到桌上有一桌热饭菜。（P+1）

## 四、 测试结果池（8 种档案卡）

根据上述 4 个维度得分的组合（如 L+S+C+P），映射出 8 种命定恋人档案。

### 1. 【爹系/妈系守护者】 (G + S + C + P为主)
- **核心称号**：全方位人生兜底专家
- **属性标签**：#细节狂魔 #情绪稳定 #无限包容
- **雷达图建议**：陪伴感 95% / 安全感 100% / 惊喜度 70% / 掌控力 85%
- **深度解析**：你的命定恋人是一个能为你的人生“兜底”的人。你内心深处其实有些缺乏安全感，容易精神内耗，而 TA 就像一座沉稳的大山。TA 不会整天把爱挂在嘴边，但会在下雨时为你撑伞，在你熬夜时给你倒杯热牛奶。和 TA 在一起，你永远不需要长大，只需安心做个被宠坏的小孩。
- **总结金句**：“这世界兵荒马乱，而我是你永远的避风港。”

### 2. 【霸道直球引领者】 (L + D + A + P为主)
- **核心称号**：人生副本满级代练
- **属性标签**：#执行力拉满 #专属偏爱 #男友/女友力MAX
- **雷达图建议**：带领度 100% / 行动力 95% / 细腻度 60% / 浪漫度 80%
- **深度解析**：你容易纠结，面对选择时常感到迷茫。你的命定恋人是一个极具决断力和领导力的人。TA 喜欢打直球，爱意表达热烈且从不吝啬。遇到困难时，TA 会一把将你护在身后，替你扫清障碍。TA 享受被你依赖的感觉，而你也会沉溺于 TA 那种“一切有我”的霸道温柔中。
- **总结金句**：“不用去想明天该怎么办，你只要牵紧我的手。”

### 3. 【灵魂共振艺术家】 (G + S + C + R为主)
- **核心称号**：午夜电台的同频听众
- **属性标签**：#精神洁癖 #极度懂你 #浪漫至死
- **雷达图建议**：精神契合 100% / 浪漫度 95% / 烟火气 60% / 行动力 75%
- **深度解析**：你是一个内心世界极其丰富的人，对你来说，懂比爱更重要。你的命定恋人不是世俗意义上的“完美伴侣”，却能精准地接住你每一个奇奇怪怪的梗。你们可以彻夜长谈，可以为了看一场日出毫不犹豫地出发。TA 懂你的奇奇怪怪，也陪你一起可可爱爱。
- **总结金句**：“别人关心你飞得高不高，而我只关心你的灵魂是否轻盈。”

### 4. 【阳光开心果】 (L + D + A + R为主)
- **核心称号**：随身携带的抗抑郁药
- **属性标签**：#永远热枕 #直白狗狗 #活力爆棚
- **雷达图建议**：提供情绪价值 100% / 活力值 95% / 稳重度 60% / 浪漫度 85%
- **深度解析**：你有时会陷入低气压，需要外界的能量来激活自己。你的命定恋人就像个不知疲倦的小太阳，永远充满活力。TA 会拉着你去尝试各种新鲜事物，把平淡的日子折腾得闪闪发光。TA 的爱热烈、坦荡、没有杂质，能驱散你生命中所有的阴霾。
- **总结金句**：“就算世界大雨滂沱，我也要拉着你在水坑里跳舞。”

### 5. 【温润如玉白月光】 (G + D + C + R为主)
- **核心称号**：岁月静好的具象化
- **属性标签**：#温柔刀 #同理心 #白月光
- **雷达图建议**：温柔度 100% / 情绪稳定 90% / 刺激度 50% / 浪漫度 85%
- **深度解析**：你经历了世事喧嚣后，最渴望的是一份宁静。你的命定恋人性格温和，说话轻声细语，永远能用最温柔的方式化解你的戾气。TA 会直白地表达对你的欣赏，把你们的小家布置得温馨且充满诗意。在 TA 身边，你的心跳会不由自主地慢下来。
- **总结金句**：“我不求波澜壮阔，只愿与你共赏每一个寻常黄昏。”

### 6. 【势均力敌野心家】 (L + S + A + P为主)
- **核心称号**：顶峰相见的王牌搭档
- **属性标签**：#智性恋 #搞钱搭子 #势均力敌
- **雷达图建议**：成长值 100% / 务实度 95% / 黏人度 40% / 默契度 90%
- **深度解析**：你是一个有追求、有野心的人，比起依附，你更渴望并肩作战。你的命定恋人同样优秀且独立。你们不仅是恋人，更是人生的合伙人。你们不会整天黏在一起互诉衷肠，但能在工作遇到瓶颈时互相点拨。你们在各自的领域闪闪发光，然后在顶峰热烈相拥。
- **总结金句**：“最好的爱情不是互相凝视，而是望向同一个远方。”

### 7. 【反差萌欢喜冤家】 (L/G均衡 + D + C + R为主)
- **核心称号**：相爱相杀的损友
- **属性标签**：#毒舌嘴硬 #护短狂魔 #反差萌
- **雷达图建议**：趣味度 100% / 欢乐度 95% / 正经度 50% / 宠溺度 85%
- **深度解析**：你的生活不能缺少乐趣。你的命定恋人表面上可能总是喜欢损你、逗你，经常和你斗嘴，但实际上是个超级护短的“醋王”。别人说你一句不好 TA 能当场急眼。你们的关系轻松没有包袱，每天都在相爱相杀中度过，但关键时刻，TA 永远是你最坚定的后盾。
- **总结金句**：“虽然你经常气我，但我还是最喜欢你。”

### 8. 【细水长流经济适用型】 (G + S + C + P 极端偏好)
- **核心称号**：人间烟火的掌勺人
- **属性标签**：#顾家好手 #精打细算 #踏实靠谱
- **雷达图建议**：靠谱度 100% / 居家值 100% / 浪漫度 40% / 责任感 95%
- **深度解析**：你是一个极其务实的人，不相信所谓的虚无缥缈，只相信看得见摸得着的温暖。你的命定恋人可能不懂什么是仪式感，不会制造浪漫惊喜，但每个月按时上交工资，每天下班准时回家做饭。TA 用最朴实的行动，为你构建了一个最牢不可破的堡垒。
- **总结金句**：“爱不仅在风花雪月中，更在柴米油盐的香气里。”

*(兜底规则：算法自动根据得分最高的前两个维度特征匹配结果，平局时默认匹配【爹系/妈系守护者】)*

## 五、 页面规划（融入大盘版）

所有页面将在 `design/test-platform` 体系内完成，整体视觉采用 **玉牌签文式（极简现代新中式）**：

- **`/ (首页与身份录入)`**：展示测试大标题、引导文案。点击“翻开姻缘簿”后，弹出或平滑切换至身份录入表单（收集称呼与单身/恋爱状态）。
- **`/test (答题页)`**：
  - **交互体验三合一**：采用极简纯文字全屏卡片式左滑切换；顶部常驻进度条；点击选项时附带“古风盖章/打钩”微动效反馈；并且随着题目维度的变化（如从“冒险维度”切到“浪漫维度”），背景底色/国风底纹会发生平滑过渡，缓解 20 题的视觉疲劳。
  - 左上角提供返回大厅，选项下方提供撤回按钮。
- **`/result (结果页)`**：获取档案卡动效，展示生成的红娘档案。视觉呈现为细长的玉牌/签文样式，文案动态插入用户称呼，并在深度解析中根据其恋爱状态进行微调。包含雷达图与底部返回大厅及分享按钮。
