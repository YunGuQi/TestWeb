**与「口音基调」的关系**：基调是「甜宠直球：把喜欢说得不害臊」，上表 12 条都落在这个底色里。**四条明确例外，不许为了统一而改写成热烈直球腔**：

- **清冷隐世策士**——源数据原话就是「不擅言辞」「清冷疏离、少言寡语」，他的甜是「润物细无声」，写成「我喜欢你我天天说」会当场失真；
- **温柔托举者**——源数据明写「TA 的爱内敛而克制」，他只做不说，甜度在「让」而不在「说」；
- **顶峰并肩者**——源数据明写「你不需要黏腻窒息的依赖」，他的甜是把喜欢放进并肩里，不是放进情话里；
- **灵魂知音**——源数据明写「甚至不需要过多语言」，基调里的「说」在他身上是多余动作。

这四条**只调低「说出口」的音量，不调低甜度**——甜照样给，只是换成动作。其余 12 条（尤其炽热破风者、破冰直球手、傲娇护短狂魔）是基调的正样本，直球可以打到最满。

## 五、红线清单（常量 · 每测试写一次）

> 口径见 SOP §零.5.3。通用表见 SOP §四，本表是**本测试摘录 + 专属弃用词**。落笔时对着本表看，不必回翻 SOP。

### 5.1 三分区摘录

| 分区 | 本测试适用 | 处理 |
|---|---|---|
| ✅ **放行** | 夸张、自嘲、阴阳、身份讽刺 | 直接写，这是「野」的主要来源。本测试可用例（均由源数据真实字段长出）：`双标怪` / `超级醋坛` / `情绪充电宝` / `暧昧修罗场` / `火葬场` |
| ⚠️ **控比例**（同一批 ≤ 三成） | 靶子只有三类可立：**已经翻篇的前任**、**只暧昧不表白的人**、**让你将就的错的人**——源数据 `redFlags` 原生支持（「在感情中拉扯前任、不清不楚」「欲擒故纵的拉扯游戏」） | **两类靶子绝对不立**：① **16 个结果本体**。它们就是用户自己的「命定恋人」，踩结果等于踩用户；且 16 条里有 `清冷隐世策士` / `温柔托举者` / `顶峰并肩者` / `灵魂知音` 四条气质偏冷，写成「不这样的都不叫爱」会让他们当场划走。② **用户自己**。本测试原生情绪是甜不是惨，写成「你有问题所以你才需要被爱」立刻掉进卖惨 + 报告腔。**自嘲（放行档）可以，自我贬低不行** |
| ❌ **不碰** | 脏话、性暗示、身体羞辱、医疗词 | 医疗词逐条列明：`确诊` / `解药` / `抑郁` / `治疗` / `处方` / `症状` / `药物` / `疗效` / `挂号` / `心理疾病`。**本测试源数据实际命中** `解药`（`终极解药`）/ `良药`（`岁月良药`、`心灵良药`）/ `药`（`安神药木香`）/ `剂`（`镇定剂`、`唤醒剂`）——已逐条进 5.2 配好替代 |

**三条口径澄清**：

- 日常叙述词（`生病` / `焦虑` / `体检`）在**非医疗主张语境**下可用——本测试源数据里 `生病`（r_gscp `description` / `loveAdvice`）、`焦虑`（r_gdcr `description`）都属于此类；
- `治愈`（r_gdcr `firstMeet.smell` 的「温暖治愈香」、r_ldcp `synergy.karma` 的「治愈生活琐碎失序」）作为日常形容词可用；但一旦接上「你的 XX」把**人**写成待治的**症状**，就不再是日常语，进 5.2；
- 本测试的 `radar.label` 是 `安全感` / `陪伴感` / `惊喜度` / `掌控力`——它们是**结果页图表用语**，写进文案正文会变成报告腔，**文案侧不取**（见 5.2）。

## 六、本测试专属注意

- **本测试的原生情绪是「甜」，不是「惨」**：`破防 / 解气 / 冷笑 / 认命` 这套创伤四档**严禁套用**，会写出一堆该甜的文案在哭；
- **`redFlags` 是本测试的独门武器**：把危险信号写成「暗号」而非「说教」，是模式四（怪癖暗号）的主要素材；
- `firstMeet`（初次相遇场景）是模式三（生活痛点 → 改写为「生活高光」）的首选素材；
- 结果数 16，主推 6（其余 10 走 §六 长尾降级）；
- **源数据里的医疗词与报告腔词见 §五 红线清单**——已逐条固化并配好替代，不要再靠记忆。
