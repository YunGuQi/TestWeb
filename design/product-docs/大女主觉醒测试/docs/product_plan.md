# 原生家庭人生剧本测试 - 产品方案与题库精算模型

## 一、 核心定位与产品包装
- **测试主题**：原生家庭人生剧本测试（测测原生家庭对你的性格与人生底色影响有多大）
- **目标受众**：受原生家庭困扰、高内耗、讨好型、安全感缺失、寻求心理自我和解的年轻群体。
- **视觉隐喻**：童年记忆档案袋 / 心理诊断与人生剧本解析卡。
- **分享噱头标题**：【原生家庭测试】你骨子里的性格创伤与天赋，原来童年早就写好了剧本！
- **引导文案**：讨论原生家庭不是为了怪罪父母，而是为了看清自己身上的性格烙印，学会接纳并重塑属于自己的独立人生。

## 二、 底层算法与精算模型（单轴累积积分制）
- **计分维度**：`数值1`（原生家庭性格创伤/受影响程度指数）
- **题库总数**：15 道题
  - **8 道情境画像题**：Q1 ~ Q7、Q9（不计入分值变量，用于快速破冰、激活童年回忆、建立心理投射与代入感）。
  - **7 道核心计分题**：Q8、Q10、Q11、Q12、Q13、Q14、Q15（精确量化家庭创伤、情感卷入、反向支持度与边界感）。
- **分值精算区间**：
  - 最低理论分：`1 + 1 + 1 + 1 + 1 + 1 + 1 = 7分`
  - 最高理论分：`7 + 5 + 7 + 7 + 7 + 7 + 7 = 47分`
