## 五、红线清单（常量 · 每测试写一次）

> 口径见 SOP §零.5.3。通用表见 SOP §四，本表是**本测试摘录 + 专属弃用词**。落笔时对着本表看，不必回翻 SOP。

### 5.1 三分区摘录

| 分区 | 本测试适用 | 处理 |
|---|---|---|
| ✅ **放行** | 夸张、自嘲、阴阳、身份讽刺 | 直接写，这是「野」的主要来源。本测试可用例：`免费保姆` / `我的善良没编制` / `情绪垃圾桶` / `孝顺KPI` |
| ⚠️ **控比例**（同一批 ≤ 三成） | 把父母 / 亲戚设为靶子 | 可写，但**靶子必须对准「关系模式」，不许对准父母这个人**——6 个结果里 1 号是「被爱浇灌的阳光剧本」、5 号是「积极正向的言传身教」，全盘否定父母会让这两类用户当场划走 |
| ❌ **不碰** | 脏话、性暗示、身体羞辱、医疗词 | 医疗词逐条列明：`确诊` / `解药` / `抑郁` / `治疗` / `处方` / `症状` / `药物` / `疗效` / `挂号` / `心理疾病` |

**两条口径澄清**：

- 日常叙述词（`生病` / `体检` / `焦虑`）在**非医疗主张语境**下可用；
- 本测试的 `radar.subject` 里带「焦虑」「孤独」「疏离感」这类词——它们是**结果页图表用语**，当文案正文写出来会变成报告腔，**文案侧不取**（见 5.2）。

### 5.2 本测试专属弃用词

> 来源：扫 `family-origin-data.ts` **原始字段值**（`acquiredTrait` / `content` / `tags` / `radar` / `antidoteList` / `attachmentType`）逐条比对，**已穷尽**。
> 凡「我记得这个不能用」的都已落到下表——**不要再靠记忆**。

| 弃用表述（源数据原文） | 出处字段 | 文案侧替代表述 |
|---|---|---|
| `微笑抑郁的孤独者` | r4 `acquiredTrait` | **命中医疗绝对红线**。改用同结果真实 `tags` 的「微笑面具」→ 文案里写「笑得最懂事的那个」 |
| `情感解离` | r6 `content` | 临床术语，且是报告腔 → 「早早就把自己的情绪关了机」 |
| `灾难化反刍` | r2 `antidoteList` | 临床术语 → 「一件事在脑子里翻来覆去地放」 |
| `情绪透支` | r4 `content` | 书面腔 → 「被自己耗空」 |
| `安全型 (100%)` / `安全型 85% + 焦虑型 15%` / `焦虑-矛盾型` / `回避型` / `混乱型（焦虑 + 逃避）` | `attachmentType`（6 条全中） | 依恋类型是**分类学术语**，文案侧一律不取用。要表达同一意思就写生活话：「怕被丢下」「习惯先撤」「不敢靠太近」 |
| `讨好倾向` / `疏离感` / `情感淡漠` / `不善表达` | `radar.subject`（r4 / r2 / r6） | `radar` 维度名是**结果页图表用语**，进正文即变报告腔 → 换成动作或场景描写（「别人一叹气我就先认错」） |
