# 04 — 关键词收敛为 leading word

**What to build:** 同一条要求散在多处复述的，收敛成一个词；文档里出现这个词，AI 就调出整片行为——不必每次把整句重述一遍。

现状（已核实）：

- 「钩子原句整句照抄／不许改写／不许砍成共用前缀」在 **3 个文件** 各说一遍（`SKILL.md` / `03` / `04`）
- `停机` 在 `SKILL.md` 出现 **7 次**、`问用户` **6 次**（合计 13 处）

**Blocked by:** 03 — 需先完成命名空间收口，以免在同一批里改到同一个标题结构。

**Status:** ready-for-agent

- [ ] 为「钩子原句整句照抄／不许改写／不许砍成共用前缀」定**一个 leading word**（建议「**钩子照抄**」），并给出它的一句话定义
- [ ] 该词统一定义**只在一处**；`SKILL.md` / `03` / `04` 的原有 3 处长句改写为**使用该词**（保留各处特有的补充，如"末行是钩子时以钩子为准"）
- [ ] `停机`／`问用户` 的 13 处收敛到**闸门那一节一处**详述，其余处改为引用（保留"哪一步要停机"这种必要信息，删掉重复的纪律复述）
- [ ] 收敛后的闸门语义**不得弱化**：开工前 1 次（A/B/C 选择）+ 交付后 1 次（汇报）两个交互点必须仍然明确可辨
- [ ] 全文搜「不许砍成共用前缀」类长句，确认**只剩定义处一处**
- [ ] 未引入新术语（只用已有的、模型预训练里就有的词），不造生词
- [ ] 三册相对链接全部可达；生成器退出码 0、体积 **≤20000 字符**
- [ ] **抽注检验**：若被收敛的内容落在抽取切片内，改真源后重生成须跟上

**本笔不做**：P1 那批（`description` 身份串瘦身、作废形态否证、开头 no-op 半句）；否证密度系统改写
