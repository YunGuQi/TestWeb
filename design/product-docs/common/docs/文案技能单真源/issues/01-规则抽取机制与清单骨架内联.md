# 01 — 规则抽取机制落地：清单与骨架改为运行时内联

**What to build:** 执行者拿到的自检清单与四模式骨架，**不再是从代码里手抄的副本**，而是每次生成时从分册真源里抽出来的原文。改分册里的一句话，重新生成的工作包就跟着变——不需要任何人记得去同步第二处。

本笔工单建立**抽取机制**并把两个已实证漂移的对象（清单、骨架）作为首批应用。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 在 `references/03_红线与门禁.md` §七 自检清单外加上抽取标记（注释形态，渲染后不可见）
- [ ] 在 `references/01_双位与正文.md` 与 `references/02_四模式.md` 的骨架表格外加上抽取标记
- [ ] 生成器在运行时读文件、抽切片、内联；**手抄副本从代码里删除**（不留 fallback 副本）
- [ ] 抽取标记缺失或切片为空时，生成器**以非零退出码失败并报出缺失的标记名**；不许静默内联空内容
- [ ] 四个 0 词表（`03 §7.2`）在本笔中**保持现状不动**（留给工单 02）——避免同笔改两套机制
- [ ] **抽注检验通过（正向）**：在清单真源里插一个唯一哨兵串 → 重新生成 → 断言哨兵出现在工作包对应位置
- [ ] **抽注检验通过（反向）**：把真源某句改成另一个唯一串 → 重新生成 → 断言产物里**旧串已消失**
- [ ] 哨兵已撤销，真源与产物无残留测试痕迹
- [ ] 生成器退出码 0；工作包体积 **≤20000 字符**（抽取不得把包撑爆）
- [ ] `01` / `02` / `03` 三册的**人类可读性未受损**：标记以注释形态存在，正常阅读与渲染都不显示
- [ ] 三册相对链接仍全部可达
- [ ] 分册里加了标记的位置**有注释说明标记用途**，便于下次新增规则时知道要加标记

**本笔不做**：词表与机器常量（02）、命名空间与矛盾指针（03）、关键词收敛（04）
