### 1.4 ⚠️ junction 的绝对路径约束（必须留档）

Windows 目录联接（junction）**存的是绝对路径**，不支持相对目标。本次两个链接的目标都是：

```
E:\AI\Antigravity\小红书\.agent\skills
```

**后果：仓库换盘符（E: → 其他）或整体移动目录后，两个链接会指向旧位置并失效。** 处置：

- 自查：`node "./link-skills.js" --check` → 会报「是链接但指向错误：<旧路径> ≠ <新路径>」；
- 修复：不带参数重跑 `node "./link-skills.js"`（或双击 `技能超链接化.cmd`）→ 删旧链接、按当前盘符重建；`.agent/skills` 的内容不受影响。

### 1.5 一键脚本（本次落到仓库根，并修掉一个致命 bug）

| 文件 | 作用 |
|---|---|
| `./link-skills.js` | 建/修两处 junction。幂等；**只改名不删除**；建链接或穿读失败自动回滚；`--check` 只读验证 |
| `技能超链接化.cmd` | 双击包装（关 IDE 提示 + `node` 调用 + 暂停看结果） |

**修掉的致命 bug（原 `.scratch/link-skills.js` 会让本工单永远做不成）**：原脚本的穿读探针指向 `xhs-auto-operator-v7/references/03_笔记文案篇.md`，而该文件已被工单 02 删除 → 链接建成后探针必然失败 → 被误判为「穿读校验失败」→ **自动回滚**，`.claude/skills` 永远转不过去。

本次一并加固：

1. 探针换成真实存在的 `xhs-note-copywriter/SKILL.md` + `scripts/gate.js`；**探针本身不存在则提前中止、一个目录都不碰**；
2. 校验由 `existsSync` 升级为**三路逐字节 md5 比对**；
3. 新增 `--check` 只读模式（不新增任何副作用即可复验）；
4. 新增「已是链接但 realpath ≠ 源」→ 重建分支（换盘符修复路径，原版会 skip）；
5. 源目录自检：`.agent/skills` 本身若是链接则直接停机（防成环）。
