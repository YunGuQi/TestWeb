## 落地口径（执行时新增的判断，供后续工单沿用）

1. **清单收敛＝「文档定词、脚本照抄，双侧自动对账」**（决策 1 选乙）。`03_红线与门禁.md` §七 是**唯一真源**；`gate.js` 的 `PROD` / `TERM` / `MED` / `BAN` 四个数组是**同名执行副本**。理由：门禁是交付闸门，若改成运行时解析 Markdown 表格，表格一改格式闸门就瘫痪；改为**真源 + 副本 + 双向一致性校验**，格式变动只会让校验报 ❌，而不会让判据静默失效。**谁多一个词都当场报 ❌**。
2. **校验的兜底口径**：词表校验**不靠"是否包含"靠"是否相等"**。某一行若因表格改版匹配不上，那一侧取到空集 → 同样报 ❌，**不会静默放行**（这是本工单刻意留的失效模式：宁可误报，不许空转）。
3. **`第X页` 写成占位形态**：门禁表里写 `第X页`（X = 任意数字，含中文数字），脚本侧用 `RE_OF` 表把占位词映射成正则 `/第[0-9Xx一二三四五六七八九十]+页/`。**不再写死 `第5页`**——旧写法会漏掉 `第3页` / `第七页`，且每批文案页数不同，写死必漂移。同理，脚本里所有词表匹配改走 `hitW()`（有正则用正则，无正则用 `includes`），`#5/#6/#10/#11` 与 `W()`、`all` 判定全部统一。
4. **跨册 `§` 引用一律带册名**（决策 2）：跨册写 `` `03_红线与门禁.md` §七 ``（纯文本册名，不链接）；**本册内裸引**（`§2.6`）；**导航位**（章节地图 / 索引"去哪"栏 / 完成判据）写 Markdown 相对链接让 lint 看住。理由：`§X` 不携带册信息，册一旦拆细就全会指错；而正文叙述里全链接会污染可读性。
5. **emoji 唯一真源定在 `03_红线与门禁.md` §七 #23 的作用域注解**，其余各处只许引用。注解里显式承认两条作用域并存且不矛盾：① **卡片本体**（封面/标题/正文/标签）按档配额；② **评论区首条**（`04_分发与排期.md` §五 第二道，写法在 `00_画像与档位.md` §零.5.2）按原样保留 emoji / 方括号表情。
6. **测试术语 #6 的表格改写成令牌写法**：`「测出/测完/测了」` → `` 测试术语（`测出`/`测完`/`测了`） ``。这是为了让 #6 也能被词表校验抓到（校验按反引号令牌取词），顺便把「全卡任何位置，含封面与标题」的口径留在同一行。
