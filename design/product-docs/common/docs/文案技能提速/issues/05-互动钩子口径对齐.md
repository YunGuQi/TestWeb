# 05 — 互动钩子口径对齐：填词库原句 + 句式不许全批复用

**What to build:** 互动钩子配额不再因「同义改写」漏判，也不再让固定句式自己吃掉「跨卡重复」配额。

**Blocked by:** 02 — 分配表生成器与计划级预检

**Status:** ready-for-agent

- [ ] 分发与排期册的「互动钩子配额」小节里，四种形态的示例**改成门禁词库里的原句**（找同类用 `有没有人`，而不是 `有没有同款`）
- [ ] 该小节补一条口径：**同一钩子句式不许全批复用**；给出轮换做法（同一结果内四个钩子形态不重复；跨结果时句式分散）
- [ ] 分配表生成器排「钩子形态」列时，同时排「互动钩子原句」，且全批**同句最多复用 2 次**
- [ ] 计划级预检器新增一条检查：全批互动钩子原句的**最大复用次数 ≤2**，超出报 ❌
- [ ] 补一条背景说明：固定句式会与「跨卡重复整句 ≤5 条」配额互相挤压（改造前真实批次：3 条重复里 3 条都是钩子句）
- [ ] 回归验证：故意把 6 张卡的钩子原句都写成同一句，预检必须判失败
- [ ] 回归验证：P1 分配表（钩子原句已轮换）预检通过
- [ ] 回归验证：合并稿的「跨卡重复整句」条数与基线对照，重复不再来自钩子句
