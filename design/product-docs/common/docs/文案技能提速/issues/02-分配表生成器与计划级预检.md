# 02 — 分配表生成器与计划级预检（动笔前拦住跨卡返工）

**What to build:** 动笔**之前**，技能能自动排出一张 12 列分配表并用计划级预检器在 0.5 秒内验完跨卡配额——不绿不许动笔。这样「同模式主展开型超限」「乙类占比不足」「封面全批同款」这类**写完整批才能算出来**的问题，在开写前就被拦住。

**Blocked by:** 01 — 工作包生成器与「只读一个文件」的开工步骤

**Status:** ready-for-agent

- [ ] 新增分配表生成器，按**拉丁方轮转**排出 12 列：模式 / 取材型 / 起手型 / 展开型 / 档 / 缺口型 / 整活 / emoji / 封面行数 / 目标末行字数 / 互动钩子 / 钩子形态
- [ ] 排布规则：每结果的四模式固定；**档在结果内两两不同、全批四档均衡**；展开型按模式分配主型（模式一清单轰炸 / 二倒带 / 三一事到底 / 四对话实录）且每组换型 ≤2 张；取材型满足乙类 ≥1/3、甲2 ≤1/4、甲1 与甲3 各 ≤1/6；封面行数在 2~4 间混排且全批不恒定；emoji 按档位两态配额
- [ ] **新增「目标末行字数」列**：在 3 / 7 / 11 / 14 字之间混排，供执行者落笔时对齐末行参差（实测缺这一列会让「末行齐整」判据从基线 33% 恶化到 71%）
- [ ] **钩子形态列填门禁词库里的原句**（如 `有没有人`），不填同义改写（如 `有没有同款`——词库不认，实测导致两组各掉到 1/4）
- [ ] 计划级预检器：验 `#9 四档皆有`、`#16 乙类占比`、`#17 单型占比`、`#20 前 2 位标签恒定`、`#21 同模式主展开型 ≤2/3`、`#23a emoji 按档`、`#23b 末行散布`、`#24 整活配额`、`#25 每结果钩子 ≥2 且形态不重复`、`#26 封面行数 2~4 且全批不恒定`
- [ ] 预检器核对该测试的档位归属（可整活档 / 低气压档）与门禁脚本的执行副本**逐名相等**；档名未登记须报错而非放行
- [ ] `SKILL.md` 与画像手册的流水线步骤同步插入「生成分配表 → 预检 → 不绿不动笔」，两处步骤数保持一致
- [ ] 预检器退出码可判（不绿即非零），便于串进一键流程
- [ ] 端到端验证：以 P1 实验的 24 行分配表为夹具，预检全绿；故意把某模式主型改成 5/6、故意写一个未登记档名，两种情况都必须判失败
- [ ] 端到端验证：实测返工次数从 6 次降到 ≤2 次，且剩余返工均为单卡级（封面级差 / 超宽行）
