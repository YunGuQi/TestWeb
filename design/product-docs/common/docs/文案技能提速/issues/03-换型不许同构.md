# 03 — 「换型不许同构」：分配表排布约束 + 写作规范补条

**What to build:** 同一模式的 ≤2 张换型**必须互不相同**，且全批换型种类 ≥3。这条约束由分配表生成器保证、由计划级预检器把关，并写进写作规范——修掉「字面达标、实则同构」的盲区。

**Blocked by:** 02 — 分配表生成器与计划级预检

**Status:** ready-for-agent

- [ ] 分配表生成器在排「换型」时，同一模式组内的 ≤2 张换型**不得使用同一个展开型**
- [ ] 全批换型所用展开型种类 **≥3**（防止四个组都拿同一个备选型顶格凑数）
- [ ] 计划级预检器把上述两条作为**硬失败**判定，命中即报 ❌ 并指出是哪一组、用了什么型
- [ ] 写作规范（双位与正文册的「展开五型」小节）补一条：同模式的换型必须真换结构，不是换标签；并说明「判词连打」作为备选型时尤其容易被顶格复用
- [ ] 回归验证：把某测试 6 结果 × 四模式的分配表故意排成「四组换型全是判词连打」，预检必须判失败
- [ ] 回归验证：P1 实验的分配表（四组换型各不相同：对话实录 / 判词连打 / 一事到底 / 清单轰炸 / 倒带）预检通过
- [ ] 附一条背景记录进该册：改造前真实批次曾有 24 张里 8 张换型全用同一个备选型、字面达标但仍是同构（作为这条约束存在的理由）
