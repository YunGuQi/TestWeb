# 07 — 规格内联与悬空指针修正（实测回归补修）

**What to build:** 修掉实测暴露的四处口径断链。本次是**回归补修**，不是新功能——上一轮去门禁化把一个分类错误带进了工作包。

**背景（实测发现，2026-09-21 · 性格城市匹配 24 卡 · P2）**

原方案把判据 `#4 单行 ≤15` 归入「数字放松」、`#12 封面错落` 归入「进清单」，工作包 §4 重写为清单形态时**把两条数字一并抹掉**。而工作包 §0 写着「不要读别的技能文档」——执行者拿不到规格，只能违规去读 `01`，读到后发现初稿 **24/24 张正文行宽超标、8 张封面错落不合格**，**整篇重写，占总耗时 50%**。

对比铁证：改造**前**的工作包含 `正文单行字数 ≤ 15 字` 与 `封面错落 2+ 行，须最短板 ≤4 字、最长板 ≥6 字`；改造**后**两条俱失。

**根本原因**：把两类数字当成了一类。**统计分布型**（占比 / 取值数 / 极差 / 密度）是代理指标，删掉正确；**物理格式型**（行宽上限 / 封面行数与长短板 / 字数上限 / 标签个数）是必须达成的形状，删掉等于丢掉唯一规格来源。

**判别口径（一句话）**：这个数字能不能被"凑"出来害人？能凑 → 删；不能凑 → 留。
