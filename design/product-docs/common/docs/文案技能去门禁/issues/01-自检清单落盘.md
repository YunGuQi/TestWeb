# 01 — 自检清单落盘（26 条判据 → 读者视角清单）

**What to build:** 执行者交付前有一份能**读着用**的自检清单。清单替代原 §七 门禁表 #1~#26，成为"交付前看什么"的唯一依据。同时 §四 擦边红线三分区（写前约束）原样保留，§八 逐条检验法按清单需要大幅删减。

清单每条必须满足三条铁律：

1. **是一个"看一眼"的动作**（眼睛能完成的检验），不是需要数数的阈值
2. **不含任何可"凑"的配额数字**（凡「至少 N 张」「≤ M%」一律不出现）
3. **含两条元规则**：「换一双眼睛」固定项、「红线词表写前过一遍」固定项

**判据处置对照（必须逐条落实，不许漏项）：**
