# 04 — 生成器去门禁化

**What to build:** 两个生成器及其共用数据与改造后的清单口径一致——不再产出"跑门禁""预检不绿不许动笔"这类过期指令，也不再排布已被删除的配额项。生成器本身**不进任何判断逻辑**（本次改造不改变它们"零判断"的性质）。

**三个文件各自的改动：**

**工作包生成器**（备料）

- §4「硬指标清单」一节：由原门禁判据表改写为**清单的读者视角动作**
- 删掉「写完跑门禁」类指令，改为指向交付前自检清单
- §0 禁止事项中「不要读门禁脚本源码」一条删除（脚本已不存在）

**分配表生成器**（排程）

- 删除以下被删配额列的生成逻辑与其表头：短行占比、乙类占比、单型占比、主展开型、末行齐整、末行取值数/极差、句号密度
- 删除「本表须经预检才许动笔」的指令
- **保留**配额列：模式 / 取材型 / 起手型 / 展开型 / 档 / 缺口型 / 整活 / emoji / 封面行数 / 目标末行字数 / 互动钩子原句 / 钩子形态
- 保留理由：这些是**排程**（动笔前定死，从源头避免撞句），不是事后判据

**共用数据**

- 同步删除上述被删配额的常量定义
- 保留清单口径需要的常量（红线词表、四档、取材型、展开型等）

**不做什么：** 不改变任何生成逻辑的算法；不新增任何判断；不动输出格式语法（` ```text ` 块与标注行）。
