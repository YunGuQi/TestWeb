# 02 — analyzer 承接合规检查

**What to build:** `xhs-note-analyzer` 成为本技能唯一的独立合规检查者。它当前是「通用账号运营合规」口径，需补齐对本业务的覆盖，并具备整批审查能力。

**两件事：**

**① 词库补齐（当前 10 缺 7）**

已有（3 个）：`治疗` `处方` `疗效`
需补（7 个）：`确诊` `解药` `抑郁` `症状` `药物` `挂号` `心理疾病`

补完后本业务医疗词覆盖 10/10。补入位置与体例沿用该词库既有的「医疗违规 / 医疗擦边」区，并补对应的安全替换建议（该词库 §安全表述替换 体例）。

**② 批量口径**

该技能当前是逐篇人工在环形态（报告后问"是否按建议修复？"）。增加「整批扫」口径：整批一次审、汇总报告、不逐篇回问——避免 24 张卡产生 24 次回环。原单篇精审能力保留不变。

**为什么不只是搬词：** 该技能独有的四件事是本次改造要承接的重点——逻辑闭环（标题承诺正文是否兑现）、去 AI 感（公式化转折、老套精致修辞）、去爹味（第二人称说教 → 第一人称分享）、软 CTA（强推销 → 口语化分享）。这些是原机器门禁**结构上做不到**的能力，也是它成为唯一检查者的正当性来源。
