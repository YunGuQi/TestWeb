## 三、代价声明（本次丢掉了什么）

1. **机器兜底整层消失**：26 条事后字面校验不再有人跑。医疗词 / 产品词 / 测试术语若我看漏，只剩「写前约束 + `xhs-note-analyzer`」两道防线。
2. **自动指针扫描消失**：`--lint-docs` 原先每次交付都能自动兜住悬空链接；现在降级为「本次一次性人工核」（本记录第一张表）。今后文档增删**没有工具兜底**——上面登记的 2 处真悬空就是这个代价的即时体现。
3. **防判据削弱基线消失**：`gate.js --selftest`（41/41）原是对「判据本身还在不在」的回归测试；判据改成清单后，**没有任何东西能证明清单条目没被后人悄悄删掉**。
4. **行为学风险（最需要盯的一条）**：清单是**人可以跳过**的。机器门禁会拒绝交稿，清单只会「提醒」。为对冲它，「**换一双眼睛**」（另起一个 agent 只问「哪一篇最假」）已从可选升为**清单固定项**，且写进了工作包模板与分片派活模板——但它仍然依赖执行者愿意照做。
5. **`plan-gate.js` 的排程反查消失**：分配表排得对不对，原先有 0.5 秒的机器复核；现在只有「生成器只出合规解」这一条结构性保证。
