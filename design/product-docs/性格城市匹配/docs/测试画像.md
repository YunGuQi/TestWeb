1. **深圳（r1）**：本测试唯一**不谈吃喝、只谈产出**的结果，`desc` / `schedule` 里没有任何烟火场景。它的「城市志」底色是写字楼的玻璃幕墙而不是街巷，**口音不许硬塞市井气**（别给它配早茶、排档）；
2. **大理（r11）/ 三亚（r16）**：这两条的内核是**反城市**——「有意识的退场」「彻底躺平」，`quote` 里写的就是「既然卷不过，不如到海边彻底躺平」。**「住在这里」的认领腔要换成「随时可以走」的腔**，否则与结果本意相反；
3. **阿勒泰（r12）**：它不是城市，是**旷野**（`tags` 为 `极致旷野` / `雪原呼吸`）。城市志口吻在它身上没有街巷载体，**口音落在「没有天花板」而不是「这座城市」**。

> 口径见 SOP §零.5.2。本测试结果是「城市 / 地点」型 → 走**城市型模板**（**全批唯一的城市型，其余测试走痛点型**）。

## 五、红线清单（常量 · 每测试写一次）

> 口径见 SOP §零.5.3。通用表见 SOP §四，本表是**本测试摘录 + 专属弃用词**。落笔时对着本表看，不必回翻 SOP。

### 5.1 三分区摘录

| 分区 | 本测试适用 | 处理 |
|---|---|---|
| ✅ **放行** | 夸张、自嘲、阴阳、身份讽刺 | 直接写，这是「野」的主要来源。本测试可用例：`人字拖` / `塑料袋装原浆` / `碳水狂欢` / `拒绝画饼` / `8D魔幻` / `一边骂一边留` |
| ⚠️ **控比例**（同一批 ≤ 三成） | **地域黑 / 地图炮**（拿某个真实城市当贬义靶子）与**城市优劣的比较性断言**（「X 市就是不行」） | 两类都**不许写成对某座城的贬低**——会得罪该城市用户，且平台对地域攻击敏感。**可写的替代框架只有一个：把靶子从「这座城烂」换成「八字不合」**（数据源自己就是这么写的：16 条 `toxicCity.reason` 全部落在第一人称体感上——`你会觉得人生失去了色彩` / `会让你憋出内伤`，没有一条在评那座城的好坏）。写法：写「我在那儿待不住」，不写「那地方不行」 |
| ❌ **不碰** | 脏话、性暗示、身体羞辱、医疗词 | 医疗词逐条列明：`确诊` / `解药` / `抑郁` / `治疗` / `处方` / `症状` / `药物` / `疗效` / `挂号` / `心理疾病` |

**两条口径澄清**：

- 日常叙述词（`生病` / `体检` / `焦虑`）在**非医疗主张语境**下可用——但本测试的 `desc` 里 `焦虑` 与 `解药` / `治愈` 是绑在一起出现的（见 5.2 r1），**只要拆开单独用「焦虑」就安全，连着写就违规**；
- **`toxicCity.name` 里出现了具名真实地域**（如 `东北小镇`）——**地名是风险最高的部分，文案侧一律不具名**，改写具体感场景（见 5.2 末行）；`toxicCity` 这个「相克城市」结构本身是本测试的合规钩子（§四 双钩子之一），**只废地名，不废字段**。

## 六、本测试专属注意

> ⚠️ **字段结构提醒（本测试最容易取错）**：`condition` 是**一个 JSON 字符串**，`tags` / `schedule` / `curePrescription` / `toxicCity` 全部**埋在这个字符串里面**，**必须先解析再取用**，不能当对象直接读。
> `title` 字段自带 `【】` 书名号，取用时须剥掉。
