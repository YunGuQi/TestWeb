# PRD: EMO 情绪内耗测试结果画像个性化主题与滤镜系统 (EMO Result Themes & Visual Filters)

## Problem Statement
当前 EMO（深度情绪内耗测算 / 安安心灵便利店）测试的结果结账单和好友共享卡片采用单调划一的黑白复古热敏小票外观。虽然具备便利店小票质感，但缺乏像 `city`（城市性格测试）那样根据测算结果画像（如【人间铁壁】、【灵魂透支大户】、【精神守财奴】等）量身定制的专属视觉冲击力。用户无论测出何种画像，底色、边框、字色和印章风格均完全一致，降低了用户在小红书或朋友圈晒图炫耀、社交裂变分享的欲望和新鲜感。

## Solution
对标 `city` 测试的 `CITY_THEMES` 架构，建立 `EMO_THEMES` 专属视觉滤镜体系。根据用户的测算画像 Key（涵盖 `low`, `bnd`, `high`, `rum`, `sen`, `pls`, `sen_pls`, `rum_low_bnd`, `burnout`, `isolated` 10 大画像），动态切换：
1. **纸张底色与质感（Paper Background）**：如月光冷灰蓝、警戒粉白、复古防伪金等。
2. **专属字色与排版对比（Text & Accents）**：如冷钢青、深墨绿、警报红、藏青等。
3. **专属边框、撕裂线与阴影（Borders, Tears & Shadows）**：双线框、粗重黑框、雷达虚线框、圆润贴纸框。
4. **专属财务防伪出纳钢印（Stamps）**：个性化定制印泥色与印文（如【绝缘认证】、【止损入库】、【赤字爆表】）。
5. **常模进度条与高光填充（Gradients & Percentiles）**。
6. **全链路端到端覆盖**：主结果页小票、高清截屏长图（`htmlToImage`）、好友分享副本卡片（`SharedReceiptCard`）全量联动。

## User Stories
1. 作为参与 EMO 测试的用户，我希望在获得测算结果时看到与我性格特质匹配的专属色调与盖章，以便感受到强烈的身份认同与仪式感。
2. 作为测出【人间铁壁】的用户，我希望看到冷冽工业钢青风格与“绝缘认证”钢印，以便体现我极低内耗的硬核特质。
3. 作为测出【灵魂透支大户】的用户，我希望看到高对比警报粉红与“赤字爆表”猩红钢印，以便形成强烈的情绪共鸣并促发截屏自嘲。
4. 作为测出【精神守财奴】的用户，我希望看到复古美钞防伪微米金底色与墨绿烫金边框，以便彰显我精明止损的边界感。
5. 作为在移动端长按保存小票的用户，我希望生成的高清长图无白边、无色彩断层，以便在小红书无缝发布高质感配图。
6. 作为收到好友分享卡片的用户，我希望打开时能看到好友画像特有的色调与边框，以便被独特的视觉吸引而点击“我也要测”。

## Implementation Decisions
1. **零改动数据库与 API**：
   - 依赖现有 `emo.engine.ts` 输出的标准画像 `key`（如 `low`, `high`, `rum` 等）。
   - 前端通过纯函数 `getEmoTheme(key)` 读取映射，完全不破坏现有 SQLite/Prisma 数据库结构及 JWT 鉴权协议。
2. **模块与接口规划**：
   - 新建 `app/emo/utils/emo-themes.ts` 集中管理 `EmoThemeConfig` 及 10 大画像主题字典。
   - 改造 `app/emo/components/ResultReceipt.tsx`：全面替换静态 Tailwind 类名为动态主题变量，优化 `toPng` 生成背景色。
   - 改造 `app/emo/components/SharedReceiptCard.tsx`：解析分享荷载中的 `key`，同步渲染主题卡片。
3. **性能与渲染安全**：
   - 纯 CSS 类名与内联色值组合，零额外 HTTP 请求，零动态加载延迟。
   - 兼容纯前端 SVG 二维码与内联样式，确保离线与截屏 100% 还原。

## Testing Decisions
1. **多画像预览覆盖测试**：
   - 利用 `/emo/preview?id=[key]` 快速比对 10 大画像的主题切换正确性。
2. **截屏渲染保真度测试**：
   - 验证 `htmlToImage` 输出的 PNG 在不同主题下的边框、阴影、底色与钢印完整性。
3. **分享链路回归测试**：
   - 验证带 `k` 参数的 URL 能否正确让 `SharedReceiptCard` 呈现对应风格。

## Out of Scope
- 本期不改动题目内容、计分公式权重及支付鉴权链路。
- 本期不增加额外的后台配置表，保持轻量前端驱动。

## Further Notes
- 视觉风格与文案严格契合小红书年轻群体审美与情绪营销心理学。
