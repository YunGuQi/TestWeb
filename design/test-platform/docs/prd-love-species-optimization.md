# PRD: 恋爱物种测试（亲密关系动物原型）内容深度扩充与权重平衡优化

## Problem Statement

当前线上运行的“恋爱物种测试（亲密关系变种图鉴，路由 `/love-species`）”拥有极高的人气和完备的 16 种动物原型（如噬元橘猫、剧毒水母、满电海獭、慢热冬眠熊等），但在内容深度与用户转化体验上仍存在明显的“价值感不足”：
1. **内容切片篇幅偏短、缺乏痛感与画面感**：
   - 目前各物种的简介仅 80 字，饲养指南和雷区仅一句话概括。用户完成 20 道细致的恋爱抉择题后（付出了极高注意力），解锁后看到的内容过于精简，容易产生“几秒钟刷完、不够看”的期待落差。
2. **缺乏小红书婚恋圈最具爆发力的“共鸣爆点”**：
   - 缺少“恋爱破防三大高发名场面（断崖式降温、查岗微表情、已读不回内心海啸）”的具象还原；
   - 缺少“亲密关系隐性情绪损耗”与“恋爱脑中毒指数”的量化痛点呈现；
   - “绝命毒师（Toxic Match）”仅有一句简评，缺乏生动具象的“相克吵架实景剧本”。
3. **题目选项极性出现频次略有偏置**：
   - 题库中倾向于 A（粘人/依赖）的选项比倾向于 D（疏离/独立）的选项多出约 30%，导致橘猫、水母、幼狼等粘人型物种总占比偏高（合占近 35%），而刺猬、猞猁等高冷独立物种出现率偏低（仅 2%~3%）。

## Solution

1. **构建“安安恋爱动物特工图鉴”五大深度切片体系**：
   - **【物种原生性情与深层依恋机制】**（200字深度剖析：你在亲密关系中的安全感黑洞与防御面具）
   - **【恋爱破防高发名场面 TOP 3】**（“在家里装监控”式的具体恋爱痛点瞬间还原）
   - **【亲密关系隐性开销与损耗账单】**（情绪电量消耗年化估算、恋爱脑中毒指数、沉没成本风险）
   - **【高阶驯养与自愈双向手册】**（既有伴侣怎么精准顺毛，又有自己如何摆脱内耗的实操退烧药）
   - **【绝命毒师相克吵架微剧本】**（具象揭示为什么两个物种一旦碰撞会引发核爆级内耗）
2. **维度权重微调与平滑归一化**：
   - 在引擎计算时对 A/D 维度的频次偏置做细微归一化补偿，使 16 种动物物种保持在 4%~8% 的黄金正态平衡区间，消除边缘物种稀释感。
3. **前端检疫档案与机能卡片长图优化**：
   - 保持暗黑头部封面结合机能纸质排版（带有盖戳印章与 MBTI 映射），分栏呈现五大深度模块，优化长图导出保存与小红书 3:4 比例卡片质感。

## User Stories

1. As a 正在恋爱或处于暧昧期的年轻用户，我希望测出具体生动的恋爱动物原型，以便看清自己在感情里的底层依恋模式。
2. As a 用户，我希望在结果页看到精准戳中我痛处的“恋爱破防名场面”，以便惊呼“太准了”并截图发给闺蜜或伴侣。
3. As a 总是容易在感情中内耗疲惫的用户，我希望看到直观的“亲密关系隐性开销”，以便清醒意识到自己的情绪损耗并及时止损。
4. As a 付费解锁用户，我希望获得详尽扎实的“驯养手册”与“相克剧本”，而不是区区一两句话，以便让我觉得这笔测算钱花得超值。
5. As a 运营者，我希望 16 种动物物种均有平滑合理的出现概率，让高冷独立型与热情粘人型人群都能找到自己的同类。

## Implementation Decisions

1. **数据契约向下兼容与文案扩充 (`lib/love-species-data.ts`)**：
   - 保持基础字段（`title`, `emoji`, `radar`, `bestMatch`, `toxicMatch`）不变。
   - 扩充深度切片字段：`breakdownScenes: string[]` (破防名场面TOP3), `hiddenCost: { frictionLevel: string, batteryDrain: string, toxicIndex: string }`, `toxicScenario: string` (绝命毒师相克剧本), `selfCureGuide: string[]` (自我脱敏解药)。
2. **计算引擎平衡优化 (`lib/engines/love-species.engine.ts`)**：
   - 保持 A/D, E/H, S/C, I/R 四对极性判定的稳定性，加入平滑阈值校准，透传新增深度切片字段。
3. **前端渲染更新 (`app/love-species/components/ResultView.tsx`)**：
   - 采用机能特工档案分栏排版，模块化展示破防场景、损耗账单、双向驯养手册与绝命毒师剧本。
   - 优化未解锁时的遮罩诱饵与 `toPng` 高清长图无损导出。

## Testing Decisions

1. **蒙特卡洛 30,000 次模拟**：验证 16 种物种全部命中，各物种命中率全部处于 3%~10% 的健康区间。
2. **极端人格专项验证**：验证纯粘人、纯高冷、纯现实、纯浪漫作答准确命中对应极性动物。
3. **长图导出完整性**：验证移动端长图导出无样式跑偏或空白截断。

## Out of Scope

- 不修改既有 20 道题目的题干文案。
- 不修改数据库主表结构与既有激活码验证流程。
