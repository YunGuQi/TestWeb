# PRD: 命中注定的另一半（新中式红娘档案）算法纠偏与内容深度重构

## Problem Statement

当前线上运行的“命中注定的另一半（安安新中式红娘档案，路由 `/destiny-lover`）”在恋爱心理学与交付体验上存在以下核心瓶颈：
1. **算法死锁与分布失衡**：
   - 题目由 4 对维度（引领L/守护G、直球D/细节S、冒险A/居家C、现实R/精神P）二分组合，理论存在 16 种组合。当前仅配置 8 个结果，且因 `key.split('_')[0]` 前缀截断逻辑，导致 `gscp_pure`【纯粹守护型】命中率为绝对的 **0.00%（死锁）**。
   - `gscp` 单个画像独占超过 25% 的流量，前 4 个画像吞噬超过 81% 的结果分布，导致大量用户产生“撞签”感。
2. **文案堆砌混排，严重缺乏呼吸感与小红书网感**：
   - 目前 `description` 是一整段 300 多字的纯文本，虽然前端尝试通过 `【` 截断，但本质上仍是粗糙的大白话，手机上一眼望去全是密密麻麻的小字，缺乏视觉节奏与小红书年轻情侣喜爱的排版质感。
3. **缺乏具象化的宿命画面感**：
   - 用户做“命定恋人”测试的核心心理是**投射效应与具象救赎幻想**。用户最想看的是“TA 到底长什么样？穿什么衣服？身上有什么气味？我们在什么场景相遇？”，目前全在谈抽象性格，缺乏让人脸红心跳的初遇具象画面。

## Solution

1. **破除死锁并扩充至 12~16 种经典命定恋人谱系**：
   - 修复前缀覆盖 Bug，确保每个 Key 独立参与精确匹配与哈希距离评分。
   - 扩充丰富画像（如：【新中式爹系长辈】、【清冷隐世策士】、【并肩同盟合伙人】、【高阶猫系直球手】等），使全盘 16 维组合精准映射，分布平滑健康（无死锁，各画像在 6%~12% 之间）。
2. **构建新中式红娘“四大深度档案切片”**：
   - **【宿命画像与初遇暗号】**（具象化：穿搭风格、专属气味、常出没地点、初遇宿命微镜头）
   - **【相处默契与致命雷区 TOP 3】**（最令 TA 瞬间沦陷的心动行为 vs 导致断崖式降温的相处死穴）
   - **【红娘合盘与相生相克】**（五行能量互补契合度、前世因缘判词、冤种相处指数）
   - **【催旺正缘红线锦囊】**（单身吸引法则 / 恋爱期如何锁死该类型恋人的实操攻略）
3. **视觉与红娘红签卡片长图优化**：
   - 升级“古典姻缘簿判词”卡片排版，分栏卡片化呈现，增强朱砂印章与红线装饰质感，一键保存高清 3:4 比例小红书分享海报。

## User Stories

1. As a 单身或感情迷茫的用户，我希望看到我的命定恋人有清晰具象的初遇场景与外貌气质描绘，以便在脑海中产生强烈的画面感与心动期待。
2. As a 用户，我希望测试算法不会因为代码 Bug 吞掉某些特定画像，让我能根据真实选择匹配到独一无二的正缘形态。
3. As a 正在恋爱或暧昧中的用户，我希望看到详细的“致命雷区 TOP 3”，以便在现实相处中避免踩中对方的情绪引信。
4. As a 喜爱新中式玄学与红娘文化的小红书用户，我希望看到“合盘契合度”与“宿命判词”，以便获得仪式感与精神慰藉。
5. As a 用户，我希望在解锁后看到条理清晰、卡片式分栏的精致排版，而不是一大坨拥挤的文字，以便我截图发小红书求偶或秀恩爱。
6. As a 运营者，我希望 12~16 个画像在全域作答中分布合理，消除 0% 死锁，保障真实口碑。

## Implementation Decisions

1. **数据契约与谱系扩充 (`lib/destiny-lover-data.ts`)**：
   - 扩充结果画像至 12~16 类，为每个画像注入结构化字段：`firstMeet: { scene: string, visual: string, smell: string }`, `redFlags: string[]`, `synergy: { score: number, karma: string }`, `loveAdvice: string[]`。
2. **算法重构 (`lib/engines/destiny-lover.engine.ts`)**：
   - 彻底修复 `res.key.split('_')[0]` 的死锁逻辑，改为完全唯一的键值比较或基于 4 维位运算的最短汉明距离（Hamming Distance）匹配。
   - 动态输出精准的合盘指标透传给前端。
3. **前端渲染更新 (`app/destiny-lover/components/ResultReceipt.tsx`)**：
   - 升级古典红联卡片为分栏结构：姻缘判词 ➔ 初遇微镜头 ➔ 雷区警示 ➔ 催旺锦囊。
   - 优化未解锁与解锁后的排版与 `html-to-image` 长图导出。

## Testing Decisions

1. **蒙特卡洛 30,000 次模拟**：验证所有结果画像全部命中，无 0.00% 死锁，各画像概率在 5%~15% 健康区间。
2. **汉明距离匹配精度测试**：验证极端作答（纯引领、纯直球、纯居家、纯精神）精准命中目标画像。
3. **海报导出兼容性测试**：验证在移动端导出高清无空白。

## Out of Scope

- 不修改现有 20 道题目的题干文案。
- 不影响数据库主表结构与既有激活码验证流程。
