# PRD: 城市性格匹配测试（精神故乡）商业化卡密遮罩与防白嫖安全闭环

## Problem Statement

当前在测试平台上运行的“城市性格匹配测试（寻找契合你灵魂的那座城，路由 `/city`）”虽然已扩展至 16 座特色城市并校准了算法偏置，但在商业化变现与知识付费交付上存在致命断层：
1. **完全无变现闭环（全量裸奔）**：用户在投入 2~3 分钟完成 20 道细致的日常情境抉择后，结果页面将 24 小时隐居日程、治愈处方、相克城市预警以及车票海报全量无阻拦展示。平台无法通过千帆店铺挂车售卖卡密形成变现，错失了巨大的商业收益。
2. **缺乏防白嫖安全机制**：没有建立“服务端真遮罩”，若直接使用前端 CSS 隐藏，极易被小红书用户 F12 或抓包白嫖。
3. **缺乏“列车长验票”仪式感**：未将“车票”、“登机牌”题材的隐喻转化为付费阻断点，缺乏强有力的心理学逼单钩子。

## Solution

1. **构建“列车长验票”卡密核销闭环**：
   - 确立前 30% 黄金诱饵免费展示：城市名称、精神市民定调、五维坐标图谱、引言、精神市民身份证号（`residentId`）；
   - 确立后 70% 深度生活避难指南卡密锁定：
     - 🌅 24小时精神隐居日程（清晨/午后/深夜的生活方式细节）
     - 🧘 城市治愈处方（发呆圣地、灵魂碳水、精神搭子）
     - ⚠️ 相克城市避雷毒舌预警（把你空投到哪里会当场精神休克）
     - 🎫 完整版超清车票/精神移民证海报无损导出
2. **服务端真遮罩与物理数据脱敏**：
   - 重构 `POST /api/city/submit-test`：作答提交后，后端物理剔除后 70% 的生活切片字段，网络传输报文中绝不包含付费敏感字段；
   - 完善 `POST /api/city/verify`：只有合法卡密核销成功后，作为唯一权威数据源（SSOT）下发解密数据。
3. **前端高质感骨架屏与异步渲染**：
   - 改造 `app/city/components/ResultView.tsx`，在后 70% 区域挂载 `OrderOverlay`；
   - 未解锁时 DOM 树渲染带有脉冲动效的骨架屏（不挂载真实文本，F12 审查也无法白嫖）；
   - 解锁后平滑渐变渲染真实生活切片，并解锁超清海报生成下载。

## User Stories

1. As a 平台运营操盘手，我希望城市测试具备卡密核销拦截，以便在小红书千帆店铺挂车变现并获得真实收益。
2. As a 刚测完城市性格的用户，我希望在免费看到我的“精神市民身份证号”和“五维城市图谱”后，被精准激发起对“24小时隐居日程与相克城市”的强烈好奇心。
3. As a 购买了卡密的用户，我希望输入激活码后能获得深度的生活方式切片与专属治愈处方，感到这笔测算钱花得超值。
4. As a 知识付费消费者，我希望下载一张带有完整印章、条形码和避难日程的高清复古车票海报，以便在小红书晒单打卡。
5. As a 运营开发者，我希望系统具备严格的服务端真遮罩防白嫖机制，杜绝前端源码或网络抓包泄露。

## Implementation Decisions

1. **提交接口脱敏 (`app/api/city/submit-test/route.ts`)**：
   - 在将数据返回给客户端前，物理删除 `schedule`、`curePrescription`、`toxicCity` 字段。
2. **核销接口解密 (`app/api/city/verify/route.ts`)**：
   - 校验卡密成功并记录设备后，从 `CITY_RESULTS_FALLBACK` 中根据城市标识提取完整的深度切片，组装为 `unlockedData` 下发。
3. **前端结果视图接入 (`app/city/components/ResultView.tsx`)**：
   - 引入 `OrderOverlay` 组件；
   - 增加 `isUnlocked` 与 `unlockedData` 状态管理；
   - 未解锁时显示骨架屏，遮罩层提示“【列车长验票】解锁你的专属单程通行证”；
   - 点击“保存海报”时进行鉴权拦截，未解锁拉起弹窗，解锁后导出完整版。

## Testing Decisions

1. **接口脱敏测试**：调用 `POST /api/city/submit-test`，断言返回的 JSON 中不存在 `schedule` 等付费字段。
2. **核销鉴权测试**：调用 `POST /api/city/verify` 输入测试卡密，断言返回完整三大切片。
3. **UI 与 F12 防白嫖自检**：在未解锁状态下审查 DOM 树，确认无真实生活切片文本，输入卡密后平滑渲染并正常导出海报。

## Out of Scope

- 不修改现有 20 道城市测试题目的题干文案。
- 不改动 `schema.prisma` 表结构，卡密复用 `ActivationCode` 表（`testId: 'city-personality'`）。
