# PRD: 测试平台防白嫖安全重构与全域算法概率均衡优化

## Problem Statement

当前线上运行的小红书测试平台（`test.mutong-xhs.top`）在商业安全防护与测评算法分布上存在致命隐患与体验瓶颈：
1. **商业级数据泄露（前端伪遮罩白嫖漏洞）**：
   - 现行系统在用户答题完毕后，`/api/submit` 接口在未经激活码鉴权的情况下，直接将包含完整付费内容（高频破防场景 TOP3、能量吸血鬼、隐性年化账单、专属退税处方、初遇微镜头、雷区警示等）一次性打包返回给浏览器客户端。
   - 前端仅依靠 CSS `backdrop-blur-md` 浮层进行视觉遮挡。任意用户只需在浏览器 F12 中删除遮罩 DOM 节点或直接查看网络请求 JSON 响应，即可零门槛白嫖全套付费测算报告，给知识付费转化造成巨大资金损失。
2. **底层算法极端值死锁（0.06% 近似死锁）**：
   - 在深度情绪内耗测试中，【灵魂透支大户 (`high`)】由于三极值硬门槛脱离统计学实际，在 50,000 次蒙特卡洛全域作答中命中率仅为 0.06%（绝对死锁边缘），而【人间铁壁 (`low`)】仅占 1.01%，无法满足年轻群体对极端情绪体检的诉求。
3. **城市性格匹配测试部分代表城市偏冷**：
   - 城市匹配算法中，【深圳】(1.20%) 与【北京】(2.71%) 因偏置与情境选项偏离，命中率低于 3% 基准线，导致大量一线高压搞钱青年的精神属地无法精准匹配。

## Solution

1. **服务端真遮罩与物理数据脱敏重构**：
   - 重构提交接口 `/api/submit`：未核销卡密前，后端强制剔除后 70% 的核心付费切片数据，前端 DOM 树物理不挂载真实长文，彻底杜绝 F12 白嫖。
   - 激活码核销接口 `/api/verify` 承担唯一权威数据下发职责：只有核销成功后才异步下发解密报告，前端动态挂载。
2. **情绪内耗引擎双极门槛自适应调优**：
   - 调整 `emo.engine.ts` 中极端状态拦截门槛，确保【灵魂透支大户】与【人间铁壁】命中率平滑回升至 4%~8% 的黄金健康区间，全盘 10 个画像无死锁。
3. **城市空间偏置平衡校准**：
   - 微调 `CITY_BIASES` 字典中深圳与北京的权重，使全盘 16 座城市概率全部收敛在 3.5%~12% 之间。
4. **范围明确约定**：
   - 原生家庭测试（`family-origin`）的核心性格指标雷达图完全保留既有现状，不进行动态化变更。

## User Stories

1. As a 平台操盘者，我希望所有测试的付费内容必须在卡密核销成功后才下发给客户端，以保障千帆店铺卡密的真实购买转化率。
2. As a 用户，我希望即使我审查网页元素，也无法看到未付费的真实报告，从而保障知识付费体系的公平与神秘感。
3. As a 极度疲惫或重度内耗的用户，我希望在真实选择消极选项时能顺利测出【灵魂透支大户】，感到被理解与治愈。
4. As a 钝感力极强的生活掌控者，我希望在选择高边界选项时能顺利测出【人间铁壁】，获得心理认同。
5. As a 在一线城市拼搏的效率型用户，我希望在选择快节奏与高搞钱属性时能精准匹配到【深圳】或【北京】。
6. As a 运营开发者，我希望 5 个测试在 50,000 次蒙特卡洛模拟中无任何 0% 死锁画像，各结果均处于健康正态区间。

## Implementation Decisions

1. **提交接口脱敏中间层 (`app/api/submit/route.ts`)**：
   - 引入脱敏过滤函数，在保存流水后，依据不同 `testId` 过滤掉后 70% 的切片字段，仅将前 30% 诱饵数据打包返回。
2. **核销接口解密服务 (`app/api/verify/route.ts`)**：
   - 完善服务端按 `testId` 与 `resultKey` 组装完整深度切片数据的逻辑，保证原子核销后前端获得真实且完整的数据包。
3. **前端结果卡片异步绑定 (`app/emo/components/ResultReceipt.tsx` 等)**：
   - 改造结果组件：将付费区域改为由 `isUnlocked && unlockedData` 驱动，未解锁时仅渲染高质感骨架屏或伪文本占位，核销成功后平滑渐变展示真实干货。
4. **算法判定参数重定 (`lib/engines/emo.engine.ts` & `app/api/city/submit-test/route.ts`)**：
   - 调整 `high` 和 `low` 判定阈值；
   - 调整深圳、北京的 `CITY_BIASES`。

## Testing Decisions

1. **蒙特卡洛 50,000 次纯数学离线模拟**：
   - 验证 `emo` 10 个画像全部 $\ge 4\%$ 且 $\le 20\%$；
   - 验证 `city` 16 座城市全部 $\ge 3.5\%$ 且 $\le 12\%$。
2. **黑盒安全脱敏断言**：
   - 校验 `/api/submit` 返回的 JSON，断言 `scenarios, adviceList, vampires, hiddenCosts` 等字段绝对为 `undefined`。
   - 校验 `/api/verify` 返回有效结果，断言深度切片字段完整可用。

## Out of Scope

- 原生家庭测试（`family-origin`）的雷达图不进行任何代码变更，维持既有呈现。
- 不变更主数据库表结构，不升级核心依赖包。
