# PRD: 命定恋人测试平台合规风控重构与视觉交付物深度升级

## Problem Statement

当前线上运行的“命中注定的另一半（路由 `/destiny-lover`）”在商业化售卖与小红书官方巡检中面临两大致命危机与交付瓶颈：
1. **平台违规封店高危隐患（封建迷信词汇密集暴露）**：
   - 界面与数据中高频出现“月老红娘”、“算命解签”、“五行能量”、“前世宿命因缘”、“催旺正缘”等小红书官方机器过滤算法与人工巡检严厉打击的高危违禁词。
   - 这类词汇在小红书千帆店铺挂车售卖时，极易被直接判定为“封建迷信类违规服务”，面临下架商品、扣除保证金甚至永久封禁店铺的毁灭性打击。
2. **解锁交付体验单薄枯燥（纯文字堆叠、缺乏画面感）**：
   - 用户付费 4.9~9.9 元解锁后，虽然看到了穿搭、气味与初遇镜头的文字描述，但页面缺乏具象的视觉意象载体，全是黑白与米色小字，无法支撑小红书用户追求“高颜值、电影感、发笔记晒单”的感官期待。

## Solution

1. **全面合规化重构（穿上心理学与东方高级美学面具）**：
   - 全面清洗高危词汇：
     - 将“月老红娘 / 姻缘簿”更名为【潜意识择偶原型 / 心动印记】；
     - 将“解签测算”更名为【契合度测算】；
     - 将“五行能量 / 宿命因缘”更名为【共振磁场 / 潜意识羁绊】；
     - 将“催旺正缘秘籍”更名为【高维吸引力 · 专属相处锦囊】；
   - 彻底清除一切封建迷信词汇，打造兼具东方诗意与现代科学心理学背书的全新面具，保障千帆店铺永久合规存续。
2. **视觉交付升级（16 大画像专属意象图腾与电影氛围感卡片）**：
   - 在 `lib/destiny-lover-data.ts` 中为 16 个画像配置东方美学意象象征物（如雪松孤灯、惊涛烈阳、暮色温玉等）与高定光影配色；
   - 在前端结果页将初遇微镜头与意象图腾深度结合，升级为带有烫金边框与氛围徽章的“高定心映画卷”，极大提升付费满足感与 3:4 小红书分享长图的晒单率。

## User Stories

1. As a 平台运营操盘手，我希望测试页面和数据中 0 处出现迷信违规词汇，以确保千帆店铺可以长期安全挂车售卖而不被平台封禁。
2. As a 正在寻找另一半的用户，我希望在解锁后不仅能看到文字分析，还能看到极具意境的意象图腾和电影感氛围卡片，在脑海中产生强烈的浪漫联想。
3. As a 喜欢在小红书晒单的用户，我希望保存的海报极具高级审美与设计感，吸引评论区好友惊呼“好唯美、求测试链接”。
4. As a 购买了卡密的用户，我希望看到实操性强的“单身吸引法”和“恋爱锁死术”，获得切实的情感指导价值。

## Implementation Decisions

1. **数据源扩展与词条清洗 (`lib/destiny-lover-data.ts`)**：
   - 在 16 个画像对象中新增 `visualMotif: { symbol: string, themeColors: string[], moodQuote: string }`；
   - 清洗 `synergy` 中的迷信词汇：`element` 改为共振磁场属性，`karma` 改为潜意识羁绊描绘。
2. **前端界面词条清洗与氛围卡片渲染 (`app/destiny-lover/components/ResultReceipt.tsx`)**：
   - 彻底替换顶部 Header、标签、分栏一、遮罩层以及分栏四五中的所有涉迷信敏感词；
   - 在初遇微镜头上方渲染全新设计的新中式意象图腾卡片。
3. **海报导出兼容性保障**：
   - 确保新增的意象视觉组件能被 `html-to-image` 完美无损捕获，不出现任何排版错位。

## Testing Decisions

1. **敏感词自动化扫描**：脚本全量扫描代码与数据，断言 `月老`、`算命`、`解签`、`五行`、`催旺正缘` 出现频次为 0。
2. **UI 视觉与长图导出自检**：验证 16 个画像的意象图腾在各端正常渲染，长图保存正常。

## Out of Scope

- 不修改现有 20 道题目的打分判定算法（保持汉明距离 16 画像绝对均衡）。
- 不改动数据库表结构。
