# PRD：EMO 情绪测试结果页「图文双轨联动与截屏动态注入二维码」规范

## Problem Statement

目前测试平台中 `emo`（深度情绪内耗测试）的结果页保存小票图片无法实现社交链路闭环。如果直接在常态页面增加二维码，会破坏小票界面的复古美感；如果让用户手动分两步“先保存图片、再找按钮复制链接”，操作链路冗长、体验割裂。

## Solution

1. **保存截图一键联动双享**：
   - 用户点击【保存账单截图】一个按钮，系统同时完成“下载高清小票图片”与“复制精美分享种草文案及链接到剪贴板”；
   - 界面弹出一体化正向反馈 Toast：“账单已保存！分享文案已复制”。
2. **免隐私配置，全量内容呈现**：
   - 去除复杂的隐私模式开关，保留最纯粹的完整账单呈现与分享体验。
3. **截屏瞬间无痕动态注入二维码**：
   - 正常网页浏览状态下，页面底部完全**不显示二维码**，保持票据原汁原味的极简美感；
   - 仅在点击保存瞬间（截屏渲染生命周期），小票底部无痕挂载黑白票据风格的 SVG 二维码，打入下载的 PNG 图片中，实现“图外无码，图中有码”。
4. **好友落地社交裂变卡片**：
   - 朋友点击复制的链接或扫码进入时，承接「好友情绪简报」与强引导【我也要测】按钮，一键开启全新测试。

## User Stories

1. 作为测试用户，我在结果页浏览时看到的是原汁原味的复古黑白小票，没有任何突兀的二维码打扰阅读。
2. 作为测试用户，我点击【保存账单截图】后，系统自动帮我把图片保存到手机相册，同时把适合发在微信群/朋友圈的扎心种草文案和链接直接复制到剪贴板，我切到微信直接长按粘贴即可发给朋友。
3. 作为测试用户，我发到朋友圈或小红书的截图底部自然包含一个黑白条码风格的二维码，朋友长按即可识别进入测试。
4. 作为被分享的好友，我打开链接后看到好友的内耗账单简报，点击【我也要测】一键无缝开启我自己的测试。
