# PRD：原生家庭人生剧本测试（family-origin）结果页「保存长图 · 剪贴板交付 · 微信移动端防报错」标准化规范

## Problem Statement

目前 `family-origin`（原生家庭人生剧本测试 · 绝密人生剧本档案）的结果页在移动端及微信内置浏览器环境下存在以下影响传播和转化的痛点：
1. **微信系统级剪贴板报错**：如果在长图异步渲染完毕后调用剪贴板 API，微信内核会因手势过期强行弹窗报错「未能复制到剪切板」；
2. **移动端无法自动下载长图**：iOS Safari 与微信内核屏蔽脚本自动触发的 `<a download>`，导致点击【分享我的人生剧本】后相册中毫无动静；
3. **导出的长图缺少二维码**：人生档案长图导出后没有二维码，他人看图无法便捷扫码进入测试；若常态显示二维码又破坏了硬核黑白档案的冷峻视觉质感；
4. **本地开发链接真机无法访问**：本地调试直接采用 `origin` 会生成 `localhost` 链接，真机微信扫码直接 404 报错。

## Solution

严格对齐 `emo`、`city` 与 `destiny-lover` 测试的最佳实践：
1. **剪贴板第一毫秒强同步写入**：
   - 用户点击【分享我的人生剧本】的瞬间，在第一毫秒主线程中利用 `textarea`（固定视口内、透明度 0.01、iOS 选区保护）配合 `document.execCommand('copy')` 将原生家庭觉醒文案与短链写入剪贴板；
   - 彻底规避异步调用导致的微信手势过期报错。
2. **移动端与微信专属「长图预览与长按保存浮层」**：
   - 移动端与微信环境生成超清长图后，弹出 `z-[160]` 毛玻璃全屏浮层；
   - 启用长图的 `WebkitTouchCallout: 'default'`，挂载醒目指引条：`👇 请「长按下方图片」保存到相册或发给朋友`；
   - 浮层底部提供清晰的微信发圈发聊天操作指引，附带 `[重新复制文案]` 与 `[我知道了 · 返回]` 按钮；
   - PC 桌面端保持原有静默触发 PNG 文件下载，并支持富文本 `text/html` + `text/plain` 混合写入。
3. **截屏瞬间无痕挂载纯前端矢量二维码**：
   - 正常浏览档案时**完全隐藏二维码**，保持黑白冷峻的档案美感；
   - 点击保存的渲染生命周期内，在档案底部金句横幅下方动态注入纯前端生成的 SVG 矢量二维码（使用 `qrcode` 库，严禁第三方外链防 CORS）；
   - 二维码下方采用利他引导文案：`[ 扫码解密 · 重写你的原生家庭人生剧本 ]`。
4. **极简短链与生产域名智能映射**：
   - 分享链接采用语义化短 Key（如 `?share=ind_fight`）；
   - 本地开发/局域网环境自动映射为生产域名 `https://test.mutong-xhs.top`。

## User Stories

1. 作为一名在微信内测完原生家庭人生剧本的用户，我点击保存档案时不会弹出任何系统级报错，体验行云流水。
2. 作为一名手机用户，点击保存后会弹出一个全屏长图浮层，我可以通过长按卡片直接保存到手机相册或发送给好友。
3. 作为一名测试用户，浮层下方有清晰明了的提示，告知我觉醒文案已自动复制，发微信朋友圈或小红书时直接长按粘贴文案配上相册长图即可。
4. 作为一名被分享的好友，我看到剧本长图底部带有精致的二维码，长按能直接扫码进入同款测试。
5. 作为开发者，我在本地开发生成的档案二维码发给真机微信也能正常扫码打开。

## Implementation Decisions

### 1. 工具模块划分
- 新建 `app/family-origin/utils/share.ts`，封装原生家庭画像语义化短 Key、觉醒治愈文案生成器、纯前端 SVG 矢量二维码生成器、第一毫秒强同步剪贴板写入与环境探测器；
- 在 `app/family-origin/components/ResultReceipt.tsx` 中直接消费这些工具函数，注入二维码容器与移动端长图预览浮层。

### 2. 剪贴板环境风控与分端策略
- 移动端与微信环境：第一毫秒同步执行 `syncCopyText(shareCopy)`，截屏完毕后不再调用任何剪贴板 API；
- PC 桌面端：第一毫秒执行 `syncCopyText`，截屏完毕后额外调用 `copyImageAndTextToClipboard` 实现富文本图文混合写入。

### 3. 无痕二维码注入策略
- 二维码容器在档案 DOM 中常态声明为 `hidden`；
- 在 `isGeneratingImage === true` 时切换为 `flex`，供 `toPng` 截取后立即恢复 `hidden`。

## Testing Decisions

- 必须运行 `rtk npx tsc --noEmit` 保证 TypeScript 零报错；
- 浏览器手机模拟器及微信真机全流程验证。

## Out of Scope

- 不修改现有原生家庭测评题目计分与雷达图模型；
- 不修改原有的订单激活码核销逻辑。
