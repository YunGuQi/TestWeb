# PRD: 城市性格匹配测试（精神故乡）算法修复与内容体系深度升级

## Problem Statement

当前线上运行的“城市性格匹配测试（寻找你的精神故乡，路由 `/city`）”存在致命的算法漏洞与严重的内容敷衍问题：
1. **算法绝对死锁（100% 流量垄断）**：由于用户初始坐标预设为 `[5, 5, 5, 5, 5]` 且题目加分多为正数，导致用户作答后坐标停留在正数区间；而备选城市坐标包含大量负值。在欧氏距离计算中，【上海 / 香港】由于全正数坐标距离最近，**真实模拟命中率为绝对的 100.00%**，其余 4 个城市命中率全部为 **0.00%**！任何用户测出的城市永远只有上海，造成极其严重的体验事故。
2. **内容极其单薄敷衍**：每个城市仅有区区 50 字的官方宣传腔文案，缺乏小红书年轻人喜爱的“生活方式沉浸感”、“城市相克对立梗”和“精神市民常住证”包装，用户答完 10 题后感知价值极低，缺乏付费解锁与晒单动力。
3. **城市库未完全打通**：完整配置文件 `city-personality.json` 中定义了 30+ 座精美城市，但后端的 Fallback 仅硬编码了 5 个城市，导致海量优质城市资产被闲置。

## Solution

1. **重构坐标系与空间相似度算法**：
   - 将坐标系原点重置为以 0 为中心的对称区间 `[-10, +10]`，采用**余弦相似度（Cosine Similarity）结合加权欧氏距离**，消除初始偏置影响。
   - 彻底激活并接入完整城市库（涵盖北上广深、成都、大理、阿勒泰、武汉、重庆、长沙、青岛、杭州、苏州、厦门等 16+ 座核心特色城市），消除 0% 死锁，实现各城市 5%~10% 的健康正态分布。
2. **构建“精神市民常住证”五大深度内容切片**：
   - **精神市民身份证号 & 属地特征**（专属编号、属地能量评级、气候适宜度）
   - **城市精神切片**（200字深度解析：为什么你的灵魂与这座城市同频共振）
   - **24小时精神隐居日程**（具象化生活方式：清晨咖啡、午后放空小巷、深夜路边碳水）
   - **城市治愈处方**（推荐发呆圣地、专属治愈食物、灵魂精神搭子）
   - **相克城市预警**（极具反差和幽默感的毒舌预警：把你空投到哪里会当场精神休克）
3. **车票与证书长图渲染优化**：
   - 升级车票/登机牌（Boarding Pass）排版质感，增加虚线切角与盖印，优化长图保存分享。

## User Stories

1. As a 渴望逃离内卷的年轻人，我希望在完成测试后测出真正契合我生活节奏的精神母城，而不是全网千篇一律只能测出上海。
2. As a 崇尚自由自然的用户，我希望在选择偏爱大自然、低社交时，能够精准匹配到【阿勒泰】、【大理】等旷野城市。
3. As a 追求高效搞钱的打工人，我希望在选择效率至上时，能够精准匹配到【深圳】或【东京】，获得能力认同。
4. As a 用户，我希望看到详细的“24小时精神隐居日程”，以便在脑海中沉浸式体验在这座城市生活的美好细节。
5. As a 用户，我希望了解我的“相克城市”，以便在被戳中痛点时开怀一笑，并转发到社交平台吐槽。
6. As a 小红书用户，我希望生成一张具有复古车票、精神身份证质感的高清长图，以便发笔记打卡晒单。
7. As a 平台运营者，我希望 16+ 个城市在蒙特卡洛模拟下均有稳定命中概率，彻底消除 0% 死锁与 100% 垄断。

## Implementation Decisions

1. **城市库整合与契约统一**：
   - 将 `lib/city-fallback.ts` 扩充至 16 座代表性超级城市，并补充完整的五大深度切片字段（`schedule`, `curePrescription`, `toxicCity`, `residentId`）。
2. **算法重构（消除 100% 偏置）**：
   - 初始坐标设为中性原点 `[0, 0, 0, 0, 0]`。
   - 各题目选项分数标准化，避免单一维度无限正偏。
   - 匹配距离重构为标准向量距离，确保所有城市坐标均处于可达空间内。
3. **渲染层升级 (`ResultView.tsx` / `ResultPoster.tsx`)**：
   - 升级票据卡片为“精神故乡车票 + 市民认证”，分栏呈现日程与相克预警，并支持长图无损导出。

## Testing Decisions

1. **蒙特卡洛算法全域模拟**：运行 30,000 次随机作答，验证所有 16 座城市全部命中，且最高城市占比不超过 15%，最低不低于 3%。
2. **极端人格专项验证**：
   - 极端自然/低社交作答 -> 命中阿勒泰/大理
   - 极端效率/工作狂作答 -> 命中深圳
   - 极端松弛/美食作答 -> 命中成都/长沙
3. **长图生成自检**：验证在移动端各尺寸下长图生成无空白截断。

## Out of Scope

- 不修改卡密验证流程与全局配置表。
- 不影响其他测试路由。
