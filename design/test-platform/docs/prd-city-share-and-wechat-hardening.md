# PRD：城市性格测试（city）结果页「保存长图 · 剪贴板交付 · 微信移动端防报错」标准化规范

## Problem Statement

目前 `city`（心灵逃跑车票 · 城市性格测试）的结果页在分享与保存长图流程中存在以下严重影响转化与传播的痛点：
1. **微信系统级剪贴板报错**：在图片异步渲染完成后调用剪贴板 API，微信内核会因手势过期弹窗警告「未能复制到剪切板」，严重破坏用户信任感；
2. **移动端无法自动下载长图**：iOS Safari、微信与多数 Android 原生 Webview 拦截脚本自动触发的 `<a download>`，导致用户点击保存后相册无图；
3. **生成的长图缺乏回流闭环**：导出的车票图片缺少二维码，他人看图无法便捷进入测试；若常态显示二维码又破坏了车票电影感的设计质感；
4. **本地调试生成的链接在微信端无法访问**：本地使用 `window.location.origin` 生成的包含 `localhost` 的链接，真机扫码直接 404/打不开。

## Solution

参照已在 `emo` 测试验证通过的成熟标准化方案，对 `city` 结果页进行全面升级：
1. **剪贴板第一毫秒强同步写入**：
   - 用户点击【保存/导出专属超清海报】瞬间，在同步主线程第一毫秒利用高兼容性的 `textarea`（固定视口内、透明度 0.01、iOS 选区保护）配合 `document.execCommand('copy')` 将文案与短链写入剪贴板；
   - 杜绝在异步回调中操作剪贴板，彻底根治微信内核报错。
2. **移动端与微信专属「长图预览与长按保存浮层」**：
   - 移动端与微信环境生成高清长图后，弹出 `z-[160]` 毛玻璃全屏浮层；
   - 启用长图的 `WebkitTouchCallout: 'default'`，挂载醒目指引条：`👇 请「长按下方图片」保存到相册或发给朋友`；
   - 浮层底部提供清晰的微信发圈发聊天操作指引，附带 `[重新复制文案]` 与 `[我知道了 · 返回]` 按钮；
   - PC 桌面端保持原有静默触发 PNG 文件下载，并支持富文本 `text/html` + `text/plain` 混合写入（支持 PC 微信直接 Ctrl+V）。
3. **截屏瞬间无痕挂载纯前端矢量二维码**：
   - 正常浏览车票时**完全隐藏二维码**，保持车票原有极简设计美感；
   - 点击保存的渲染生命周期内，在车票底部条形码下方动态注入纯前端生成的 SVG 矢量二维码（使用 `qrcode` 库，严禁第三方外链防 CORS）；
   - 二维码下方采用利他引导文案：`[ 扫码开始测试 · 测测契合你灵魂的那座城 ]`。
4. **极简短链与生产域名智能映射**：
   - 分享链接采用语义化短 Key（如 `?share=dali`）；
   - 本地开发/局域网环境自动映射为生产域名 `https://test.mutong-xhs.top`。

## User Stories

1. 作为一名在微信内置浏览器中完成城市测试的用户，我点击保存海报时，系统不会抛出「未能复制到剪切板」的错误提示，体验顺畅自然。
2. 作为一名在手机上测出心仪城市的用户，点击保存海报后会弹出一个全屏长图预览浮层，我可以通过长按图片方便地保存到系统相册或直接转发给微信好友。
3. 作为一名测试用户，浮层底部有清晰明了的指引，告诉我文案已自动复制，发朋友圈时只需长按粘贴文案并从相册选择刚保存的长图即可。
4. 作为一名被分享的好友，我看到车票截图底部有一个精致的二维码，长按扫码能直接打开测试平台。
5. 作为开发者，我在本地 localhost 调试生成的车票二维码，微信真机扫码也能直接打开线上对应的测试页面。

## Implementation Decisions

### 1. 架构与工具模块划分
- 新建 `app/city/utils/share.ts`，封装 16 座城市语义化短 Key、文案生成器、纯前端 SVG 二维码生成器、第一毫秒强同步剪贴板写入与环境探测器；
- 在 `app/city/components/ResultView.tsx` 中直接消费这些工具函数，注入二维码与移动端预览浮层。

### 2. 剪贴板环境风控与分端策略
- 移动端与微信环境：第一毫秒同步执行 `syncCopyText(shareCopy)`，截屏完毕后不调用任何剪贴板 API；
- PC 桌面端：第一毫秒执行 `syncCopyText`，截屏完毕后额外调用 `copyImageAndTextToClipboard` 实现富文本图文混合写入。

### 3. 无痕二维码注入策略
- 二维码容器在车票 DOM 中常态声明为 `hidden`；
- 在 `isGeneratingImage === true` 时切换为 `flex`，供 `toPng` 截取后立即恢复 `hidden`。

## Testing Decisions

- 必须运行 `rtk npx tsc --noEmit` 保证 TypeScript 零报错；
- 浏览器手机模拟器及微信真机扫码全流程验证。

## Out of Scope

- 不修改现有城市五维算法和题目计分模型；
- 不修改原有的订单激活码核销逻辑。
