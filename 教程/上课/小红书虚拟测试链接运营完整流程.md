## 一、 业务闭环模型与矩阵架构

### 1.1 五步循环飞轮
```
选赛道与品类 → 账号初始化 → 合规上架与自动履约 → 工业化出帖 → 出单核销
      ↑                                                      ↓
      └────────────────── 每日5~10条矩阵发帖 ─────────────────┘
```

### 1.2 标准矩阵架构（1 主 3 辅）
```
主账号（实名认证 + 开通店铺 + 上架商品 + 绑定阿奇索 + 矩阵发帖）
  ├── 关联账号 A（不开店，千帆 App 绑定主店商品，独立手机卡发帖）
  ├── 关联账号 B（同上）
  └── 关联账号 C（同上）
```
* **设备与网络铁律**：一机一卡一号，发帖必须使用**手机自身移动数据流量**，严禁多账号在同一 Wi-Fi 下高频批量发帖，以防平台批量标记限流；
* **实名配额**：单张身份证最多实名认证 2 个小红书账号，4 号矩阵中剩余 2 个账号建议使用家人实名认证；
* **内容分发原则**：老罗私聊确认——**4 个矩阵号完全可以分发相同的爆款商品和相同的文案**，覆盖不同公域流量切片，极大放大爆单概率。

## 二、 账号冷启动与基础搭建

### 2.1 注册账号
1. 手机下载小红书 App，点击【其他登录方式】选择【手机号登录】（**严禁使用微信授权一键登录**）；
2. 初始推荐偏好：性别选**女生**（私信与咨询转化亲和度更高），年龄选 **25~35 岁**，兴趣标签任选 4 个。

### 2.2 资料完善（四项核心设定）
| 资料项 | 规范要求 | 核心目的 |
| :--- | :--- | :--- |
| **头像** | 小动物 / 可爱卡通 / 治愈系女生真人生图 | 消除营销号冰冷感，塑造亲切人设 |
| **名字** | 包含人设与测试字眼（如“安安心理测评”、“小李成长站”） | 强化测试垂类认知，让粉丝感知是真人在运营 |
| **简介** | 简洁一句话：「所有测试仅供娱乐，侵权联系删除」 | 降低版权防卫心理，免责声明防封号 |
| **生日** | 填成年日期即可 | 保证账号具备商业开店资质 |

### 2.3 实名认证与冲突秒级释放
* **认证路径**：我 → 设置 → 账号与安全 → 实名认证；
* **防限流机制**：注册后应立即实名。未实名账号在持续发帖后容易被系统将笔记与商品全局隐藏；
* **实名被占用解决方案**：认证时若提示身份证已被旧号占用，选择【注销旧账号】，注销原因务必勾选【实名被占用】确认提交。**实名身份当场秒级释放**，无需等待 7 天冷却，即可立即在新号上通过认证。

## 三、 店铺开通与商品合规上架（2026新规标准）

> ⚠️ **高危预警**：小红书 2026 年新规已严禁无资质挂靠“电子资源”类目（需官方定向邀请与原创证明，乱挂直接封店）。完整避坑细节详见：[2026新规与阿奇索自动发货配置](references/2026新规与阿奇索自动发货配置.md)。

### 3.1 开通店铺（仅主账号操作）
* **路径**：创作者中心 → 全部服务 → 开通店铺 → 立即开店；
* **类型**：选择【个人店铺】，上传身份证正反面，规模选【小额零售】；
* **保证金策略**：开店初期**无需提前缴纳 500 元保证金**，等有订单产生需要提现时再交；如需参加大促推流活动，可按需预先缴纳。

### 3.2 商品发布关键参数配置
进入电脑千帆后台（[https://ark.xiaohongshu.com/](https://ark.xiaohongshu.com/)），选择【普通方式发布商品】：

1. **商品类目**：必须搜索选择 **【艺术品及周边】 → 【艺术定制】 → 【虚拟定制】**；
2. **商品主图**（二选一，以极简文字突出主题）：
   * **美图秀秀方案**：创建“电商首图”（1:1），纯色背景，居中添加粗黑大号字体（如《SCL-90综合心理健康测试》），导出上传；
   * **豆包 AI 生图方案**：比例选 1:1，提示词：`帮我生成一个商品首图，主题是"xxx心理测试"，简洁纯色背景，居中文字突出`；
3. **商品标题**：直接参考对标标题微调，突出核心卖点（如：`【SCL90在线测试/不限次数/1分钟自动发货/无物流/抑郁焦虑自查】`）；
4. **价格与库存**：标价设为 **1.5 元**（留出活动打折空间，实收 0.5~1 元），库存必须填 **9999**；
5. **物流与服务参数**：
   * 运费模板：**全国包邮**；
   * 发货模式：**现货 / 24h**；
   * 售后服务：**不支持七天无理由退货**；
   * 电脑端提示“开启属性自动填充”时，**坚决不勾选**。

## 四、 测试链接交付与自动化履约（阿奇索）

### 4.1 获取高转化测试链接
1. **AI 自建专属测试（强烈推荐）**：
   * 工具：**百度秒哒**（[https://www.miaoda.cn/](https://www.miaoda.cn/)）或自建单文件 H5；
   * 优势：无版权纠纷、无第三方店铺导流，每天登录送 100 积分（生成一个网站耗约 40 积分）；
   * **标准提示词模板**：
     ```text
     帮我制作一个SCL-90综合焦虑测试网站，
     要求每一题回答完成后才能进入下一题，
     全部问题回答完成后提供详细分析报告，
     界面采用温馨治愈风格，首页添加一个按钮【小红书店铺】跳转到我的店铺链接。
     ```
2. **购买同行链接注意事项**：
   * 严禁使用“一人一码/授权码”的测试链接；
   * 严禁使用带有同行店铺导流链接或标有“免费公益倒卖必究”的网页。

### 4.2 配置阿奇索（Agiso）自动发货
1. 注册登录 [阿奇索官网](https://www.agiso.com/)，选择小红书千帆授权绑定；
2. 在【自动发货设置】中关联千帆上架的测试商品，**核心勾选：[自动更新物流状态]、[千帆消息]、[不使用模板]**；
3. 在发货内容中填入测试网站链接及温馨说明；
4. 电脑端下载安装【阿奇索自动发货助手】，扫码保持登录与静默挂机（或租用云电脑保持后台开机）。

## 五、 矩阵账号关联（小号共享商品）

1. 打开手机端【千帆 App】（仅手机端支持此操作）；
2. 路径：全部工具 → 账号关联 → 创建关联邀请；
3. 输入要绑定的 3 个小红书号（名称下方的数字 ID）；
4. 关联成功后，3 个辅号无需开店即可在发帖时直接挂载主号的测试商品链接；
5. **注意**：关联关系绑定后，即使注销关联小号，解除关联通常需要经过 30 天缓冲期。

## 六、 工业化出帖 SOP（引流出单核心）

出单 95% 依靠单篇笔记的视觉冲击与点击欲望，发帖操作严格遵循以下工业化流水线：

```
[手机App写文字] ───> 极简粗体封面（纯文字或极端实拍）
       │
       ├───────────> 标题嵌入心理钩子（提问 / 制造悬疑 / 极端反差）
       │
       ├───────────> AI（豆包/Kimi）文案批量复制，1条对标派生10篇
       │
       ├───────────> 照搬对标置顶评论与引导文案
       │
       └───────────> 添加组件挂商品链接 ───> 手机流量单日发布5~10条
```

### 6.1 封面制作（零门槛）
* 打开小红书手机 App，点击底部【+】选择【写文字】；
* 直接输入与标题一致的核心大字，选择系统自动生成的简洁纯文字模板，白底黑字或淡色底，**严禁添加艺术字和杂乱贴纸**；
* 或选用手机实拍测试结果的极端分值截图（如占有欲 100%、纯黑暗人格等）。

### 6.2 标题三大心理钩子公式
1. **痛点提问式**：`“正常人装抑郁能骗过医生吗？”`、`“你的动物塑到底是哪一种？”`
2. **制造悬疑与危机感**：`“摆烂太久天赋真的会被系统收走…”`、`“抑郁症最吓人的地方不是心慌手抖。”`
3. **极端案例反差**：`“恋爱占有欲指数拉满100%是种什么体验？”`

### 6.3 批量文案生成
1. 复制对标账号爆款帖子的文案；
2. 粘贴至豆包或 Kimi 输入提示词：`学习这篇心理测试文案的风格与情绪落点，按照此风格帮我扩写10条相似的测试文案`；
3. 一次批量产出 10 篇笔记正文，日后仅需更换封面与标题即可快速发布。

## 七、 每日运营节奏与执行核对表（Checklist）

### 7.1 日常运营节奏表
| 频次 | 核心动作 | 耗时评估 | 验收标准 |
| :--- | :--- | :--- | :--- |
| **每日** | 登录秒哒领 100 积分备用，维持阿奇索助手挂机 | 1 分钟 | 阿奇索助手显示“正常运行中” |

| **每周** | 查阅灰豚商品榜（文教服务）与千帆潜力榜，补充 1~2 个新品 | 15 分钟 | 对标账号粉丝量严格控制在 2000 以内 |

### 7.2 运营排坑避雷警示
* ❌ **禁忌 1**：不要把宝押在单一测试品上（单一品类极易流量枯竭，必须多测试轮换）；
* ❌ **禁忌 2**：封面切勿使用花字与大量表情包（详见 [44帖出8单死因拆解](references/爆款对标与44帖出8单死因拆解.md)）；
* ❌ **禁忌 3**：文案切勿写成冗长的“医学科普或心灵鸡汤”，直接抛出心理痛点与测试钩子转化率最高；
* ❌ **禁忌 4**：发帖切勿使用电脑端后台发布，必须使用手机客户端发布以保障推流权重。
