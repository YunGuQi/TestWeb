## 一、 2026年官方新规红线（生死攸关）

### 1.1 违规封店雷区
* **旧模式失效**：小红书官方对虚拟资料类目全面收紧。原“电子资源”、“电子资料包”等支持官方自动发货的类目，目前**需要官方定向邀请入驻，且必须提交原创资质证明**，保证金门槛也已提升至 1000 元。
* **致命风险**：如果强行在未获邀请的情况下乱挂靠类目，平台判定为虚假类目或无资质经营，将**直接封店**！

### 1.2 官方客服沟通及实测稳妥类目
经过实际测试与小红书官方客服核验，测试类虚拟链接目前最稳妥、不违规的挂靠类目为：
```
【艺术品及周边】 → 【艺术定制】 → 【虚拟定制】
```
* **特点**：无需官方邀请，个人店铺即可上架，合规安全；
* **注意**：该类目**不自带小红书官方免挂机自动发货功能**，因此必须配合第三方挂机发货软件（阿奇索）实现自动履约。

## 二、 商品上架参数配置（合规标准）

在千帆后台发布测试商品时，基础步骤（主图、标题）保持常规，关键在于点击底部的【继续丰富商品信息】进行物流参数配置：

| 配置字段 | 必填值 | 关键说明 |
| :--- | :--- | :--- |
| **所属类目** | **艺术品及周边 > 艺术定制 > 虚拟定制** | 绝不乱挂“电子资源”，防止触发封店 |
| **商品价格** | **1.5 元** | 预留打折/活动空间，实收约 0.5~1 元 |
| **库存数量** | **9999** | 必填项，不填买家无法下单 |
| **运费模板** | **全国包邮** | 必须设置为包邮 |
| **发货模式与时间** | **现货 / 24h** | 配合自动发货助手快速核销 |
| **售后服务** | **不支持七天无理由退货** | 虚拟商品核心保护条款 |
| **发货地址** | 任意地址 | 系统提示添加发货地址时，直接填写一个虚拟地址即可 |
| **属性自动填充** | **关闭 / 不勾选** | 电脑端若弹出“开启属性自动填充”，坚决不选，防止覆盖错误分类 |

## 三、 第三方工具：阿奇索（Agiso）自动发货全配置

### 3.1 工具准备与成本
* **官网地址**：[https://www.agiso.com/](https://www.agiso.com/)
* **费用**：30 元 / 月（新用户提供 **7天免费试用**，启动期先用试用期跑通闭环）。

### 3.2 绑定小红书千帆店铺
1. 登录阿奇索官网，进入【产品中心】选择【自动发货】；
2. 选择【小红书发货】，使用已开店的主账号小红书 App 或千帆 App 扫码完成授权绑定。

### 3.3 自动发货参数设置（核心三勾选）
进入阿奇索后台左侧导航：【商品设置】 → 【自动发货设置】 → 点击【添加】关联刚刚在千帆上架的商品，点击【修改】配置发货规则：

```
[勾选] 自动更新物流状态   ───> 订单支付后自动点击千帆后台发货，无需人工干预
[勾选] 千帆消息           ───> 必须选客服千帆私信发送，切勿勾选短信或买家提取
[勾选] 不使用模板         ───> 剔除“感谢光临”等冗余废话，只发送纯净链接与说明
```

### 3.4 发货文本内容规范
在内容输入框中填入测试网站链接及说明（示例如下）：
```text
【测试链接】：https://xxx.your-test-site.com
【使用说明】：请复制上述链接至手机或电脑浏览器中打开，支持不限次数多次测试。
（注：测试完全免费，拍下为数据整理与服务器服务费）
```
> **排坑提醒**：
> 1. 发货链接严禁使用“一人一码/单次授权码”的网站；
> 2. 严禁使用带有同行引流、水印或声明“公益免费禁止倒卖”的第三方网页；
> 3. 必须确保链接可以永久、多次反复作答（推荐自建 H5 或秒哒生成）。

## 四、 发货助手（客户端）静默挂机实操

### 4.1 挂机必要性
阿奇索是通过本地客户端模拟客服向买家回传私信并更新千帆物流状态的。**如果客户端未运行，买家下单后将无法自动发货，会导致订单超时超时罚款或违规！**

### 4.2 部署步骤
1. 在阿奇索官网首页点击【助手下载】，安装“阿奇索自动发货助手”电脑客户端；
2. 打开客户端，用开店的小红书千帆账号扫码登录；
3. 登录成功后无需其他繁琐设置，保持窗口最小化静默运行即可。

### 4.3 挂机环境建议
* **个人电脑**：白天/晚上开机时保持后台常驻；
* **无长期开机条件者**：建议租用一台基础型**云电脑 / 挂机宝**（月费约十几元），将阿奇索助手安装在云电脑中 24 小时保持在线开机。

## 五、 验收清单（Checklist）

- [ ] 店铺类目是否为【艺术品及周边 > 艺术定制 > 虚拟定制】？
- [ ] 运费是否包邮、售后是否不支持七天无理由？
- [ ] 阿奇索后台是否勾选了“自动更新物流状态”、“千帆消息”、“不使用模板”？
- [ ] 发货链接是否在浏览器无痕模式下测试可用、且支持多次重复答题？
- [ ] 阿奇索发货助手是否在电脑/云电脑中登录并保持运行状态？
- [ ] （自测）用小号自费 1.5 元拍下一单，核验是否在 10 秒内收到自动发货私信且千帆订单变为“已发货”。
